Linear Algebra Cheat Sheet

Everything from vectors to eigenvalues, with the finance applications (portfolio variance, OLS, covariance matrices) that make the abstract material concrete. Each module has definitions, the key theorems, a worked example at exam level, and the traps examiners like.

How to use: read modules 1–7 in order the first time. Modules 8–10 build on 7. Module 11 is the one-page memory dump to rewrite from memory the night before. Module 12 has 27 exam-style problems with full solutions; do them on paper before opening the answers.
