Things that are NOT true

  • $AB=BA$
  • $(AB)^{-1}=A^{-1}B^{-1}$ (order must reverse)
  • $\det(A+B)=\det A+\det B$
  • $\det(cA)=c\det A$ (it is $c^n$)
  • $(A+B)^{-1}=A^{-1}+B^{-1}$
  • $AB=0\Rightarrow A=0$ or $B=0$
  • $\|\mathbf{x}+\mathbf{y}\|=\|\mathbf{x}\|+\|\mathbf{y}\|$
  • Eigenvectors of non-symmetric $A$ are orthogonal
  • Column-space basis read off the reduced matrix

CHECK Exam-day procedure— ⊡ ✕

Before every matrix computation

  • Write dimensions next to each matrix; confirm inner dimensions match.
  • Is the matrix square? Only then: det, inverse, eigenvalues.
  • Is it symmetric? Then eigenvalues real, eigenvectors orthogonal, definiteness tests apply.
  • Is it triangular/diagonal? Then det and eigenvalues are on the diagonal.

When asked to solve $A\mathbf{x}=\mathbf{b}$

  • Square: compute $\det A$. Nonzero ⟹ unique; use inverse, Cramer, or elimination.
  • $\det=0$ or non-square: row reduce $[A|\mathbf{b}]$, compare ranks.
  • Write infinite solutions as particular + $t\cdot$(null vector).

When asked for eigenvalues

  • Set up $\det(A-\lambda I)$; for 2×2 use tr and det directly.
  • Verify: sum = trace, product = det.
  • Each eigenvector: row reduce $A-\lambda I$; it must have a zero row.
  • Verify $A\mathbf{v}=\lambda\mathbf{v}$ numerically.

Self-checks that cost 10 seconds

  • $AA^{-1}=I$ for one row.
  • Residual ⊥ columns after least squares.
  • $\mathbf{u}_i^{\mathsf T}\mathbf{u}_j=0$ after Gram–Schmidt.
  • Portfolio variance $\ge0$; weights sum to 1.
