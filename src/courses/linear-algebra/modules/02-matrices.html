arrays of numbers, or: linear maps written down
DEF Types of matrix— ⊡ ✕

An $m\times n$ matrix has $m$ rows and $n$ columns; entry $a_{ij}$ is row $i$, column $j$. Always state rows × columns.

DEF Matrix multiplication— ⊡ ✕

$AB$ is defined only if columns of A = rows of B. $(m\times n)(n\times p)=(m\times p)$.

$$(AB)_{ij}=\sum_{k=1}^n a_{ik}\,b_{kj}=(\text{row } i \text{ of } A)\cdot(\text{col } j \text{ of } B)$$
PropertyHolds?
Associative $(AB)C=A(BC)$yes
Distributive $A(B+C)=AB+AC$yes
Commutative $AB=BA$NO in general
$AB=0 \Rightarrow A=0$ or $B=0$NO
$AB=AC \Rightarrow B=C$NO (unless A invertible)
$(A+B)^2=A^2+2AB+B^2$NO: it is $A^2+AB+BA+B^2$
DEF Transpose & trace— ⊡ ✕

Transpose swaps rows and columns: $(A^{\mathsf T})_{ij}=a_{ji}$. An $m\times n$ becomes $n\times m$.

$(A^{\mathsf T})^{\mathsf T}$$=A$
$(A+B)^{\mathsf T}$$=A^{\mathsf T}+B^{\mathsf T}$
$(cA)^{\mathsf T}$$=cA^{\mathsf T}$
$(AB)^{\mathsf T}$$=B^{\mathsf T}A^{\mathsf T}$ order reverses
$(ABC)^{\mathsf T}$$=C^{\mathsf T}B^{\mathsf T}A^{\mathsf T}$
$A^{\mathsf T}A$, $AA^{\mathsf T}$always symmetric (and positive semidefinite)
$\mathbf{x}^{\mathsf T}A\mathbf{y}$is a scalar, so equals its own transpose $\mathbf{y}^{\mathsf T}A^{\mathsf T}\mathbf{x}$

Trace (square matrices only)

$$\text{tr}(A)=\sum_{i=1}^n a_{ii}$$
Linearity$\text{tr}(A+B)=\text{tr}A+\text{tr}B$, $\;\text{tr}(cA)=c\,\text{tr}A$
Transpose$\text{tr}(A^{\mathsf T})=\text{tr}(A)$
Cyclic$\text{tr}(AB)=\text{tr}(BA)$, $\;\text{tr}(ABC)=\text{tr}(CAB)=\text{tr}(BCA)$
Eigenvalues$\text{tr}(A)=\sum\lambda_i$ (module 7)
Exam shortcut
Scalar trick: $\mathbf{x}^{\mathsf T}A\mathbf{x}=\text{tr}(\mathbf{x}^{\mathsf T}A\mathbf{x})=\text{tr}(A\mathbf{x}\mathbf{x}^{\mathsf T})$. Used to show $E[\mathbf{x}^{\mathsf T}A\mathbf{x}]=\text{tr}(A\Sigma)+\mu^{\mathsf T}A\mu$.
EX Worked example: multiplication, transpose, trace— ⊡ ✕
$$A=\begin{pmatrix}1&2\\3&4\end{pmatrix},\quad B=\begin{pmatrix}0&1\\-1&2\end{pmatrix}$$
$$AB=\begin{pmatrix}1\cdot0+2\cdot(-1) & 1\cdot1+2\cdot2\\ 3\cdot0+4\cdot(-1) & 3\cdot1+4\cdot2\end{pmatrix}=\begin{pmatrix}-2&5\\-4&11\end{pmatrix}$$ $$BA=\begin{pmatrix}3&4\\5&6\end{pmatrix}\neq AB$$
$$(AB)^{\mathsf T}=\begin{pmatrix}-2&-4\\5&11\end{pmatrix}=B^{\mathsf T}A^{\mathsf T}=\begin{pmatrix}0&-1\\1&2\end{pmatrix}\begin{pmatrix}1&3\\2&4\end{pmatrix}\;\checkmark$$ $$\text{tr}(AB)=-2+11=9=\text{tr}(BA)=3+6\;\checkmark$$
Trap
Before multiplying, write the dimensions: $(2\times2)(2\times2)$. If asked for $\mathbf{x}^{\mathsf T}A$ with $\mathbf{x}\in\mathbb{R}^2$, the result is $(1\times2)(2\times2)=1\times2$, a row vector. Dimension bookkeeping catches half of all errors.
