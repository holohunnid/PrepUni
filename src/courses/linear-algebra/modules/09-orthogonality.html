Orthogonality

perpendicular bases, Gram–Schmidt, least squares
DEF Orthogonal & orthonormal sets, orthogonal matrices— ⊡ ✕
TermCondition
Orthogonal set$\mathbf{v}_i^{\mathsf T}\mathbf{v}_j=0$ for all $i\neq j$
Orthonormal setorthogonal and $\|\mathbf{v}_i\|=1$, i.e. $\mathbf{v}_i^{\mathsf T}\mathbf{v}_j=\delta_{ij}$
Orthogonal matrix $Q$square with orthonormal columns: $Q^{\mathsf T}Q=QQ^{\mathsf T}=I$, $Q^{-1}=Q^{\mathsf T}$
Orthogonal complement $W^\perp$all vectors orthogonal to every vector in $W$; $\dim W+\dim W^\perp=n$

Why orthonormal bases are nice

Coordinates need no inverse: if $\{\mathbf{q}_1,\dots,\mathbf{q}_n\}$ is orthonormal,

$$\mathbf{x}=\sum_i(\mathbf{q}_i^{\mathsf T}\mathbf{x})\,\mathbf{q}_i,\qquad\|\mathbf{x}\|^2=\sum_i(\mathbf{q}_i^{\mathsf T}\mathbf{x})^2\;(\text{Parseval})$$

Orthogonal $Q$ preserves lengths and angles: $\|Q\mathbf{x}\|=\|\mathbf{x}\|$, $(Q\mathbf{x})^{\mathsf T}(Q\mathbf{y})=\mathbf{x}^{\mathsf T}\mathbf{y}$, $\det Q=\pm1$. Examples: rotation $\begin{pmatrix}\cos\theta&-\sin\theta\\\sin\theta&\cos\theta\end{pmatrix}$, permutation matrices, reflections.

Projection onto a subspace

If $W=C(A)$ with $A$ having independent columns, the projection matrix is

$$P=A(A^{\mathsf T}A)^{-1}A^{\mathsf T},\qquad P^2=P,\;P^{\mathsf T}=P$$

With orthonormal columns $Q$: $P=QQ^{\mathsf T}$. Onto a single vector $\mathbf{a}$: $P=\dfrac{\mathbf{a}\mathbf{a}^{\mathsf T}}{\mathbf{a}^{\mathsf T}\mathbf{a}}$.

DEF Gram–Schmidt process— ⊡ ✕

Turns an independent set $\{\mathbf{a}_1,\dots,\mathbf{a}_k\}$ into an orthogonal set $\{\mathbf{u}_i\}$ with the same span (then normalise to get $\{\mathbf{q}_i\}$):

$$\begin{aligned} \mathbf{u}_1&=\mathbf{a}_1\\ \mathbf{u}_2&=\mathbf{a}_2-\frac{\mathbf{u}_1^{\mathsf T}\mathbf{a}_2}{\mathbf{u}_1^{\mathsf T}\mathbf{u}_1}\mathbf{u}_1\\ \mathbf{u}_3&=\mathbf{a}_3-\frac{\mathbf{u}_1^{\mathsf T}\mathbf{a}_3}{\mathbf{u}_1^{\mathsf T}\mathbf{u}_1}\mathbf{u}_1-\frac{\mathbf{u}_2^{\mathsf T}\mathbf{a}_3}{\mathbf{u}_2^{\mathsf T}\mathbf{u}_2}\mathbf{u}_2\\ \mathbf{q}_i&=\mathbf{u}_i/\|\mathbf{u}_i\| \end{aligned}$$

Each step subtracts the projections onto all previous $\mathbf{u}$'s. Result: $A=QR$ with $R$ upper triangular.

Trap
Project onto the already-orthogonalised $\mathbf{u}_j$, not onto the original $\mathbf{a}_j$. Keep fractions exact until the final normalisation, and normalise last.
DEF Least squares & the normal equations— ⊡ ✕

$A\mathbf{x}=\mathbf{b}$ has no solution when $\mathbf{b}\notin C(A)$ (more equations than unknowns, typical for data). Best we can do: minimise the squared error

$$\min_{\mathbf{x}}\|A\mathbf{x}-\mathbf{b}\|^2$$

Solution: choose $\hat{\mathbf{x}}$ so that $A\hat{\mathbf{x}}$ is the projection of $\mathbf{b}$ onto $C(A)$. Residual $\mathbf{e}=\mathbf{b}-A\hat{\mathbf{x}}$ must be ⊥ every column: $A^{\mathsf T}\mathbf{e}=\mathbf{0}$, giving the normal equations

$$A^{\mathsf T}A\,\hat{\mathbf{x}}=A^{\mathsf T}\mathbf{b}\qquad\Longrightarrow\qquad\hat{\mathbf{x}}=(A^{\mathsf T}A)^{-1}A^{\mathsf T}\mathbf{b}$$

$A^{\mathsf T}A$ is invertible ⟺ columns of $A$ are independent. Fitted values $\hat{\mathbf{b}}=A\hat{\mathbf{x}}=P\mathbf{b}$, $P=A(A^{\mathsf T}A)^{-1}A^{\mathsf T}$.

EX Worked examples: Gram–Schmidt and a least-squares line— ⊡ ✕

Gram–Schmidt on $\mathbf{a}_1=(1,1,0)^{\mathsf T}$, $\mathbf{a}_2=(1,0,1)^{\mathsf T}$

  1. $\mathbf{u}_1=(1,1,0)^{\mathsf T}$
  2. $\dfrac{\mathbf{u}_1^{\mathsf T}\mathbf{a}_2}{\mathbf{u}_1^{\mathsf T}\mathbf{u}_1}=\dfrac12$, so $\mathbf{u}_2=(1,0,1)^{\mathsf T}-\tfrac12(1,1,0)^{\mathsf T}=(\tfrac12,-\tfrac12,1)^{\mathsf T}$
  3. Check $\mathbf{u}_1^{\mathsf T}\mathbf{u}_2=\tfrac12-\tfrac12+0=0$ ✓
  4. $\mathbf{q}_1=\tfrac1{\sqrt2}(1,1,0)^{\mathsf T}$, $\;\mathbf{q}_2=\tfrac1{\sqrt{6}}(1,-1,2)^{\mathsf T}$

Fit $y=\beta_0+\beta_1t$ through $(0,1),(1,3),(2,4)$

$$A=\begin{pmatrix}1&0\\1&1\\1&2\end{pmatrix},\;\mathbf{b}=\begin{pmatrix}1\\3\\4\end{pmatrix},\;A^{\mathsf T}A=\begin{pmatrix}3&3\\3&5\end{pmatrix},\;A^{\mathsf T}\mathbf{b}=\begin{pmatrix}8\\11\end{pmatrix}$$ $$\hat{\boldsymbol\beta}=\frac{1}{6}\begin{pmatrix}5&-3\\-3&3\end{pmatrix}\begin{pmatrix}8\\11\end{pmatrix}=\frac16\begin{pmatrix}7\\9\end{pmatrix}=\begin{pmatrix}7/6\\3/2\end{pmatrix}$$

Line: $\hat y=\tfrac76+\tfrac32t$. Residuals $\mathbf{e}=\mathbf{b}-A\hat\beta=(-\tfrac16,\tfrac13,-\tfrac16)^{\mathsf T}$; check $A^{\mathsf T}\mathbf{e}=\mathbf{0}$: column 1: $-\tfrac16+\tfrac13-\tfrac16=0$ ✓. Residuals sum to zero because there is an intercept column of ones.
