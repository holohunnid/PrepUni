01

Vectors

the atoms of everything that follows
DEF Notation & basic operations— ⊡ ✕

A vector in ℝⁿ is an ordered list of n real numbers. Default is a column vector; a row vector is its transpose.

$$\mathbf{x}=\begin{pmatrix}x_1\\ x_2\\ \vdots\\ x_n\end{pmatrix},\qquad \mathbf{x}^{\mathsf T}=(x_1,\;x_2,\;\dots,\;x_n)$$
Addition$(\mathbf{x}+\mathbf{y})_i = x_i + y_i$ — componentwise, same dimension only
Scalar mult.$(c\mathbf{x})_i = c\,x_i$ — stretches (|c|>1), shrinks (|c|<1), flips (c<0)
Linear comb.$c_1\mathbf{v}_1 + c_2\mathbf{v}_2 + \dots + c_k\mathbf{v}_k$
Zero vector$\mathbf{0}$, identity for addition

A portfolio is a linear combination: weights $w_i$ times asset return vectors.

DEF Dot product, norm, distance, angle— ⊡ ✕
Dot product$\mathbf{x}\cdot\mathbf{y}=\mathbf{x}^{\mathsf T}\mathbf{y}=\sum_{i=1}^n x_i y_i$
Norm (length)$\|\mathbf{x}\|=\sqrt{\mathbf{x}^{\mathsf T}\mathbf{x}}=\sqrt{x_1^2+\dots+x_n^2}$
Distance$d(\mathbf{x},\mathbf{y})=\|\mathbf{x}-\mathbf{y}\|$
Angle$\cos\theta=\dfrac{\mathbf{x}^{\mathsf T}\mathbf{y}}{\|\mathbf{x}\|\,\|\mathbf{y}\|}$
Orthogonal$\mathbf{x}\perp\mathbf{y}\iff \mathbf{x}^{\mathsf T}\mathbf{y}=0$
Unit vector$\hat{\mathbf{x}}=\mathbf{x}/\|\mathbf{x}\|$
Cauchy–Schwarz$|\mathbf{x}^{\mathsf T}\mathbf{y}|\le\|\mathbf{x}\|\,\|\mathbf{y}\|$
Triangle ineq.$\|\mathbf{x}+\mathbf{y}\|\le\|\mathbf{x}\|+\|\mathbf{y}\|$

Properties of the dot product: commutative, distributive over +, $\,(c\mathbf{x})\cdot\mathbf{y}=c(\mathbf{x}\cdot\mathbf{y})$, $\,\mathbf{x}\cdot\mathbf{x}\ge 0$ with equality only at $\mathbf{0}$.

DEF Projection— ⊡ ✕

Projection of $\mathbf{b}$ onto the line spanned by $\mathbf{a}$:

$$\text{proj}_{\mathbf{a}}\mathbf{b}=\frac{\mathbf{a}^{\mathsf T}\mathbf{b}}{\mathbf{a}^{\mathsf T}\mathbf{a}}\,\mathbf{a}, \qquad \text{scalar component}=\frac{\mathbf{a}^{\mathsf T}\mathbf{b}}{\|\mathbf{a}\|}$$

The residual $\mathbf{b}-\text{proj}_{\mathbf{a}}\mathbf{b}$ is orthogonal to $\mathbf{a}$. This single idea becomes least squares and OLS in modules 9 and 10.

EX Worked example— ⊡ ✕

Let $\mathbf{x}=(1,2,2)^{\mathsf T}$, $\mathbf{y}=(2,0,-1)^{\mathsf T}$.

  1. $\mathbf{x}^{\mathsf T}\mathbf{y}=1\cdot2+2\cdot0+2\cdot(-1)=0 \Rightarrow \mathbf{x}\perp\mathbf{y}$
  2. $\|\mathbf{x}\|=\sqrt{1+4+4}=3$, $\;\|\mathbf{y}\|=\sqrt{4+0+1}=\sqrt5$
  3. $\hat{\mathbf{x}}=\tfrac13(1,2,2)^{\mathsf T}$
  4. $d(\mathbf{x},\mathbf{y})=\|(-1,2,3)\|=\sqrt{14}$
  5. Project $\mathbf{z}=(3,3,0)^{\mathsf T}$ onto $\mathbf{x}$: $\dfrac{\mathbf{x}^{\mathsf T}\mathbf{z}}{\mathbf{x}^{\mathsf T}\mathbf{x}}\mathbf{x}=\dfrac{9}{9}\mathbf{x}=(1,2,2)^{\mathsf T}$
Trap
$\|\mathbf{x}+\mathbf{y}\|\neq\|\mathbf{x}\|+\|\mathbf{y}\|$ in general. Only equal when the vectors point the same way. Also $\mathbf{x}\cdot\mathbf{y}$ is a scalar, never a vector.
Finance link
Correlation between two demeaned return series $\mathbf{r}_1,\mathbf{r}_2$ is exactly $\cos\theta$: $\rho=\dfrac{\mathbf{r}_1^{\mathsf T}\mathbf{r}_2}{\|\mathbf{r}_1\|\|\mathbf{r}_2\|}$. Uncorrelated = orthogonal.
