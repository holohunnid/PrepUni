Vectors

the atoms of everything that follows
READ FIRST What is a vector, and why should you care?— ⊡ ✕

A vector is simply an ordered list of numbers. That's it. The list $(3, 5)$ is a vector with two entries; $(1, 0, -2, 7)$ is a vector with four. What makes vectors more than "just lists" is that we give them two superpowers — you can add two of them, and you can scale one by a number — and a way to measure how they relate to each other (the dot product). All of linear algebra is built from these three operations.

There are two ways to picture the same vector, and you should get comfortable switching between them:

  • As a point / arrow. The vector $(3,5)$ is an arrow starting at the origin and ending at the point 3 steps right, 5 steps up. This picture gives you geometry: length, direction, angle.
  • As data. The vector $(0.02, -0.01, 0.03)$ could be the daily returns of three stocks, or three days of one stock. This picture is why finance uses linear algebra everywhere: a portfolio, a price history, a set of factor exposures — all vectors.

The arrow picture only works up to 3 dimensions, but every formula in this module works identically in ℝ¹⁰⁰. That is the trick of the subject: build intuition in 2D, compute in any dimension.

IDEA 1 Notation & the two basic operations— ⊡ ✕

A vector in $\mathbb{R}^n$ ("R-n") is an ordered list of $n$ real numbers. The symbol $\mathbb{R}^n$ just means "the set of all such lists": $\mathbb{R}^2$ is the plane, $\mathbb{R}^3$ is 3D space, $\mathbb{R}^{50}$ is the space of 50-number lists (no picture available, formulas unchanged).

By convention a vector is written as a column (stacked vertically). The transpose, written $\mathbf{x}^{\mathsf T}$, lays the same numbers out as a row. This distinction seems pedantic now, but from module 2 onward it decides whether a multiplication is even allowed, so build the habit early.

$$\mathbf{x}=\begin{pmatrix}x_1\\ x_2\\ \vdots\\ x_n\end{pmatrix},\qquad \mathbf{x}^{\mathsf T}=(x_1,\;x_2,\;\dots,\;x_n)$$

Operation 1: addition

Add two vectors entry by entry. Only vectors of the same dimension can be added — there is no way to add a 2-list to a 3-list.

$$\begin{pmatrix}1\\2\end{pmatrix}+\begin{pmatrix}3\\-1\end{pmatrix}=\begin{pmatrix}1+3\\2+(-1)\end{pmatrix}=\begin{pmatrix}4\\1\end{pmatrix}$$

Geometrically this is the tip-to-tail rule: slide the second arrow so it starts where the first one ends; the sum is the arrow from the origin to the final tip.

Operation 2: scaling

Multiply a vector by a single number $c$ (called a scalar, precisely because it scales): every entry gets multiplied by $c$.

$$3\begin{pmatrix}1\\2\end{pmatrix}=\begin{pmatrix}3\\6\end{pmatrix},\qquad -\tfrac12\begin{pmatrix}4\\2\end{pmatrix}=\begin{pmatrix}-2\\-1\end{pmatrix}$$

The arrow keeps its direction and gets stretched ($|c|>1$), shrunk ($|c|<1$), or flipped to point the opposite way ($c<0$). The zero vector $\mathbf{0}$ (all entries 0) is what you get from $c=0$; adding it changes nothing.

Combining both: the linear combination

Do both at once — scale several vectors and add the results — and you get the single most important expression in this course:

$$c_1\mathbf{v}_1 + c_2\mathbf{v}_2 + \dots + c_k\mathbf{v}_k$$

Read it as "a recipe": take $c_1$ parts of $\mathbf{v}_1$, $c_2$ parts of $\mathbf{v}_2$, and so on. Almost every question in later modules ("does this system have a solution?", "are these vectors redundant?") is secretly a question about which vectors a set of recipes can produce.

Finance link
A portfolio is a linear combination: if asset $i$ has return vector $\mathbf{r}_i$ (its returns over time) and you hold weight $w_i$, the portfolio's return vector is $w_1\mathbf{r}_1+\dots+w_n\mathbf{r}_n$.

Check yourself: with $\mathbf{u}=(1,0)^{\mathsf T}$, $\mathbf{v}=(0,1)^{\mathsf T}$, which vector is $2\mathbf{u}-3\mathbf{v}$? (Answer: $(2,-3)^{\mathsf T}$. Note that any vector in ℝ² is some combination of these two.)

IDEA 2 The dot product: one number that measures alignment— ⊡ ✕

The dot product (also written $\mathbf{x}^{\mathsf T}\mathbf{y}$, "x transpose y") multiplies two vectors of the same dimension entry by entry and adds everything up. The result is a single number, not a vector:

$$\mathbf{x}\cdot\mathbf{y}=\mathbf{x}^{\mathsf T}\mathbf{y}=\sum_{i=1}^n x_i y_i = x_1y_1+x_2y_2+\dots+x_ny_n$$

Example: $(1,2,3)\cdot(4,0,-1)=1\cdot4+2\cdot0+3\cdot(-1)=1$.

What does that number mean? It measures how much the two vectors point the same way:

  • Large positive → roughly the same direction.
  • Zero → perpendicular (the vectors are called orthogonal, written $\mathbf{x}\perp\mathbf{y}$).
  • Negative → pointing in roughly opposite directions.

Everything the dot product gives you

Length. Dot a vector with itself: $\mathbf{x}^{\mathsf T}\mathbf{x}=x_1^2+\dots+x_n^2$, the sum of squared entries. Its square root is the length (the norm) — in 2D this is literally Pythagoras:

$$\|\mathbf{x}\|=\sqrt{\mathbf{x}^{\mathsf T}\mathbf{x}}=\sqrt{x_1^2+\dots+x_n^2}\qquad\text{e.g. }\|(3,4)\|=\sqrt{9+16}=5$$

Distance. The distance between two points is the length of the difference vector: $d(\mathbf{x},\mathbf{y})=\|\mathbf{x}-\mathbf{y}\|$.

Angle. The angle $\theta$ between two vectors satisfies

$$\cos\theta=\frac{\mathbf{x}^{\mathsf T}\mathbf{y}}{\|\mathbf{x}\|\,\|\mathbf{y}\|}$$

This formula explains the sign behaviour above: $\cos\theta$ is $+1$ for parallel vectors, $0$ at 90°, $-1$ for opposite. Setting the numerator to zero recovers the orthogonality test: $\mathbf{x}\perp\mathbf{y}\iff \mathbf{x}^{\mathsf T}\mathbf{y}=0$.

Direction only. Dividing a vector by its own length produces a unit vector (length exactly 1) pointing the same way: $\hat{\mathbf{x}}=\mathbf{x}/\|\mathbf{x}\|$. Useful whenever you care about direction but not magnitude.

Rules it obeys

Symmetric$\mathbf{x}\cdot\mathbf{y}=\mathbf{y}\cdot\mathbf{x}$
Distributes over +$\mathbf{x}\cdot(\mathbf{y}+\mathbf{z})=\mathbf{x}\cdot\mathbf{y}+\mathbf{x}\cdot\mathbf{z}$
Scalars pull out$(c\mathbf{x})\cdot\mathbf{y}=c\,(\mathbf{x}\cdot\mathbf{y})$
Never negative with itself$\mathbf{x}\cdot\mathbf{x}\ge0$, and $=0$ only for $\mathbf{x}=\mathbf{0}$
Cauchy–Schwarz$|\mathbf{x}^{\mathsf T}\mathbf{y}|\le\|\mathbf{x}\|\,\|\mathbf{y}\|$ — why $\cos\theta$ above is always in $[-1,1]$
Triangle inequality$\|\mathbf{x}+\mathbf{y}\|\le\|\mathbf{x}\|+\|\mathbf{y}\|$ — a detour is never shorter

Check yourself: compute $(2,1)\cdot(-1,2)$. (Answer: $-2+2=0$ — the vectors are orthogonal. Sketch them: one is the other rotated 90°.)

IDEA 3 Projection: the shadow of one vector on another— ⊡ ✕

Question: given two vectors $\mathbf{a}$ and $\mathbf{b}$, how much of $\mathbf{b}$ points along $\mathbf{a}$? Imagine the sun directly above the line through $\mathbf{a}$: the projection is the shadow $\mathbf{b}$ casts onto that line.

To find it, note the shadow must be some multiple $t\mathbf{a}$ of $\mathbf{a}$, and the leftover $\mathbf{b}-t\mathbf{a}$ must be perpendicular to $\mathbf{a}$ (a shadow is directly below the object). Perpendicular means dot product zero:

$$\mathbf{a}^{\mathsf T}(\mathbf{b}-t\mathbf{a})=0\;\Longrightarrow\;t=\frac{\mathbf{a}^{\mathsf T}\mathbf{b}}{\mathbf{a}^{\mathsf T}\mathbf{a}}$$

So the projection formula — worth memorising, it reappears constantly — is:

$$\text{proj}_{\mathbf{a}}\mathbf{b}=\frac{\mathbf{a}^{\mathsf T}\mathbf{b}}{\mathbf{a}^{\mathsf T}\mathbf{a}}\,\mathbf{a}$$

The projection splits $\mathbf{b}$ into two clean pieces: a part along $\mathbf{a}$ and a part perpendicular to $\mathbf{a}$. The perpendicular part $\mathbf{b}-\text{proj}_{\mathbf{a}}\mathbf{b}$ is the shortest possible gap between $\mathbf{b}$ and the line — "closest point on a line" is a projection. Replace "line" with "plane of all possible regression fits" and this same idea becomes least squares and OLS in module 9.

The length of the shadow (with a sign for direction) is called the scalar component: $\dfrac{\mathbf{a}^{\mathsf T}\mathbf{b}}{\|\mathbf{a}\|}$.

Check yourself: project $\mathbf{b}=(2,2)^{\mathsf T}$ onto $\mathbf{a}=(1,0)^{\mathsf T}$. (Answer: $t=2/1=2$, projection $(2,0)^{\mathsf T}$ — the shadow of the point $(2,2)$ on the x-axis, as expected.)

EX Worked example: every formula once— ⊡ ✕

Let $\mathbf{x}=(1,2,2)^{\mathsf T}$, $\mathbf{y}=(2,0,-1)^{\mathsf T}$. We compute everything from this module.

  1. Dot product. $\mathbf{x}^{\mathsf T}\mathbf{y}=1\cdot2+2\cdot0+2\cdot(-1)=2+0-2=0$. Zero, so $\mathbf{x}\perp\mathbf{y}$: these vectors are perpendicular in 3D space even though you can't easily sketch them.
  2. Lengths. $\|\mathbf{x}\|=\sqrt{1^2+2^2+2^2}=\sqrt9=3$ and $\|\mathbf{y}\|=\sqrt{4+0+1}=\sqrt5$.
  3. Unit vector. Divide by the length: $\hat{\mathbf{x}}=\tfrac13(1,2,2)^{\mathsf T}$. Sanity check: its length is $\tfrac13\cdot3=1$ ✓.
  4. Distance. $\mathbf{x}-\mathbf{y}=(-1,2,3)^{\mathsf T}$, so $d(\mathbf{x},\mathbf{y})=\sqrt{1+4+9}=\sqrt{14}$.
  5. Angle. $\cos\theta=\dfrac{0}{3\sqrt5}=0$, so $\theta=90°$ — consistent with step 1.
  6. Projection. Project $\mathbf{z}=(3,3,0)^{\mathsf T}$ onto $\mathbf{x}$: first $\mathbf{x}^{\mathsf T}\mathbf{z}=3+6+0=9$ and $\mathbf{x}^{\mathsf T}\mathbf{x}=9$, so $t=9/9=1$ and $\text{proj}_{\mathbf{x}}\mathbf{z}=1\cdot\mathbf{x}=(1,2,2)^{\mathsf T}$. The leftover $\mathbf{z}-\mathbf{x}=(2,1,-2)^{\mathsf T}$ should be ⊥ $\mathbf{x}$: check $2+2-4=0$ ✓.
Trap
$\|\mathbf{x}+\mathbf{y}\|\neq\|\mathbf{x}\|+\|\mathbf{y}\|$ in general — lengths don't add unless the vectors point the same way (walk 3 km east then 4 km north: you are 5 km from home, not 7). And $\mathbf{x}\cdot\mathbf{y}$ is a scalar, never a vector — writing a vector answer for a dot product is an instant lost mark.
Finance link
Take two return series, subtract each one's mean ("demean" them) to get $\mathbf{r}_1,\mathbf{r}_2$. Their correlation is exactly the cosine formula: $\rho=\dfrac{\mathbf{r}_1^{\mathsf T}\mathbf{r}_2}{\|\mathbf{r}_1\|\|\mathbf{r}_2\|}=\cos\theta$. Correlated = small angle; uncorrelated = orthogonal; perfectly negatively correlated = opposite directions. Geometry and statistics are the same picture.
