01

Matrix terminology

lecture 1, slides 6–14 · what a matrix is and what its shape already tells you
READ FIRST Why start with vocabulary?— ⊡ ✕

The lecture opens with a list of motivations, and they are worth taking seriously because they explain the shape of everything that follows:

  • Systems of linear equations. A page of simultaneous equations becomes one short expression, $A\mathbf{x}=\mathbf{b}$, which you can then reason about as a single object.
  • Optimization. Second-order conditions are statements about a Hessian matrix — whether it is positive or negative definite decides maximum versus minimum.
  • Finance. Portfolio variance is $\mathbf{w}'\Sigma\mathbf{w}$, where $\Sigma$ is the covariance matrix of asset returns. One matrix carries every variance and every correlation.
  • Economics. Input–output models of production are matrices of technical coefficients (module 13 solves one).

This first module is only terminology, and it is genuinely short. But the lecture makes a point on slide 13 that is easy to read past and worth stating loudly:

The point of this module
The type of a matrix — square, symmetric, diagonal, triangular — tells you something structural about the problem before you compute anything. "$\Sigma$ is symmetric" is not bookkeeping; it is the statement that $\text{Cov}(X,Y)=\text{Cov}(Y,X)$. "$\Sigma$ is diagonal" is the statement that the assets are uncorrelated. Learning to read shape as meaning is most of what this module is for.
DEF Matrix, entries, rows, columns— ⊡ ✕

A matrix is a rectangular array of numbers. We write it $A=[a_{ij}]$, where the entry $a_{ij}$ sits in row $i$ and column $j$ — row index always first:

$$A=[a_{ij}]=\begin{bmatrix}a_{11}&a_{12}&\dots&a_{1k}\\a_{21}&a_{22}&\dots&a_{2k}\\ \vdots& & &\vdots\\ a_{n1}&a_{n2}&\dots&a_{nk}\end{bmatrix}$$

Two pieces of notation from the lecture that get used constantly later:

  • the $i$-th row of $A$ is written $\;\mathbf{a}_{i\cdot}:=\begin{bmatrix}a_{i1}&a_{i2}&\dots&a_{ik}\end{bmatrix}$ — a row of $k$ numbers;
  • the $j$-th column of $A$ is written $\;\mathbf{a}_{\cdot j}:=\begin{bmatrix}a_{1j}\\a_{2j}\\ \vdots\\ a_{nj}\end{bmatrix}$ — a column of $n$ numbers.

The dot occupies the slot that runs free: $\mathbf{a}_{i\cdot}$ fixes the row and lets the column vary. This looks fussy now; from module 03 onward it is the only way to state the multiplication rule without drowning in indices.

Dimensions

The dimensions of a matrix are how many rows and how many columns it has. $A$ above is an $(n\times k)$-matrix — read "$n$ by $k$" — with $n$ rows and $k$ columns. Rows first, always. If $n=k$ the matrix is square.

Trap
$(2\times3)$ and $(3\times2)$ are different objects and are almost never interchangeable. Getting the order backwards is the single most common source of "this product is not defined" errors later. Say it out loud: rows by columns.

Check yourself: in $\begin{bmatrix}1&2&3\\0&4&5\end{bmatrix}$, what are the dimensions, what is $a_{23}$, and what is $\mathbf{a}_{\cdot2}$? (Answers: $2\times3$; $a_{23}=5$; $\mathbf{a}_{\cdot2}=\begin{bmatrix}2\\4\end{bmatrix}$.)

DEF Vectors are matrices too— ⊡ ✕

A vector is an ordered set of numbers arranged in a single row or a single column. The lecture's point is that this is not a separate kind of object — a vector is just a matrix with one of its two dimensions equal to 1:

  • a row vector is a $(1\times k)$-matrix: $\;\mathbf{a}=\begin{bmatrix}a_1&a_2&\dots&a_k\end{bmatrix}$;
  • a column vector is an $(n\times1)$-matrix: $\;\mathbf{b}=\begin{bmatrix}b_1\\b_2\\ \vdots\\ b_n\end{bmatrix}$.

Because of this, every rule you learn for matrices applies to vectors automatically. You never need a separate theory.

Notation conventions used everywhere below

Capital letters$A$, $B$, $\Sigma$ — matrices
Bold lower case$\mathbf{a}$, $\mathbf{b}$, $\mathbf{x}$ — vectors
Italic lower case$c$, $\lambda$ — scalars (plain real numbers)
Default shapea vector is a column unless stated otherwise

That last line matters. When the lectures write $\mathbf{x}\in\mathbb{R}^n$ they mean an $(n\times1)$ column. If a row is wanted it is written as a transpose, $\mathbf{x}'$ (module 02).

Why the column default
Because the object we care most about is $A\mathbf{x}$: a matrix acting on a vector. For that product to be defined, $\mathbf{x}$ has to be a column. Every formula in modules 03 and 12–13 is built around it.
DEF The named types of matrix— ⊡ ✕

These six names appear on slides 9–12 and are used without further comment for the rest of the course. Each is a restriction on where the zeros are or on how the entries mirror each other.

Zero (null) matrix, written $\mathbf{0}$every entry is 0. Not necessarily square — there is a $2\times5$ zero matrix.
Diagonal matrixsquare, and $a_{ij}=0$ whenever $i\neq j$. Only the main diagonal may be non-zero (a diagonal entry is allowed to be zero too).
Scalar matrixdiagonal, with the same value in every diagonal position: $cI$.
Identity matrix $I$ (or $I_n$)the scalar matrix with 1s on the diagonal. It is to matrices what the number 1 is to numbers: $AI=A$, $IB=B$ (module 03).
Symmetric matrix$a_{ij}=a_{ji}$ for all $i,j$ — the matrix is unchanged by reflecting across the main diagonal. Necessarily square.
Triangular matrixzeros entirely above the diagonal (lower triangular) or entirely below it (upper triangular). Usually square.

A concrete instance of each, matching slide 9:

$$\underbrace{\begin{bmatrix}0&0\\0&0\\0&0\end{bmatrix}}_{\text{zero }(3\times2)}\quad \underbrace{\begin{bmatrix}1&0&0\\0&8&0\\0&0&4\end{bmatrix}}_{\text{diagonal}}\quad \underbrace{\begin{bmatrix}a&0&0\\0&a&0\\0&0&a\end{bmatrix}}_{\text{scalar}}\quad \underbrace{\begin{bmatrix}1&0&0\\0&1&0\\0&0&1\end{bmatrix}}_{I_3}\quad \underbrace{\begin{bmatrix}1&2&6\\2&8&4\\6&4&5\end{bmatrix}}_{\text{symmetric}}\quad \underbrace{\begin{bmatrix}a&b&c\\0&d&e\\0&0&f\end{bmatrix}}_{\text{upper triangular}}$$

Note how the names nest: every identity matrix is scalar, every scalar matrix is diagonal, every diagonal matrix is both symmetric and triangular (both ways at once). The list is a hierarchy, not six unrelated boxes.

EXERCISE (slide 14) · covariance matrix — reading a matrix's type as an economic statement

A portfolio manager gives you the covariance matrix of returns of three assets:

$$\Sigma=\begin{pmatrix}0.04&0.01&0.00\\0.01&0.09&0.02\\0.00&0.02&0.16\end{pmatrix}$$

a) What type of matrix is $\Sigma$?

  1. It has 3 rows and 3 columns, so it is square.
  2. Check the mirror condition $a_{ij}=a_{ji}$: $\sigma_{12}=\sigma_{21}=0.01$ ✓, $\sigma_{13}=\sigma_{31}=0.00$ ✓, $\sigma_{23}=\sigma_{32}=0.02$ ✓. So $\Sigma$ is symmetric.
  3. It is not diagonal (there are non-zero entries off the diagonal), not scalar, not triangular.

b) Why must a covariance matrix always be symmetric?

Because the entry in position $(i,j)$ is by definition $\sigma_{ij}=\text{Cov}(R_i,R_j)=E[(R_i-\mu_i)(R_j-\mu_j)]$, and multiplication of numbers is commutative:

$$\text{Cov}(R_i,R_j)=E[(R_i-\mu_i)(R_j-\mu_j)]=E[(R_j-\mu_j)(R_i-\mu_i)]=\text{Cov}(R_j,R_i)=\sigma_{ji}$$

So symmetry is not a coincidence of this particular data set — it is forced by what covariance means. The diagonal entries are the special case $i=j$: $\sigma_{ii}=\text{Cov}(R_i,R_i)=V[R_i]$, the variances. Here $V[R_1]=0.04$ (so $\sigma_1=20\%$), $V[R_2]=0.09$ ($\sigma_2=30\%$), $V[R_3]=0.16$ ($\sigma_3=40\%$).

c) Is $\Sigma$ diagonal? What would that mean economically?

No: $\sigma_{12}=0.01$ and $\sigma_{23}=0.02$ are non-zero. If $\Sigma$ were diagonal, every off-diagonal covariance would be zero, i.e. all three assets would be pairwise uncorrelated. That is a very strong economic claim: no common factor, no sector effect, no market beta shared between them. Portfolio variance would then collapse to $\sum_i w_i^2\sigma_i^2$, with no cross terms at all.

What is true here is the single zero $\sigma_{13}=0$: assets 1 and 3 are uncorrelated with each other, although both are correlated with asset 2. Notice how much you have just read off the matrix without doing any arithmetic — that is the skill slide 13 is pointing at.

Where this is going
Symmetry of $\Sigma$ is not decoration. It is exactly the property that makes portfolio variance $\mathbf{w}'\Sigma\mathbf{w}$ a well-behaved quadratic form, which is what makes mean–variance optimisation solvable.
