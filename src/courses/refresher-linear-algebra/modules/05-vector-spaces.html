05

Vector spaces

lecture 2, slides 5–11 · two closure conditions, and what fails them
READ FIRST A definition with only two lines, and why it is so useful— ⊡ ✕

Up to now "vector" has meant "column of numbers". This module makes the notion abstract, and the abstraction costs almost nothing: a vector space is any set in which you can add two elements and scale one, without ever leaving the set. That is the whole definition. Its elements are then called vectors, whatever they actually are — columns of numbers, matrices, functions.

The reason to bother is stated bluntly on slide 9: not every economically meaningful set is a vector space, and knowing which ones are tells you immediately whether "combining strategies" is a well-defined operation. If you can hold portfolio $\mathbf{u}$ and portfolio $\mathbf{v}$, can you hold $\mathbf{u}+\mathbf{v}$? Can you hold $2\mathbf{u}$, or $-\mathbf{u}$? For some sets yes, for others no — and the two closure conditions are exactly the test.

How to use the definition
To prove a set is a vector space you must verify both conditions for arbitrary elements. To disprove it you need only one explicit counterexample. Most exam questions are the second kind, so always try first to break the set — it is much faster when it works.
DEF Vector space— ⊡ ✕

A vector space $V$ is a set of elements which is

  1. closed under addition: if $v_1,v_2\in V$ then $v_1+v_2\in V$;
  2. closed under scalar multiplication: if $v\in V$ and $\lambda\in\mathbb{R}$ then $\lambda v\in V$.

The elements of a vector space are called vectors. "Closed" means: performing the operation never produces something outside the set. There is no third condition to check in this course.

Two consequences you get for free

  • $\mathbf{0}\in V$. Take any $v\in V$ and $\lambda=0$: closure under scaling forces $0\cdot v=\mathbf{0}$ into $V$. So a set that does not contain the zero vector cannot be a vector space — the fastest disproof available, and worth trying first every time.
  • Closed under subtraction. If $u,v\in V$ then $-v=(-1)v\in V$ by scaling, and then $u+(-v)=u-v\in V$ by addition. Subtraction needs no separate axiom.

Combining the two conditions repeatedly gives the general statement (slide 14): a vector space is closed under any linear combination of its elements,

$$\sum_{i=1}^{n}\alpha_i v_i\in V\qquad\text{for all }v_i\in V,\ \alpha_i\in\mathbb{R}$$

which is really the form in which the definition gets used.

EX The standard examples— ⊡ ✕

$\mathbb{R}^n$ for any $n\ge1$

Adding two lists of $n$ real numbers gives a list of $n$ real numbers; multiplying a list of $n$ real numbers by $\lambda$ gives a list of $n$ real numbers. Both closures hold trivially, so $\mathbb{R}^n$ is a vector space — the one we work in throughout.

In $\mathbb{R}^2$ you can see it: adding two arrows by the parallelogram rule keeps you in the plane; stretching, shrinking or reversing an arrow keeps you in the plane. There is nowhere else to go.

All matrices of a fixed size

The set of all $(n\times k)$-matrices is a vector space: the sum of two $(n\times k)$-matrices is an $(n\times k)$-matrix, and a scalar times an $(n\times k)$-matrix is an $(n\times k)$-matrix (module 02). Note the size must be fixed — the set of "all matrices" is not closed under addition, since most pairs cannot be added at all.

Why this example matters
It shows "vector" is a role, not a shape. A $3\times3$ matrix is a perfectly good vector in the space of $3\times3$ matrices. So is a random variable, in the space of random variables with finite variance — which is why covariance behaves like a dot product and why "orthogonal" means "uncorrelated".

Check yourself: is the set of all $(2\times2)$ symmetric matrices a vector space? (Yes: $A'=A$ and $B'=B$ give $(A+B)'=A'+B'=A+B$, and $(\lambda A)'=\lambda A'=\lambda A$. Both closures survive.)

EXERCISE (slide 10) · is the budget set a vector space?

Consider the investor budget set

$$B=\{(x_1,x_2)\in\mathbb{R}^2_+\;:\;p_1x_1+p_2x_2\le m\},\qquad m>0$$

Check both closure conditions. Which fails, and why? (What happens if you double an affordable bundle?)

Solution. Both conditions fail. It is enough to exhibit one counterexample for each.

  1. Scalar multiplication fails on two counts. Take an affordable bundle that exhausts the budget, e.g. $\mathbf{x}=(m/p_1,\,0)$, so $p_1x_1+p_2x_2=m$ and $\mathbf{x}\in B$. Now scale by $\lambda=2$: $$2\mathbf{x}=(2m/p_1,\,0),\qquad p_1(2m/p_1)=2m>m$$ so $2\mathbf{x}\notin B$. This is the "double an affordable bundle" hint: doubling a bundle doubles its cost, and the budget does not double with it.
  2. Scaling fails a second way, independently of the budget line. Take $\lambda=-1$ and any $\mathbf{x}\in B$ with $\mathbf{x}\neq\mathbf{0}$: then $-\mathbf{x}$ has a negative coordinate, so $-\mathbf{x}\notin\mathbb{R}^2_+$ and is not in $B$. Negative consumption is outside the set by construction.
  3. Addition fails too. With the same $\mathbf{x}$ as above, $\mathbf{x}+\mathbf{x}=2\mathbf{x}$ costs $2m>m$. Two individually affordable bundles need not be jointly affordable — which is the entire economic content of a budget constraint.

So $B$ is not a vector space. Note that the zero test does not settle it here: $\mathbf{0}=(0,0)$ is in $B$ (it costs nothing and is non-negative), so the quick check passes and you still have to do the work.

The economics behind the failure
Two features break closure, and both are deliberate modelling choices: the inequality with a positive bound $m$ (scaling up eventually exceeds it) and the non-negativity restriction $\mathbb{R}^2_+$ (no short-selling of consumption). A budget set is a convex set, not a linear one — convexity is what economics needs here, and it is a genuinely weaker property.
EXERCISE (slide 11) · fully-invested versus self-financing portfolios

Three assets; $x_i$ is the fraction of wealth held in asset $i$. Define

$$W=\{\mathbf{x}\in\mathbb{R}^3:x_1+x_2+x_3=1\}\ \text{(fully invested)},\qquad W_0=\{\mathbf{w}\in\mathbb{R}^3:w_1+w_2+w_3=0\}\ \text{(self-financing, long–short)}$$

Which of $W$, $W_0$ is a vector space?

Solution: $W_0$ is; $W$ is not.

  1. $W$ fails immediately at the zero test. $\mathbf{0}=(0,0,0)$ has coordinate sum $0\neq1$, so $\mathbf{0}\notin W$ and $W$ cannot be a vector space. Done in one line.
  2. If you prefer an explicit counterexample: $\mathbf{x}=(1,0,0)$ and $\mathbf{y}=(0,1,0)$ are both in $W$, but $\mathbf{x}+\mathbf{y}=(1,1,0)$ has sum $2\neq1$. Likewise $2\mathbf{x}=(2,0,0)$ has sum 2. Both closures fail.
  3. $W_0$ passes both. Let $\mathbf{u},\mathbf{v}\in W_0$, so $\sum_i u_i=0$ and $\sum_i v_i=0$. Then $$\sum_i(u_i+v_i)=\sum_i u_i+\sum_i v_i=0+0=0\ \Rightarrow\ \mathbf{u}+\mathbf{v}\in W_0$$ $$\sum_i(\lambda u_i)=\lambda\sum_i u_i=\lambda\cdot0=0\ \Rightarrow\ \lambda\mathbf{u}\in W_0$$ Both closures hold for arbitrary elements, so $W_0$ is a vector space — in fact a subspace of $\mathbb{R}^3$ (module 06), of dimension 2 (module 08).
The economics
The difference is the right-hand side, $1$ versus $0$. A fully-invested portfolio must deploy exactly your wealth: the constraint is an affine one (a plane not through the origin), and combining two such portfolios naïvely spends your money twice. A self-financing position costs nothing to open — every long is funded by a short — so you can add two of them, scale one up, or reverse one, and it is still self-financing. Zero net cost is precisely what makes the set linear.

This is also why textbook portfolio theory writes an arbitrary portfolio as one fully-invested benchmark plus a self-financing overlay: $W=\mathbf{x}_0+W_0$, a fixed point plus a vector space. That decomposition is the finance version of the general solution structure in module 12 — one particular solution plus the space of homogeneous solutions.
