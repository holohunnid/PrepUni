Transpose, addition and scaling

lecture 1, slides 17–22 · the three easy operations, and the one condition they all share
READ FIRST The easy operations — and why they are still worth care— ⊡ ✕

Three operations in this module: transpose (flip a matrix on its diagonal), addition/subtraction (entry by entry), and multiplication by a scalar (every entry times the same number). They are easy in the sense that nothing surprising happens: matrices behave here exactly like ordinary numbers.

What is not automatic is the admissibility condition. Addition and subtraction require the two matrices to have exactly the same dimensions — same number of rows and same number of columns. There is no way to add a $(2\times3)$ to a $(3\times2)$, and no convention that quietly fixes it for you. Half of Exercise 1 at the end of lecture 1 consists of spotting which of a list of proposed operations are legal at all, and that is the actual skill being tested.

Habit to build now
Before computing anything, write the dimensions under each symbol. $\underset{(2\times3)}{A}+\underset{(3\times2)}{B}$ — the mismatch is visible before you have done a single addition. This habit becomes essential in module 03, where the condition is subtler.
DEF Equality and transposition— ⊡ ✕

Equality

Two matrices $A=[a_{ij}]$ and $B=[b_{ij}]$ with the same dimensions are equal if and only if $a_{ij}=b_{ij}$ for every $i$ and every $j$. Matrices of different dimensions are simply not comparable — the question "are they equal?" does not arise.

Transposition

The transpose of $A=[a_{ij}]$, written $A'$ (the lectures' notation) or $A^{\mathsf T}$, is obtained by interchanging rows and columns: the $k$-th row of $A'$ is the $k$-th column of $A$. Formally:

$$B=A'\iff b_{ij}=a_{ji}\quad\text{for all }i,j$$

Note the index swap. If $A$ is $(n\times k)$ then $A'$ is $(k\times n)$ — the dimensions flip as well.

$$\begin{bmatrix}1&2\\3&4\end{bmatrix}'=\begin{bmatrix}1&3\\2&4\end{bmatrix},\qquad \begin{bmatrix}1&2&3\\4&5&6\end{bmatrix}'=\begin{bmatrix}1&4\\2&5\\3&6\end{bmatrix}$$

The square example shows the diagonal entries never move; only the off-diagonal pairs swap. The rectangular example shows the shape change: $(2\times3)\to(3\times2)$.

Three facts to keep

Transposing twice does nothing$(A')'=A$
The transpose of a column vector is a row vector$\mathbf{a}=\begin{bmatrix}a_1\\ \vdots\\ a_n\end{bmatrix}\Rightarrow \mathbf{a}'=\begin{bmatrix}a_1&\dots&a_n\end{bmatrix}$
Symmetry, restated$B\text{ symmetric}\iff B=B'$

That third line is the cleanest possible definition of symmetric, and it is how you will actually check symmetry from now on: transpose it and see whether you get the same matrix back. For

$$B=\begin{bmatrix}2&3&6\\3&4&5\\6&5&9\end{bmatrix}\quad\text{we get}\quad B'=\begin{bmatrix}2&3&6\\3&4&5\\6&5&9\end{bmatrix}=B$$
Trap
$(A')'=A$ is always true. $A'=A$ is true only for symmetric matrices. Students conflate the two under exam pressure; they say very different things.
DEF Addition, subtraction, scalar multiple— ⊡ ✕

Addition and subtraction

If $A$ and $B$ have the same dimensions, then

$$C=A+B=[a_{ij}+b_{ij}],\qquad D=A-B=[a_{ij}-b_{ij}]$$

and $C$, $D$ have those same dimensions. Nothing more happens: you add the numbers that sit in matching positions.

Properties — all inherited directly from the arithmetic of real numbers:

Zero is neutral$A+\mathbf{0}=A$
Commutative$A+B=B+A$
Associative$(A+B)+C=A+(B+C)$
Transpose distributes$(A+B)'=A'+B'$

Remember the last one: in module 03 the corresponding rule for products is $(AB)'=B'A'$ — the order reverses. For sums it does not. That asymmetry is a favourite exam question.

Scalar times matrix

For a real number $c\in\mathbb{R}$ and a matrix $A=[a_{ij}]$, the product $cA$ multiplies every entry by $c$:

$$cA:=[c\,a_{ij}]$$

$cA$ has the same dimensions as $A$; no admissibility condition at all, since a scalar fits any shape. In the special case where the matrix is a vector,

$$c\mathbf{a}=c\begin{bmatrix}a_1\\a_2\\ \vdots\\ a_n\end{bmatrix}=\begin{bmatrix}ca_1\\ca_2\\ \vdots\\ca_n\end{bmatrix}$$

Geometrically (in $\mathbb{R}^2$ or $\mathbb{R}^3$) this stretches the arrow by a factor $|c|$, keeping its direction if $c>0$ and reversing it if $c<0$. Scaling never rotates a vector — a fact module 07 turns into the test for whether two vectors are dependent.

Finance link
Rescaling a portfolio by $c$ is exactly $c\mathbf{w}$: same relative composition, $c$ times the money. Adding two matrices of returns adds them period by period. These operations are cheap precisely because they never mix different assets or different dates together — that mixing is what the product in module 03 does.
WORKED · which of these are even defined?

Let $A=\begin{bmatrix}1&2&3\\0&4&5\end{bmatrix}$ (a $2\times3$) and $B=\begin{bmatrix}1&2\\0&4\\0&3\end{bmatrix}$ (a $3\times2$). Decide, then compute what you can.

  1. $A+B$: $(2\times3)+(3\times2)$ — dimensions differ, so not defined. No rescue available.
  2. $A+B'$: $B'$ is $(2\times3)$, matching $A$. Defined: $$A+B'=\begin{bmatrix}1&2&3\\0&4&5\end{bmatrix}+\begin{bmatrix}1&0&0\\2&4&3\end{bmatrix}=\begin{bmatrix}2&2&3\\2&8&8\end{bmatrix}$$
  3. $A'-B$: $A'$ is $(3\times2)$, matching $B$. Defined: $$A'-B=\begin{bmatrix}1&0\\2&4\\3&5\end{bmatrix}-\begin{bmatrix}1&2\\0&4\\0&3\end{bmatrix}=\begin{bmatrix}0&-2\\2&0\\3&2\end{bmatrix}$$
  4. $3A'$: always defined. $3A'=\begin{bmatrix}3&0\\6&12\\9&15\end{bmatrix}$.

The pattern: transposing is the tool that makes a mismatched addition legal. When an exercise says "if possible, compute…", it is asking you to notice both the impossible cases and the ones a transpose repairs. The full version of this is Exercise 1 in module 14.
