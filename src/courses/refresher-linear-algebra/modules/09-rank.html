09

Matrices as sets of vectors — rank

lecture 3, slides 4–10 · one number that summarises how much a matrix really contains
READ FIRST A change of viewpoint— ⊡ ✕

Lecture 3 opens by asking you to stop seeing a matrix as a rectangular array of numbers and start seeing it as a set of vectors. An $(n\times k)$-matrix becomes a set of $k$ vectors of $\mathbb{R}^n$ — namely its $k$ columns:

$$\underset{(n\times k)}{A}=\begin{bmatrix}a_{11}&a_{12}&\dots&a_{1k}\\a_{21}&a_{22}&\dots&a_{2k}\\ &&\dots&\\a_{n1}&a_{n2}&\dots&a_{nk}\end{bmatrix}\quad\longleftrightarrow\quad \underbrace{\{\mathbf{a}_{\cdot1},\mathbf{a}_{\cdot2},\dots,\mathbf{a}_{\cdot k}\}}_{k\text{ vectors in }\mathbb{R}^n}$$

Read the two dimensions accordingly: $k$ (columns) is how many vectors there are, $n$ (rows) is how many coordinates each one has. Everything from modules 06–08 — span, independence, basis, dimension — now applies to a matrix directly, and that is exactly what makes rank, determinant and inverse definable.

Why bother
Because module 03 established that $A\mathbf{x}$ is a linear combination of the columns of $A$. So the columns-as-vectors picture is not an analogy: it is the correct way to see what a matrix does. The rank measures how many genuinely different directions the matrix can produce.
DEF Rank— ⊡ ✕

The rank of a matrix is the number of linearly independent vectors among the matrix columns — equivalently, the dimension of the column space, the vector space generated by the columns:

$$\text{rank}(A)=\dim\big(\text{span}(\{\mathbf{a}_{\cdot1},\mathbf{a}_{\cdot2},\dots,\mathbf{a}_{\cdot k}\})\big)$$

where $\mathbf{a}_{\cdot i}\in\mathbb{R}^n$ is the $i$-th column of $A$.

Reading it as "how much is genuinely there": a matrix with 5 columns but rank 2 is carrying 5 vectors of which only 2 are new — the other 3 are combinations of those. The column space is a 2-dimensional plane inside $\mathbb{R}^n$, no matter how many columns you write down.

Rows give the same answer

Theorem. The number of linearly independent vectors among the columns of a matrix equals the number of linearly independent vectors among its rows.

Corollary. The column space and the row space of a matrix have the same dimension.

This is why one can speak unambiguously of "the rank of a matrix" — no need to say "column rank" or "row rank". It also gives a free identity:

$$\text{rank}(A)=\text{rank}(A^{\mathsf T})\;\le\;\min\left(\text{number of rows},\ \text{number of columns}\right)$$

The inequality is worth using constantly. You cannot have more independent columns than there are columns (obviously), and you cannot have more than there are rows either — each column lives in $\mathbb{R}^n$, which holds at most $n$ independent vectors (module 08).

Instant bound
A $(3\times5)$-matrix has rank at most 3, whatever its entries. A $(2\times100)$-matrix has rank at most 2. Write this bound down before doing any work — it often settles the problem, and it always narrows the possibilities.
TIP How to find a rank in practice— ⊡ ✕

At this stage of the course you have three tools, and you should use them in this order:

  1. Bound it first. $\text{rank}\le\min(n,k)$. For a $4\times3$ matrix, rank is 0, 1, 2 or 3 — you have already eliminated most answers.
  2. Look for an obvious relation. Is a column a multiple of another? Is one column the sum of two others? Does a whole row or column vanish? Spotted relations reduce the count immediately, and are far faster than any systematic method.
  3. Test a candidate set with a determinant (module 10). If some $r\times r$ block of the matrix has non-zero determinant, those $r$ columns are independent and $\text{rank}\ge r$. Combined with the upper bound, this usually pins the number exactly.

Two facts that shorten the work:

  • $\text{rank}(A)=0$ if and only if $A$ is the zero matrix. Any non-zero entry gives rank at least 1.
  • If $A$ has a row of zeros, that row contributes nothing; the same for a zero column. But note the rank is not simply "number of non-zero rows" — the surviving rows can still be dependent on each other.
Finance reading
Let $R$ be the matrix of asset returns, states $\times$ assets. Then $\text{rank}(R)$ is the number of non-redundant securities, and the column space is the set of achievable payoffs. Market completeness is $\text{rank}(R)=$ number of states. Module 14, Exercise (vii) does exactly this computation.
EXERCISE 13 (slide 9) · find the rank of three matrices
$$A=\begin{bmatrix}1&2&5\\1&3&7\\1&0&1\\2&3&8\end{bmatrix},\qquad B=\begin{bmatrix}1&0&-1&0\\1&-1&2&0\\0&0&0&-15\end{bmatrix},\qquad C=\begin{bmatrix}2&3&0\\1&5&-1\end{bmatrix}$$

Matrix $A$ — a $(4\times3)$, so $\text{rank}(A)\le\min(4,3)=3$.

  1. Name the columns: $\mathbf{a}_1=(1,1,1,2)$, $\mathbf{a}_2=(2,3,0,3)$, $\mathbf{a}_3=(5,7,1,8)$.
  2. Look for a relation. Try $\mathbf{a}_1+2\mathbf{a}_2$: $$(1,1,1,2)+2(2,3,0,3)=(1+4,\;1+6,\;1+0,\;2+6)=(5,7,1,8)=\mathbf{a}_3\ \checkmark$$ So $\mathbf{a}_3=\mathbf{a}_1+2\mathbf{a}_2$ — the third column is redundant and contributes no new direction.
  3. Are $\mathbf{a}_1,\mathbf{a}_2$ themselves independent? Neither is a multiple of the other (the third coordinates are 1 and 0, so any multiple would need factor 0, killing the rest). For two vectors that is the complete test (module 07), so yes.
  4. Therefore exactly 2 independent columns: $\;\boxed{\text{rank}(A)=2}$. The column space is a plane inside $\mathbb{R}^4$.

Matrix $B$ — a $(3\times4)$, so $\text{rank}(B)\le\min(3,4)=3$.

  1. With 4 columns in $\mathbb{R}^3$, the columns are certainly dependent — but that does not settle the rank. Use rows instead: there are only 3 of them, and the theorem says rows give the same answer.
  2. Rows: $\mathbf{r}_1=(1,0,-1,0)$, $\mathbf{r}_2=(1,-1,2,0)$, $\mathbf{r}_3=(0,0,0,-15)$.
  3. $\mathbf{r}_3$ is independent of the other two: any combination $\alpha\mathbf{r}_1+\beta\mathbf{r}_2$ has last coordinate $0$, while $\mathbf{r}_3$ has $-15\neq0$ there.
  4. $\mathbf{r}_1$ and $\mathbf{r}_2$ are independent of each other: not multiples (second coordinates 0 and $-1$).
  5. Formally, suppose $\alpha\mathbf{r}_1+\beta\mathbf{r}_2+\gamma\mathbf{r}_3=\mathbf{0}$. The last coordinate gives $-15\gamma=0$, so $\gamma=0$. The second gives $-\beta=0$, so $\beta=0$. The first then gives $\alpha=0$. Only the trivial combination vanishes, so all three rows are independent.
  6. $\;\boxed{\text{rank}(B)=3}$ — the maximum possible for a matrix with 3 rows.

Matrix $C$ — a $(2\times3)$, so $\text{rank}(C)\le\min(2,3)=2$.

  1. Again work with rows, since there are fewer: $\mathbf{r}_1=(2,3,0)$, $\mathbf{r}_2=(1,5,-1)$.
  2. Two vectors, so the test is just "is one a multiple of the other?". Matching first coordinates would need $\lambda=1/2$, but then the second coordinate would be $3/2\neq5$. Not multiples, so independent.
  3. $\;\boxed{\text{rank}(C)=2}$, the maximum for a matrix with 2 rows. (Equivalently: the three columns $(2,1)$, $(3,5)$, $(0,-1)$ live in $\mathbb{R}^2$ and any two non-parallel ones already span it — a third can add nothing.)
Insight
Notice the strategy in $B$ and $C$: work with whichever side has fewer vectors. Because $\text{rank}(A)=\text{rank}(A^{\mathsf T})$, you are free to choose, and checking 2 or 3 rows beats checking 4 columns every time. That freedom is the practical value of the row/column theorem.
DEF Full rank— ⊡ ✕

From here the lecture narrows to square matrices, because those are the ones attached to systems with as many equations as unknowns — the case where you can hope for exactly one solution.

A square $(n\times n)$-matrix $A$ has full rank if its $n$ columns are linearly independent, i.e. if

$$\text{rank}(A)=n$$

Since $\text{rank}\le\min(n,n)=n$ always, "full rank" means the rank is as large as it could possibly be — no column is redundant.

By module 08, $n$ independent vectors in the $n$-dimensional space $\mathbb{R}^n$ form a basis. So for a square matrix these are all the same statement:

$A$ has full rank$\text{rank}(A)=n$
the columns of $A$ are linearly independentno redundancy
the columns of $A$ form a basis of $\mathbb{R}^n$they reach everything, uniquely
$A\mathbf{x}=\mathbf{b}$ has exactly one solution, for every $\mathbf{b}$module 12
$\det A\neq0$module 10 (Proposition 3.1)
$A^{-1}$ existsmodule 11 (Proposition 4.2)

Six equivalent conditions. The reason the next two modules exist is entirely practical: checking independence directly means solving a system, whereas the determinant reduces the whole question to computing a single number and comparing it with zero.
