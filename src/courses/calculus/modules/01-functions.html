01

Functions & foundations

the algebra you must not fumble, and the objects calculus acts on
READ FIRST Why this module exists— ⊡ ✕

Calculus is not really about limits, derivatives and integrals. It is about functions — and those three tools are just three questions you can ask about a function: where is it heading? (limit), how fast is it changing? (derivative), how much has accumulated? (integral). If the function itself is hazy, all three answers will be hazy.

Almost every mark lost in a calculus exam is lost twice: once on the calculus and once on the algebra underneath it. A sign slipped while expanding a bracket, a log rule misremembered, a domain forgotten — the derivative was right, the answer was wrong. So this module does two jobs:

  • Refresh the algebra that every later manipulation silently assumes — powers, logs, exponentials, factoring.
  • Pin down what a function is, its domain, how functions combine and invert, and what the standard library of functions looks like — because from module 4 onward you will be differentiating these by reflex.
Chapter map
Sets and intervals (the language for "where the function lives") → what a function actually is → the standard function library and their graphs → combining functions: composition and inverses → the algebra toolkit you should be able to use without thinking.
IDEA 1 Sets and intervals — the language of "where"— ⊡ ✕

A set is a collection of objects, with no order and no repetition. We write $x\in A$ for "$x$ is in $A$" and $x\notin A$ for "is not". Two ways to specify a set:

  • Listing: $A=\{1,2,3\}$.
  • Rule (set-builder): $A=\{x\in\mathbb{R}: x^2<9\}$, read "all real $x$ such that $x^2<9$". This is the form you meet constantly, because domains are described this way.

The three operations, and the one relation:

Union$A\cup B=\{x: x\in A \text{ or } x\in B\}$
Intersection$A\cap B=\{x: x\in A \text{ and } x\in B\}$
Complement$A^c=\{x: x\notin A\}$
Difference$A\setminus B=A\cap B^c$
Subset$A\subseteq B$: every element of $A$ is in $B$
De Morgan$(A\cup B)^c=A^c\cap B^c$, $(A\cap B)^c=A^c\cup B^c$

Intervals — the only sets you will actually use

Calculus lives on the real line $\mathbb{R}$, and almost every set you meet is an interval. Square bracket = endpoint included, round bracket = excluded. Infinity always gets a round bracket, because $\infty$ is not a number you can include.

$[a,b]$$a\le x\le b$ — closed (contains its endpoints)
$(a,b)$$a<x<b$ — open
$[a,b)$$a\le x<b$ — half-open
$(a,\infty)$$x>a$ — unbounded

This open/closed distinction looks like pedantry and is not: in module 3 the Extreme Value Theorem guarantees a maximum on $[a,b]$ and guarantees nothing on $(a,b)$. The function $f(x)=x$ on $(0,1)$ has no largest value — every candidate is beaten by something closer to 1.

Absolute value

$|x|$ is the distance from $x$ to 0, so $|x-a|$ is the distance from $x$ to $a$. That reading turns inequalities into intervals instantly:

$$|x-a|<\delta \iff a-\delta < x < a+\delta \iff x\in(a-\delta,\,a+\delta)$$

Memorise that equivalence now — it is the definition of a limit in module 2, where $\delta$ is a small distance and the statement reads "$x$ is within $\delta$ of $a$".

Check yourself: write $\{x:|x-3|\le 2\}$ as an interval. (Answer: $[1,5]$ — everything within distance 2 of 3.)

IDEA 2 What a function is (and what a domain is for)— ⊡ ✕

A function $f:D\to\mathbb{R}$ is a rule that assigns to each input $x$ in the set $D$ exactly one output $f(x)$. Three words carry all the weight:

  • each — no input in $D$ may be left without an output. That is what forces us to state the domain honestly.
  • exactly one — no input may produce two outputs. This is the graphical vertical line test: a vertical line may cross the graph at most once. A circle is not a function.
  • rule — it needn't be a formula. A table, a graph, or "the closing price on day $t$" are all functions.

Vocabulary you must be able to use precisely:

Domain $D$the set of legal inputs
Codomainthe set the outputs are drawn from (usually $\mathbb{R}$)
Range / imagethe outputs that are actually achieved: $\{f(x):x\in D\}$
Graphthe set of points $\{(x,f(x)):x\in D\}$ in the plane

Finding the natural domain

When a function is given by a formula with no domain stated, the natural domain is every $x$ for which the formula makes sense. In practice there are exactly three things that can go wrong, and you should scan for all three every time:

  1. Division by zero. Denominator $\ne 0$.
  2. Even root of a negative. Inside of $\sqrt{\ }$ must be $\ge 0$.
  3. Log of a non-positive number. Inside of $\ln$ must be $>0$ (strictly).
Domain of $f(x)=\dfrac{\ln(x-1)}{\sqrt{4-x}}$

Three conditions at once, then intersect:

  • $\ln(x-1)$ needs $x-1>0$, so $x>1$.
  • $\sqrt{4-x}$ needs $4-x\ge0$, so $x\le4$.
  • The square root sits in a denominator, so it must also be non-zero: $4-x\ne0$, i.e. $x\ne4$. This tightens the previous line to $x<4$.

Intersecting: $\;D=(1,4)$.

Trap
A root in the denominator has to satisfy both conditions — non-negative to be defined, and non-zero to be divided by. Stopping at $x\le4$ is the single most common domain error.

Even, odd, increasing, bounded

Four descriptive words that come up in questions and save work when they apply:

Even$f(-x)=f(x)$ — mirror-symmetric about the $y$-axis ($x^2$, $\cos x$)
Odd$f(-x)=-f(x)$ — rotationally symmetric about the origin ($x^3$, $\sin x$)
Increasing$x_1<x_2\Rightarrow f(x_1)<f(x_2)$ (strictly)
Bounded$|f(x)|\le M$ for some fixed $M$ and all $x\in D$

Check yourself: is $f(x)=x^3-x$ even, odd, or neither? (Answer: odd — $f(-x)=-x^3+x=-(x^3-x)$.)

FIGURE The standard library, and what the four transformations do— ⊡ ✕

Every function you meet in this course is one of a handful of basic shapes, possibly stretched and shifted. Learn the shapes once and you can sketch anything. The general transformed form is

$$g(x)=a\,f\big(b(x-c)\big)+d$$

and each of the four parameters does exactly one thing. Move the sliders and watch which one moves:

$a>1$stretch vertically; $0<a<1$ squash; $a<0$ flip upside down
$b>1$squeeze horizontally (faster); $b<0$ mirror left–right
$c$shift right by $c$ — note the minus sign inside
$d$shift up by $d$
Trap
Inside the bracket, everything is backwards: $f(x-3)$ moves the graph 3 to the right, and $f(2x)$ makes it narrower, not wider. The reason: to get the old output you now need a bigger $x$ to feed the bracket the old input.

Notice $\sqrt{x}$, $\ln x$ and $1/x$ have restricted domains — the curve simply stops. That is the domain of Idea 2 made visible.

IDEA 3 Composition and inverses— ⊡ ✕

Composition: functions in series

Feeding the output of one function into another gives the composite, written $(f\circ g)(x)=f(g(x))$ and read "f after g". Order matters enormously:

With $f(x)=x^2$ and $g(x)=x+1$: $\;f(g(x))=(x+1)^2$ but $g(f(x))=x^2+1$. Different functions.

The habit to build now, because the chain rule in module 5 depends entirely on it: given a messy function, identify the outer and inner parts.

$\sqrt{3x+1}$outer $\sqrt{\;}$, inner $3x+1$
$e^{-x^2}$outer $e^{\square}$, inner $-x^2$
$\ln(\cos x)$outer $\ln$, inner $\cos x$
$(\ln x)^3$outer $\square^3$, inner $\ln x$ — not the same as the line above

The domain of $f\circ g$ is the $x$ in the domain of $g$ whose output $g(x)$ is legal for $f$. Example: $\ln(\cos x)$ needs $\cos x>0$, not all of $\mathbb{R}$.

Inverse: running the machine backwards

The inverse $f^{-1}$ undoes $f$: $f^{-1}(f(x))=x$ and $f(f^{-1}(y))=y$. It exists only if $f$ never sends two different inputs to the same output — such an $f$ is called one-to-one, and graphically it passes the horizontal line test. Any strictly increasing (or strictly decreasing) function qualifies.

To find it: write $y=f(x)$, solve for $x$, then rename. For $f(x)=2x+3$: $y=2x+3\Rightarrow x=\tfrac{y-3}{2}$, so $f^{-1}(x)=\tfrac{x-3}{2}$.

Two facts worth carrying: the graph of $f^{-1}$ is the graph of $f$ reflected in the line $y=x$, and the domain and range swap roles.

Trap
$f^{-1}(x)$ means the inverse function; $f(x)^{-1}$ means $1/f(x)$. They are unrelated. Only $\sin^{-1}$, $\cos^{-1}$ etc. break this convention — and even there $\sin^2x$ means $(\sin x)^2$. Read carefully.

The pair you will use most: $e^x$ and $\ln x$ are inverses of each other. That single fact is why $e^{\ln u}=u$ and $\ln(e^u)=u$, which is how you will unpick almost every exponential equation.

Check yourself: decompose $h(x)=e^{\sqrt{x+1}}$ into three nested functions. (Answer: outer $e^{\square}$, then $\sqrt{\square}$, then $x+1$.)

TIP The algebra toolkit — know these cold— ⊡ ✕

Every rule below will be used without comment from module 4 onward. If any of them makes you hesitate, that hesitation will cost you marks under time pressure.

Powers

Product$x^a x^b=x^{a+b}$
Quotient$x^a/x^b=x^{a-b}$
Power of a power$(x^a)^b=x^{ab}$
Negative$x^{-a}=1/x^a$
Fractional$x^{1/n}=\sqrt[n]{x}$, so $x^{m/n}=\sqrt[n]{x^m}$
Zero$x^0=1$ (for $x\ne0$)

Rewriting roots and reciprocals as powers is the single most useful preparatory move before differentiating: $\dfrac{1}{\sqrt{x}}=x^{-1/2}$ is now a one-line power-rule job.

Exponentials and logarithms

Definition$y=\ln x \iff e^y=x$ (so $\ln$ is only defined for $x>0$)
Product$\ln(ab)=\ln a+\ln b$
Quotient$\ln(a/b)=\ln a-\ln b$
Power$\ln(a^b)=b\ln a$ — the rule that makes logs useful
Values$\ln 1=0$, $\ln e=1$, $e^0=1$
Base change$a^x=e^{x\ln a}$ — turns any exponential into base $e$
Trap
$\ln(a+b)\ne\ln a+\ln b$. There is no rule for the log of a sum. Likewise $e^{a+b}=e^ae^b$ (true) but $e^{ab}\ne e^ae^b$ (false). Sums inside logs and products inside exponents are where marks vanish.

Factoring patterns worth recognising instantly

Difference of squares$a^2-b^2=(a-b)(a+b)$
Perfect squares$a^2\pm2ab+b^2=(a\pm b)^2$
Difference of cubes$a^3-b^3=(a-b)(a^2+ab+b^2)$
Quadratic formula$x=\dfrac{-b\pm\sqrt{b^2-4ac}}{2a}$

Difference of squares is the workhorse of module 2: it is how you kill the $\tfrac00$ in limits like $\lim_{x\to2}\frac{x^2-4}{x-2}$ — factor to $(x-2)(x+2)$, cancel, done.

Finance link
$a^x=e^{x\ln a}$ is why continuously-compounded returns are natural: a growth factor of $(1+r)$ per year over $t$ years is $(1+r)^t=e^{t\ln(1+r)}$, and $\ln(1+r)$ is exactly the continuously-compounded ("log") return. Module 11 builds on this.

Check yourself: simplify $\ln(x^2)-2\ln x$ for $x>0$. (Answer: $2\ln x-2\ln x=0$.)
