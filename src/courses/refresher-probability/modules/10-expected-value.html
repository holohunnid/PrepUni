Expected value

lecture 4, slides 44–57 · the centre of gravity of a distribution
READ FIRST One number to summarise a whole distribution— ⊡ ✕

A probability distribution is a whole table or formula. Often you want a single number that says where it sits. That number is the expected value — a measure of centrality, computed ex ante, before any experiment is run. It tells you the "position of the probability distribution" of $X$.

Two readings, both correct and both worth carrying:

  • Weighted average. $E(X)$ averages the possible realisations of $X$, weighting each by its probability. Values that are more likely pull harder.
  • Long-run average. $E(X)$ is the mean value of $X$ we expect to obtain if the experiment were repeated a large number of times and the observations averaged.
$E(X)$ is a number, not a random quantity
Once you have the distribution, $E(X)$ is fixed and computable — there is nothing random left in it. Note also that the expected value need not be a value $X$ can actually take: a fair die has $E(X)=3.5$, which no face shows. "Expected" is a technical term, not a prediction.
DEF Expected value— ⊡ ✕

The expected value $E(X)$ of a discrete random variable $X$ is

$$\boxed{\;E(X)=\sum_x x\,P(X=x)=\sum_x x\,P(x)\;}\tag{5}$$

where the summation extends over all possible values that $X$ can take.

Example: typographical errors (slide 45)

$X$ is the number of typographical errors per page in business economics textbooks:

$x$012
$P(x)$0.810.170.02
$$E(X)=0\times0.81+1\times0.17+2\times0.02=0+0.17+0.04=0.21$$

So ex ante — before reading the books — we expect 0.21 typographical errors per page, or 21 errors every 100 pages. That rephrasing is the honest interpretation: no single page contains 0.21 errors.

The barycentre reading (slide 48)

By construction $E(X)$ is the barycentre (centre of gravity) of the probability distribution: imagine the probabilities as physical weights placed at the points $x$ on a rod; $E(X)$ is where the rod balances. An immediate consequence:

$$\min(X)\le E(X)\le\max(X)$$

The balance point cannot lie outside the range of the weights — a free sanity check on every computation.

For the loaded die of module 07:

$$E(X)=1(0.168)+2(0.360)+3(0.309)+4(0.132)+5(0.028)+6(0.002)=2.5$$

and indeed $\min(X)=1<2.5<6=\max(X)$ ✓. (A fair die would give 3.5; this die is pulled left by its heavy low faces.)

RULE Linearity — the property that does all the work— ⊡ ✕

The expected value is a linear operator. For random variables $X$ and $Y$:

$$E(X+Y)=E(X)+E(Y)$$

and more generally $E\left(\sum_{i=1}^n X_i\right)=\sum_{i=1}^n E(X_i)$. For any constants $a,b\in\mathbb{R}$:

$$\boxed{\;E(aX+bY)=a\,E(X)+b\,E(Y)\;}$$

and more generally $E\left(\sum_i a_iX_i\right)=\sum_i a_iE(X_i)$.

No independence required
This is the remarkable part, and it is what makes linearity so useful: $E(X+Y)=E(X)+E(Y)$ holds whatever the dependence between $X$ and $Y$. Contrast with variance in module 11, where a covariance term appears unless the variables are uncorrelated. Expected portfolio return is always the weighted average of expected returns; portfolio variance is never so simple.

Exercise (slides 53–54): $E(a+bX)=a+b\,E(X)$

Verify for any constants $a,b\in\mathbb{R}$ and any RV $X$.

  1. Start from the definition (5), applied to the random variable $a+bX$: $$E(a+bX)=\sum_i (a+bx_i)\,P(X=x_i)$$
  2. Expand the bracket inside the sum and split it in two: $$=\sum_i\Big(a\,P(X=x_i)+b\,x_i\,P(X=x_i)\Big)=\sum_i a\,P(X=x_i)+\sum_i b\,x_i\,P(X=x_i)$$
  3. Pull the constants out of each sum: $$=a\sum_i P(X=x_i)+b\sum_i x_i\,P(X=x_i)$$
  4. The first sum is 1 (property 2 of a probability distribution, module 07); the second is $E(X)$ by definition. Hence $$E(a+bX)=a+b\,E(X)\qquad\square$$

The two facts used — probabilities sum to 1, and constants factor out of sums — are the only ingredients in every linearity proof.

EXERCISE (slides 46–47) · expected value of a Bernoulli

Calculate $E(X)$ for a Bernoulli random variable, which takes the value 1 with probability $p$ and 0 with probability $1-p$.

  1. Apply definition (5) over the two possible values: $$E(X)=\sum_x x\,P(x)=1\cdot p+0\cdot(1-p)$$
  2. The second term vanishes, leaving $$\boxed{E(X)=p}$$
Insight
The expected value of a Bernoulli is its success probability. This tiny result is the bridge used repeatedly later: it is why $E[X]=np$ for a binomial, and why "1 out of 8 frogs on average" immediately gives $p=1/8$ in module 08.
EXERCISE (slides 50–51) · a three-valued RV and a function of it

$X$ takes only the values 1, 2 and 3, with $P(X=1)=1/3$ and $P(X=2)=1/6$. (1) Compute $E[X]$. (2) Let $Y=e^X$. Is $Y$ discrete or continuous? Compute $E[Y]$.

  1. Find the missing probability. The three probabilities must sum to 1: $$P(3)=1-P(1)-P(2)=1-\tfrac13-\tfrac16=1-\tfrac26-\tfrac16=\tfrac36=\tfrac12$$
  2. (1) Expected value, writing everything over 6: $$E[X]=1\cdot\tfrac26+2\cdot\tfrac16+3\cdot\tfrac36=\tfrac{2}{6}+\tfrac{2}{6}+\tfrac{9}{6}=\tfrac{13}{6}\approx2.1667$$ Check the barycentre bound: $1\le2.1667\le3$ ✓
  3. (2) Is $Y=e^X$ discrete? Yes — $Y$ is discrete. A function of a discrete random variable is discrete: $Y$ can take only the three values $e^1$, $e^2$, $e^3$, and it takes each one exactly when $X$ takes the corresponding value. The values are irrational numbers, but there are only three of them, which is what "discrete" is about.
  4. Compute $E[Y]$. The probabilities carry over unchanged from $X$ to $Y$: $$E[Y]=E[e^X]=e^1\cdot\tfrac26+e^2\cdot\tfrac16+e^3\cdot\tfrac36\approx0.9061+1.2313+10.0428\approx12.18$$
The trap this exercise sets
$E[e^X]\neq e^{E[X]}$. Here $e^{E[X]}=e^{13/6}\approx8.74$, well below the correct $12.18$. The expected value of a function is not the function of the expected value — linearity holds for linear functions only. (For a convex function like $e^x$ the inequality always runs one way, $E[g(X)]\ge g(E[X])$; that is Jensen's inequality, and it is why volatility raises the expected value of a convex payoff.)
RESULTS Expected value of the named distributions— ⊡ ✕

Binomial (slide 55)

Recall from module 08 that a binomial $X$ is the sum of $n$ independent Bernoulli variables, $X=\sum_{i=1}^nX_i$. Linearity makes this a one-line calculation — no sums over binomial coefficients needed:

$$E(X)=E\left(\sum_{i=1}^{n}X_i\right)=E(X_1)+\dots+E(X_n)=\underbrace{p+\dots+p}_{n\text{ terms}}=\boxed{np}$$

The direct route from the definition gives the same answer with far more effort:

$$E(X)=\sum_{x=0}^{n}x\binom{n}{x}p^x(1-p)^{n-x}=np$$

This is a good illustration of why decompositions matter: recognising $X$ as a sum turned an awkward series into three symbols.

Sanity checks. $n=800$ chips at $p=0.001$ gives $E(X)=0.8$ expected defectives — consistent with a lot that passes 99% of the time (module 08). $n=9$ men at $p=0.08$ gives $0.72$ expected colorblind men, so needing three is indeed a tail event.

Poisson (slide 56)

For $X\sim Po(\lambda)$ with $P(x)=e^{-\lambda}\lambda^x/x!$:

$$E(X)=\sum_x x\,P(x)=\sum_{x=0}^{\infty}x\,\frac{e^{-\lambda}\lambda^x}{x!}=\boxed{\lambda}$$

Why it comes out to $\lambda$: the $x=0$ term contributes nothing; for $x\ge1$ cancel one factor, $x/x!=1/(x-1)!$, and substitute $j=x-1$:

$$\sum_{x=1}^{\infty}\frac{e^{-\lambda}\lambda^x}{(x-1)!}=\lambda e^{-\lambda}\sum_{j=0}^{\infty}\frac{\lambda^{j}}{j!}=\lambda e^{-\lambda}e^{\lambda}=\lambda$$

So $E(X)=\lambda$ is the expected number of events per unit of time — which is exactly the interpretation used to fit $\lambda=93/100$ in the earthquakes exercise and $\lambda=1000\times0.005$ in the vaccine exercise (module 09). Note also the consistency with the binomial approximation: if $Bin(n,p)\approx Po(np)$, the means must agree, and $np=\lambda$ ✓

KEY Deviations from the expected value sum to zero— ⊡ ✕

Write $\mu:=E(X)=\sum_x x\,P(x)$. Then the deviations of $X$ from its own expected value have expectation zero:

$$\boxed{\;E\big(X-E(X)\big)=E(X-\mu)=0\;}$$

Proof. Expand using the definition, remembering that $\mu$ is a constant:

$$E(X-\mu)=\sum_x(x-\mu)P(x)=\sum_x x\,P(x)-\mu\sum_x P(x)=\mu-\mu\cdot1=0\qquad\square$$

The two ingredients are again $\sum_x P(x)=1$ and the fact that constants factor out.

In this precise sense $E(X)$ is a measure of centrality: it is the unique point about which the probability-weighted deviations cancel exactly. Values above the mean and values below it balance out.

Why module 11 has to square the deviations
Because they sum to zero, raw deviations are useless as a measure of spread — a tight distribution and a wildly dispersed one both give exactly 0. The fix is to remove the signs before averaging, and squaring is the standard way to do it. That is precisely the definition of variance: $$V(X)=E\big[(X-\mu)^2\big]$$ The zero result above is not a curiosity; it is the reason variance is defined the way it is.
