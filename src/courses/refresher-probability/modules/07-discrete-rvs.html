Discrete random variables

lecture 4, slides 3–15 · attaching numbers to outcomes, and the two functions that describe them
READ FIRST From events to numbers— ⊡ ✕

Lectures 1–3 dealt with events — subsets of a sample space — and their probabilities. That is enough to answer yes/no questions, but not to compute an average, a variance, or a portfolio return. For those you need numbers attached to the outcomes, and that is what a random variable is.

A Random Variable (RV) $X$ is a variable whose possible values $x$ are numerical outcomes associated with a random experiment. Which value $X$ takes depends on the realised outcome of the experiment.

Rolling a die, $X=$ the face value doubledpossible values $2,4,6,8,10,12$; if the die shows 3, the realisation is $x=6$
$X=$ the return of a risky assetthe "experiment" is the state of the economy; possible values range from $-100\%$ upward, e.g. $x=-20\%$ or $x=1.5\%$
Capital versus lower case — keep this straight
$X$ (capital) is the random variable: the whole mechanism, before you look. $x$ (lower case) is a realisation: one particular number it might take. $P(X=x)$ therefore reads "the probability that the mechanism produces the specific value $x$" — and it is a legitimate probability because $\{X=x\}$ is an event, i.e. the set of outcomes that make $X$ equal $x$. DEF Discrete random variable and its probability distribution— ⊡ ✕

There are two kinds of random variable, discrete and continuous. This lecture handles the discrete case; module 12 does the continuous one.

A discrete random variable $X$ is one which may take only a finite number or a countable number of distinct values.

  • Finite: tossing a coin, $X=1$ if head and $X=0$ if tail. Two values.
  • Countable: the number of customers arriving at a service desk, $X\in\{0,1,2,3,4,\dots\}$. Infinitely many values, but you can list them one after another.

The probability distribution

The probability distribution of a discrete RV lists all possible values $x$ together with their probabilities:

$$\boxed{\;P(x):=P(X=x)\quad\text{for each value }x\;}$$
A subtle but useful point
$P(x)$ exists for every numeric value $x$, not only for the values $X$ can actually take. The probability of a value $X$ does not take is simply 0. So $P(X=1.5)=0$ for a die — that is a genuine, well-defined answer, not an error.

Two characterising properties

A function $P$ is a probability distribution if and only if:

$$\text{1)}\quad 0\le P(X=x)\le1\ \text{ for every }x,\qquad\qquad \text{2)}\quad \sum_{x}P(X=x)=1$$

where $\sum_x$ runs over all possible realisations of $X$. Property 1 is Axiom 1; property 2 is Axiom 3 combined with the fact that the events $\{X=x\}$ are mutually exclusive and collectively exhaustive — they form a partition of the sample space (module 02).

If a proposed function fails even one of these two properties, it is not a probability distribution. Checking them is the first thing to do with any table you are handed.

EX The special (loaded) die— ⊡ ✕

The running example of lecture 4. A loaded die has the distribution

$x$123456
$P(x)$0.1680.3600.3090.1320.0280.002

Before rolling — ex ante — the probability of getting a 6 is $P(X=6)=0.002$. A fair die would give $P(X=6)=1/6\approx0.167$, and $P(x)=1/6$ for every face; this die is heavily biased towards low numbers.

The two questions on slide 7:

  1. $P(X=1.5)=?$  →  0. The value 1.5 is not among the faces, so the event $\{X=1.5\}$ is impossible. The distribution is still defined there; it is simply zero.
  2. $P(1)+P(2)+P(3)+P(4)+P(5)+P(6)=?$  →  1, by characterising property 2. Check: $0.168+0.360+0.309+0.132+0.028+0.002=0.999+0.001=1.000$ ✓

And the question on slide 8 — how would the distribution look if the die were fair? — has the answer: six bars of exactly equal height $1/6\approx0.167$, a flat profile, instead of the strongly right-skewed one above.

EXERCISE (slides 11–12) · rolling two fair dice

Let $T$ be the sum of the roll of two dice, and define the random variable

$$X=\begin{cases}1,&\text{if }T\le5\\ 4,&\text{if }6\le T\le10\\ 10,&\text{if }T>10\end{cases}$$

Calculate the probability of each possible realisation of $X$, i.e. for $x=1,4,10$.

  1. The sample space. Two dice, each with 6 faces, and the pair is ordered: $$S=\{(1,1),(1,2),(1,3),\dots,(6,6)\},\qquad 6\times6=36\text{ equally likely elementary events}$$
  2. $X=1$ means $T\le5$. Count the ordered pairs summing to 2, 3, 4 or 5: $$(1,1);\;(1,2),(2,1);\;(1,3),(2,2),(3,1);\;(1,4),(2,3),(3,2),(4,1)$$ that is $1+2+3+4=10$ pairs, so $$P(X=1)=\frac{10}{36}$$
  3. $X=10$ means $T>10$, i.e. $T=11$ or $T=12$: $$(5,6),(6,5);\;(6,6)\qquad\Rightarrow\qquad 3\text{ pairs},\qquad P(X=10)=\frac{3}{36}$$
  4. $X=4$ is everything left over. Either count the 23 pairs with $6\le T\le10$ directly, or use the fact that the three events partition $S$: $$P(X=4)=1-\frac{10}{36}-\frac{3}{36}=\frac{23}{36}$$
  5. Check property 2: $\frac{10}{36}+\frac{23}{36}+\frac{3}{36}=\frac{36}{36}=1$ ✓
Insight
Two things worth extracting. First, a random variable can be built on top of another one ($X$ is a function of $T$, which is itself a function of the dice) — perfectly legitimate, and how most quantities in finance are defined. Second, the values $1,4,10$ are arbitrary labels chosen by whoever defined $X$; the probabilities come from counting outcomes, not from the labels. Using the complement to get the middle case, as in step 4, is nearly always faster than counting 23 pairs by hand.
DEF The cumulative distribution function— ⊡ ✕

The cumulative distribution function (CDF) $F(x_0)$ of a random variable $X$ expresses the probability that the realisation of $X$ is smaller than or equal to $x_0$:

$$\boxed{\;F(x_0)=P(X\le x_0)\;}\tag{1}$$

Since the event $\{X\le x_0\}$ is the union of all the mutually exclusive elementary events $\{X=x\}$ with $x\le x_0$, Axiom 2 gives

$$F(x_0)=P(X\le x_0)=\sum_{x\le x_0}P(X=x)$$

You accumulate the probability mass from the left. As with $P(x)$, the function $F(x_0)$ exists for every value $x_0$, not just for the values $X$ can take.

The loaded die again

$x$0123456
$P(x)$00.1680.3600.3090.1320.0280.002
$F(x)$00.1680.5280.8370.9690.9981.000

Each $F$ entry is the running total of the $P$ entries to its left: $0.168+0.360=0.528$, then $+0.309=0.837$, and so on up to 1.

The three questions on slide 14:

  1. $F(2.3)=P(X\le2.3)$. The values of $X$ that are $\le2.3$ are 1 and 2, so $F(2.3)=0.168+0.360=\mathbf{0.528}$ — the same as $F(2)$. Between two possible values the CDF is flat.
  2. $F(3)=P(X\le3)=\mathbf{0.837}$. Note the $\le$: the value 3 itself is included, which is why the CDF of a discrete RV jumps at 3 and is drawn with a filled dot there.
  3. $F(-1)=P(X\le-1)=\mathbf{0}$. No possible value is below $-1$, so nothing has accumulated yet.

Two characterising properties

The two properties of $P$ induce two properties of $F$:

$$\text{1)}\quad 0\le F(x)\le1\ \text{ for every }x,\qquad\qquad \text{2)}\quad F\text{ is nondecreasing: } x_1<x_2\Rightarrow F(x_1)\le F(x_2)$$

Property 2 holds because moving right can only add more (non-negative) probability mass. The lecture's advice is good: remember the shape — a staircase starting at 0 on the far left and rising to 1 on the far right — and the two properties follow from the picture.

Why the CDF earns its keep
Three reasons, all used later. It answers range questions in one subtraction, $P(a<X\le b)=F(b)-F(a)$ (module 12). It is the only description that works identically for discrete and continuous variables — $P(x)$ is meaningless in the continuous case, but $F(x)=P(X\le x)$ always makes sense. And it is what statistical software actually computes: R's pbinom, ppois, pnorm are all CDFs, which is why the exercises in modules 08–13 keep reaching for them.
