The discrete family: a map

lecture 3, notes p.4–8 · read this before modules 19–21
READ FIRST What happened in the second half of lecture 3— ⊡ ✕

Until now, every random variable was built by hand: write $\Omega$, work out which outcomes give which value, add up their probabilities (modules 12–15). That works, but it is slow — and the same situations keep coming back: count the heads in $n$ flips, count the calls in an hour, wait for the first success.

The second half of lecture 3 is a catalogue of those recurring situations. For each one, the pmf has been worked out once and for all, as a formula with one or two knobs — the parameters. Such a ready-made pmf is called a special (or named) distribution. In an exercise you no longer list $\Omega$: you recognise the story, pick the distribution, plug in the parameters.

The notation you will see everywhere

$$X\sim\text{Bin}(n,p)$$

reads "$X$ is distributed as a binomial with parameters $n$ and $p$". The symbol $\sim$ means "has the distribution". Change the parameters and you get a different member of the same family: $\text{Bin}(10,\tfrac16)$ and $\text{Bin}(3,\tfrac12)$ are both binomials, with different pmfs.

WORDS Four words the lecture uses without stopping— ⊡ ✕
  • Trial (Bernoulli trial): one repetition of an experiment with two outcomes — flip a coin, roll a die and ask "six or not?", check whether a loan defaults.
  • Success / failure: just labels for the two outcomes. "Success" is the outcome you are counting — it can be a default or a crash. Coded 1 (success) and 0 (failure).
  • Parameter: a fixed number that picks one member of the family — $p$ (success probability), $n$ (number of trials), $\lambda$ (average count). Parameters are not random; $X$ is.
  • Independent trials (module 09): the outcome of one trial tells you nothing about the others. Binomial and geometric both need it, and it is what lets us multiply probabilities along a sequence.

What's fixed, what's random
In the binomial the number of trials is fixed ($n$) and the number of successes is random. In the geometric it is the other way round: the number of successes is fixed (one) and the number of trials is random. Keep that sentence and you will never mix them up.

CARDS Each distribution in plain words— ⊡ ✕

One card per distribution. Every card answers the same questions, so you can compare them line by line: what is the story, what does $X$ count, what do the parameters mean, which values can $X$ take, the pmf, its picture, mean and variance, the lecture's example, and the R command. Modules 19–21 derive everything on these cards.

1 Bernoulli$(p)$ — one yes/no trial— ⊡ ✕

Story. A single trial that succeeds with probability $p$.

X is 1 if it succeeds, 0 if it fails. Parameter $p\in[0,1]$: the success probability. Values $\{0,1\}$.

$$f(x)=p^x(1-p)^{1-x}$$

the notes' one-line form: $x=1$ gives $p$, $x=0$ gives $1-p$

$\mathbb E(X)=p$, $\ \mathbb V(X)=p(1-p)$. Example: one coin flip; "does tomorrow's loss exceed the VaR?" R: dbinom(x, 1, p) (a binomial with $n=1$).

2 Binomial$(n,p)$ — successes in $n$ trials— ⊡ ✕

Story. $n$ independent trials, each with the same success probability $p$.

X counts the successes. Parameters $n$ = number of trials (fixed in advance), $p$ = success probability. Values $\{0,1,\dots,n\}$.

$$f(k)=\binom nk p^k(1-p)^{n-k}$$

$p^k(1-p)^{n-k}$: one particular order with $k$ successes; $\binom nk$: how many such orders

$\mathbb E(X)=np$, $\ \mathbb V(X)=np(1-p)$. Example: sixes in 10 rolls of a die, $P(X=5)=0.013$. R: dbinom(k, n, p), pbinom(k, n, p).

3 Poisson$(\lambda)$ — events in a window of time— ⊡ ✕

Story. Events that can happen at any moment (calls, claims, defaults, accidents), independently, at a steady average rate. Count them over a fixed window of time (or space).

X counts the events in the window. Parameter $\lambda>0$: the average number of events in that window (the "intensity"). Values $\{0,1,2,\dots\}$ — no upper limit.

$$f(k)=e^{-\lambda}\frac{\lambda^k}{k!}$$

no $n$, no $p$: only the average $\lambda$ is needed

$\mathbb E(X)=\lambda=\mathbb V(X)$. Example: 5 calls/hour ⇒ $\lambda=\tfrac56$ in a 10-minute break; $P(\text{at least one call})=1-e^{-5/6}=0.5654$. R: dpois(k, lambda), ppois(k, lambda).

4 Discrete uniform$(a,b)$ — all equally likely— ⊡ ✕

Story. Pick an integer from $a$ to $b$ with no favourites: a fair die, a random digit, a lottery ball.

X is the number picked. Parameters $a\le b$: the smallest and largest value. Values $\{a,a+1,\dots,b\}$ — there are $b-a+1$ of them.

$$f(k)=\frac{1}{b-a+1}$$

the same for every $k$: it does not depend on $k$

$\mathbb E(X)=\frac{a+b}{2}$ (the midpoint), $\ \mathbb V(X)=\frac{(b-a+1)^2-1}{12}$. Example: a fair die, DUnif$(1,6)$: $\mathbb E=3.5$, $\mathbb V=\tfrac{35}{12}$. R: no d-function needed — $f$ is just 1/(b-a+1); simulate with sample(a:b, 1).

5 Geometric$(p)$, version I — trials until the first success— ⊡ ✕

Story. Repeat independent trials (success prob. $p$) until the first success, then stop. The number of trials is not fixed — it is the random thing.

X counts the trials needed, including the successful one. Parameter $p$. Values $\{1,2,3,\dots\}$.

$$f(k)=(1-p)^{k-1}\,p$$

$k-1$ failures in a row, then a success

$\mathbb E(X)=\frac1p$ — the higher $p$, the fewer trials you need (a six takes 6 rolls on average); $\ \mathbb V(X)=\frac{1-p}{p^2}$. Example: module 15's $f(k)=\tfrac15(\tfrac45)^{k-1}$ is Geometric I with $p=\tfrac15$. R: dgeom(k - 1, p) — note the $-1$.

6 Geometric$(p)$, version II — failures before the first success— ⊡ ✕

Story. The same waiting game, but you do not count the successful trial — only the failures before it.

X counts the failures before the first success. Parameter $p$. Values $\{0,1,2,\dots\}$ — zero if the very first trial succeeds.

$$f(k)=(1-p)^{k}\,p$$

$k$ failures, then a success

Same shape, shifted one step left: $X_{II}=X_{I}-1$. So $\mathbb E(X)=\frac{1-p}{p}=\frac1p-1$ and $\ \mathbb V(X)=\frac{1-p}{p^2}$ (a shift does not change the variance — module 17). Example: draws before the first ace, $P(X=2)=0.0655$. R: dgeom(k, p) — R uses this version.

GUIDE Which distribution is it? Ask these questions in order— ⊡ ✕

The checks that trip people up

  • Binomial needs all three: a fixed $n$, the same $p$ on every trial, and independence. Drawing cards without replacement breaks it — $p$ changes after each draw.
  • Binomial vs geometric: is the number of trials given in the question? Then binomial. Is it what you are asked about? Then geometric.
  • Binomial vs Poisson: is there a maximum possible count $n$? Binomial. Is there no natural maximum and only an average rate? Poisson. (With huge $n$ and tiny $p$ both work — module 20.)
  • Poisson's $\lambda$ must match the window. "5 calls per hour" and a 10-minute window give $\lambda=5\cdot\tfrac{10}{60}=\tfrac56$, not 5.
  • Geometric I or II? Read whether the successful trial is counted. "How many rolls until the first six" (I) vs "how many failures before" (II).
Three classic slips
1. Writing $\mathbb E(X)=p$ for a binomial: it is $np$ — $p$ is the mean of one trial. 2. Confusing $k$ (the value asked about) with $n$ (the number of trials). 3. Using R's dgeom(k, p) for version I — it computes version II.
DRILL Name that distribution— ⊡ ✕

Recognising the story is most of the work in an exam question. Click an answer; the first click counts (the score is shown in module 27).

D1A trader makes 20 independent trades; each is profitable with probability 0.55. $X$ = number of profitable trades.
Fixed number of independent trials (20), same $p$, counting successes: binomial. $\mathbb E(X)=20\cdot0.55=11$.
D2E-mails arrive at 12 per hour on average. $X$ = number of e-mails in the next 15 minutes.
Events in a time window with only an average rate: Poisson, with $\lambda$ for that window: $12\cdot\tfrac{15}{60}=3$.
D3A player shoots until she scores; each shot scores with probability 0.4. $X$ = number of shots taken.
Waiting for the first success, counting all shots including the scoring one: version I, $\mathbb E=1/0.4=2.5$.
D4$X=1$ if tomorrow's return is positive, $X=0$ otherwise.
One yes/no trial. (It would be DUniform(0,1) only if $p=\tfrac12$ exactly — Bernoulli is the general answer.)
D5A fair coin is tossed until the first head. $X$ = number of tails before that head. $P(X=0)$ is
Geometric II with $p=\tfrac12$: $f(0)=(1-p)^0p=\tfrac12$ — zero tails means the first toss is already a head.
D61,000 loans, each defaulting independently with probability 0.002. $X$ = number of defaults. The easiest accurate model is
Exactly it is Binomial(1000, 0.002) — but $n$ is huge and $p$ tiny, so Poisson with $\lambda=np=2$ is almost identical and much easier (module 20).
D75 cards are drawn without replacement from a deck; $X$ = number of aces. Is $X$ binomial with $n=5$, $p=\tfrac4{52}$?
After an ace is drawn, the chance of another ace drops ($\tfrac3{51}$): same-$p$ and independence both fail. (The correct model, the hypergeometric, is not on this course's list.)
D8$X\sim\text{Bin}(10,\tfrac16)$. Which statement is true?
$\mathbb E=np=\tfrac{10}6\approx1.67$; the values are $0,1,\dots,10$ — eleven of them. $\mathbb V=np(1-p)\neq np$ (equal mean and variance is the Poisson's fingerprint).
