Continuous RVs & the pdf

slides: Continuous Random Variables 2–11 · ahead of the lecture notes
READ FIRST The question this module answers— ⊡ ✕

Some random quantities can land anywhere in an interval: a waiting time, tomorrow's return, a random point in $(0,1)$. In module 06 you saw the problem this creates. A single point has length 0, so $P(X=x)=0$ for every $x$. A pmf "$f(x)=P(X=x)$" (module 15) would be 0 everywhere and would tell you nothing.

This module answers: what replaces the pmf when every single value has probability 0? The answer is the probability density function (pdf). It is a curve $f$ whose area over an interval is the probability of that interval:

$$P(a\le X\le b)=\int_a^b f(x)\,dx=\text{area under }f\text{ between }a\text{ and }b.$$

You already know two special cases. In module 06 the random point in $(0,1)$ had "probability = length". That is the density $f(x)=1$ on $(0,1)$, because the area of a rectangle of height 1 is its width. In module 14, $X=-\ln U$ had cdf $1-e^{-t}$. Here you will meet its big brother $5e^{-5x}$ and see where its density comes from.

Plan: why we want a continuous cdf (slides 2–3) → the definition (slide 4) → the key warning that a density is not a probability → every property, including $P(X=a)=0$ and $F'=f$ (slides 5–7) → two fully worked examples, uniform on $(1,5)$ and $5e^{-5x}$ (slides 8–11).

The one picture to keep
Probability is area under the density, never its height. Every formula in this module is this sentence written in calculus: totals are areas (they must equal 1), cdfs are areas to the left, a single point has zero area, and the density is how fast the area accumulates.
IDEA The cdf again, and two very different shapes (slides 2–3)— ⊡ ✕

Slide 2 recalls the tool from module 13. The cumulative distribution function (cdf) of a random variable $X$ is

$$F(t)=P(X\le t)$$

(see the TRAP below about the slide's "$<$"). It is defined in the same way for discrete and for continuous random variables, and the cdf completely defines a random variable: two variables with the same cdf have the same distribution. So a good way to see the difference between "discrete" and "continuous" is to look at the shape of $F$.

EXAMPLE 1 (slide 3) · Bernoulli(0.6): a tiny step in t, a big jump in F

Assume $X\sim\text{Bernoulli}(0.6)$. Show that a very small change in $t$ can cause a large change in $F(t)$.

  1. Name things. $X$ takes the value 1 with probability $p=0.6$ and 0 with probability $q=1-p=0.4$ (the Bernoulli of module 19).
  2. Write the cdf by adding up the pmf over the values $\le t$ (module 13): $$F(t)=P(X\le t)=\begin{cases}0 & t<0\\ 0.4 & 0\le t<1\\ 1 & t\ge1\end{cases}$$
  3. Just below 1. At $t=0.99999$ only the value 0 is $\le t$, so $F(0.99999)=P(X=0)=0.4$.
  4. Just above 1. At $t=1.00001$ both values are $\le t$, so $F(1.00001)=0.4+0.6=1$.
  5. Compare. $t$ moved by $0.00002$ and $F$ moved by $0.6$. The size of the jump is exactly $P(X=1)=0.6$.
Insight
Every discrete random variable has a staircase cdf, with a jump at each possible value whose height is the pmf there. For many applications this is not a desired characteristic. A price or a waiting time measured a hair differently should not make a probability jump by 0.6. We would prefer a continuous cdf.
EXAMPLE 2 (slide 3) · a random point in (0,1): F is continuous

Let $X$ be a number drawn randomly from the interval $(0,1)$. Find its cdf and check that small changes in $t$ cause only small changes in $F$.

  1. Use module 06. For a random point, probability = length. For $0\le t\le1$ the event $\{X\le t\}$ is the piece $(0,t]$, of length $t$. So $F(t)=t$.
  2. Below the interval. If $t<0$ no part of $(0,1)$ lies below $t$, so $F(t)=0$.
  3. Above the interval. If $t>1$ the whole interval lies below $t$, so $F(t)=1$. Together: $$F(t)=\begin{cases}0 & t<0\\ t & 0\le t\le1\\ 1 & t>1\end{cases}$$
  4. Same test as Example 1. $F(0.99999)=0.99999$ and $F(1.00001)=1$. $t$ moved by $0.00002$, and $F$ moved by only $0.00001$.
Insight
No jumps anywhere. Since the jump of $F$ at $t$ is $P(X=t)$ (module 13), a cdf without jumps means that every single value has probability 0. This is the defining feature of the continuous random variables in this module.
TRAP Slide 2 writes $F(t)=P(X<t)$ with a strict inequality— ⊡ ✕

Slide 2 defines $F(t):=P(X<t)$. Every other slide of the deck (6, 7 and 11), the lecture notes, module 13 and R all use $F(t)=P(X\le t)$. Use $\le$ everywhere. Does it matter?

  • Continuous $X$: no difference. $P(X\le t)=P(X<t)+P(X=t)=P(X<t)+0$. The two definitions give the same function.
  • Discrete $X$: they differ exactly at the jumps. For the Bernoulli(0.6) of Example 1, $P(X\le1)=1$ but $P(X<1)=0.4$. Likewise $P(X\le0)=0.4$ but $P(X<0)=0$. Slide 3's own figure uses $\le$: the filled dot at $t=1$ sits at height 1.
Exam habit
For a discrete variable, read the inequality in the question letter by letter. "At most 3" is $\le3$ and "fewer than 3" is $<3=\le2$. R's pbinom(q, …), ppois(q, …) etc. always return $P(X\le q)$. For a continuous variable, relax: $<$ and $\le$ are interchangeable.
DEF Continuous random variable and its pdf (slide 4)— ⊡ ✕

Let $X$ be a random variable. $X$ is called a continuous random variable if there exists a non-negative function $f:\mathbb{R}\to[0,+\infty)$ such that for any interval $A$:

$$\boxed{\;P(X\in A)=\int_A f(x)\,dx\;}$$

$f$ is called the probability density function (pdf) of the random variable $X$. (Footnote on the slide: in this chapter the terms continuous and absolutely continuous are used interchangeably.)

Reading the definition

  • "non-negative function": $f(x)\ge0$ for every $x$, because an area built from negative heights would be a negative probability.
  • "for any interval $A$": one function $f$ answers every question of the form "what is the probability that $X$ lands in $A$?" You integrate $f$ over $A$, which means you take the area under $f$ above $A$.
  • Why "density"? Think of a metal rod whose mass is spread unevenly. Its density (kg per metre) is not a mass. The mass of a piece is density × length where the density is constant, and the integral of the density otherwise. Likewise $f$ is probability per unit length, and probability is density integrated over length.

You have met two densities already

  • Module 06's random point in $(0,1)$: $P(X\in A)=\text{length of }A=\int_A 1\,dx$. So its density is $f(x)=1$ on $(0,1)$ and $0$ elsewhere.
  • Module 13's lecture cdf $F(t)=0.5+0.5t$ on $[-1,1]$ rises at constant rate $0.5$. Its density is $f(x)=0.5$ on $[-1,1]$, a rectangle of width 2 and height 0.5, so area 1.

About the footnote: there exist exotic random variables with a continuous cdf but no density at all. That is why mathematicians say "absolutely continuous" for "has a density". In this course the two words mean the same thing: continuous = has a pdf.

IDEA A density is NOT a probability— ⊡ ✕

$f(x)$ is a height. Probabilities are areas. Nothing forces the height to be at most 1. Only the total area is capped, at exactly 1.

What the height does mean. Over a short interval of width $h$ the area is roughly a rectangle, so

$$P(x\le X\le x+h)\approx f(x)\cdot h.$$

For $5e^{-5x}$ with $x=0$, $h=0.02$ the exact area is $1-e^{-0.1}=0.0952$ (using the cdf of slide 11), close to $5\times0.02=0.1$. So $f(x)$ compares how likely values near different points are. Since $f(0)=5$ and $f(0.5)=5e^{-2.5}\approx0.41$, values near 0 are about $e^{2.5}\approx12$ times as likely as values near 0.5.

TRAP · "f(x) ≤ 1 because it is a probability"
Wrong on both counts: $f(x)$ is not a probability and can be 5 or 5000. The only requirements are $f\ge0$ and total area 1. Conversely, even where $f(x)=5$, the probability of hitting that exact value is $P(X=x)=0$.
RULES Properties of the pdf (slides 5–7)— ⊡ ✕

Assume $X$ is a continuous random variable with pdf $f(x)$. The following are direct consequences of the definition. Each one is an "area" statement.

  1. Non-negative (slide 5). $f(x)\ge0$ for all $x\in\mathbb{R}$. The curve never dips below the axis.
  2. Total area 1: the normalization rule for continuous random variables (slides 5, 7). $$\int_{-\infty}^{+\infty}f(x)\,dx=P(X\in(-\infty,+\infty))=1.$$ $X$ must land somewhere on the real line, and $P(\Omega)=1$ by the axioms (module 04). This is the continuous twin of "the pmf sums to 1", and it is how you find an unknown constant in a density (slide 8).
  3. The cdf is the area to the left (slides 6–7). $$F(t)=P(X\le t)=P(X\in(-\infty,t])=\int_{-\infty}^{t}f(x)\,dx.$$
  4. A single point has probability 0 (slide 7). $$P(X=a)=P(X\in[a,a])=\int_a^a f(x)\,dx=0.$$ The "interval" $[a,a]$ has width 0, so the area above it is 0, however tall $f$ is at $a$.
  5. Endpoints do not matter (slides 6–7). Because of property 4, adding or removing an endpoint changes nothing: $$P(a\le X\le b)=P(a<X\le b)=P(a\le X<b)=P(a<X<b)=\int_a^b f(x)\,dx.$$ Combined with property 3 this gives the formula you will use most: $$\boxed{\;P(a\le X\le b)=\int_a^b f(x)\,dx=F(b)-F(a)\;}$$
  6. The density is the derivative of the cdf (slide 7). $$\frac{dF(x)}{dx}=f(x).$$ See the "slope" panel below.

RULE $dF/dx=f$: the density is the slope of the cdf— ⊡ ✕

Why it holds. Move $t$ a little to the right, to $t+h$. The cdf grows by the area of the thin strip between $t$ and $t+h$:

$$F(t+h)-F(t)=P(t<X\le t+h)=\int_t^{t+h}f(x)\,dx\approx f(t)\cdot h.$$

Divide by $h$:

$$\frac{F(t+h)-F(t)}{h}\approx f(t),$$

and let $h\to0$. The left side becomes $F'(t)$. This is the fundamental theorem of calculus: integrating $f$ gives $F$, differentiating $F$ gives back $f$.

The picture. Where the density is high, area piles up fast and the cdf climbs steeply. Where the density is near 0, the cdf is almost flat. A flat cdf means no probability there.

Use it both ways. Given $f$, integrate to get $F$ (slides 9, 11). Given $F$, differentiate to get $f$. In module 14, $F(t)=1-e^{-t}$ for $t\ge0$ gives $f(t)=e^{-t}$.

Small print: at a point where $f$ jumps (at 1 and 5 for the uniform on $(1,5)$, at 0 for $5e^{-5x}$) the cdf has a corner and no derivative. The value of $f$ at such a single point is irrelevant, because changing a height at one point changes no area. That is why writing $x\in(1,5)$ or $x\in[1,5]$ in a density makes no difference.

TRY IT Area up to $t$ and slope at $t$, for five distributions— ⊡ ✕

What to try.

  • U(1,5): F(3). Half of the rectangle is shaded, so $F(3)=0.5$. The tangent has slope $0.25$ at every $t$ in $(1,5)$: a flat density gives a straight-line cdf. Drag $t$ below 1 or above 5 and the slope drops to 0.
  • exp: F(0.2). The readout shows $F(0.2)=1-e^{-1}\approx0.632$ and $f(0.2)=5e^{-1}\approx1.84$. Now drag $t$ down to 0. The density is highest there ($f=5$), and the cdf is steepest there.
  • 3x²: F(0.5). $F(0.5)=0.5^3=0.125$ and $f(0.5)=0.75$. Only 12.5% of the area lies left of the midpoint, because the mass is piled on the right. Module 23 finds the balance point of this density.
  • standard normal. Put $t=0$: $F(0)=0.5$ by symmetry, and the tangent is steepest there, with slope $f(0)\approx0.399$.
  • Bernoulli: the jump. The discrete contrast. The cdf is a staircase, with a jump of 0.6 at $t=1$ and flat pieces elsewhere. There is no density whose area gives probabilities. The probability sits in the jumps, not in any slope.
EXAMPLE (slides 8–9) · continuous uniform on (1,5): find c, then the cdf

Let $X$ be a continuous r.v. with pdf $$f(x)=\begin{cases}c & x\in(1,5)\\ 0 & \text{otherwise}\end{cases}$$ where $c$ is a fixed positive constant. Find $c$, then the cdf of $X$.

  1. Normalization rule. The total area must be 1: $$\int_{-\infty}^{+\infty}f(x)\,dx=1.$$ Since $f=0$ outside $(1,5)$, only $(1,5)$ contributes: $\int_1^5 f(x)\,dx=1$.
  2. Integrate the constant. $$\int_1^5 c\,dx=c\cdot(5-1)=4c=1\;\Rightarrow\;\boxed{c=0.25}$$ Geometrically this is a rectangle of width 4 and height $c$, whose area must be 1.
  3. cdf for $t\le1$. No area yet: $$F(t)=\int_{-\infty}^t 0\,dx=0.$$
  4. cdf for $1<t<5$. Split at 1, where $f$ changes formula: $$F(t)=\int_{-\infty}^{1}0\,dx+\int_1^t0.25\,dx=0+0.25(t-1)=\frac{t-1}{4}.$$
  5. cdf for $t\ge5$. All the area is to the left of $t$: $$F(t)=\int_{-\infty}^{t}f(x)\,dx=\int_1^5 f(x)\,dx=\int_1^5 0.25\,dx=1.$$
  6. Checks. The pieces join up: $\frac{1-1}{4}=0$ at $t=1$ and $\frac{5-1}{4}=1$ at $t=5$, so there are no jumps. The slope of $\frac{t-1}{4}$ is $\frac14=f$ on $(1,5)$ ✓.
$$F(t)=\begin{cases}0 & t\le1\\ \dfrac{t-1}{4} & 1<t<5\\ 1 & t\ge5\end{cases}$$

This random variable is called the continuous uniform random variable on $(1,5)$: $X\sim\text{Uniform}(1,5)$ or $X\sim\mathcal{U}(1,5)$. The variable $X\sim\mathcal{U}(0,1)$ is called the standard continuous uniform. It is module 06's random point. The generalization to $X\sim\mathcal{U}(a,b)$, with height $1/(b-a)$, is straightforward and comes in module 24.

EX Reading probabilities off U(1,5)— ⊡ ✕

A few probabilities that are not on the slides, each done two ways:

  1. $P(2<X<3)$. Area: a slice of width 1 and height 0.25, so $0.25$. Cdf: $F(3)-F(2)=\frac{2}{4}-\frac{1}{4}=0.25$ ✓.
  2. $P(X>4.5)$. Area: width $5-4.5=0.5$ times $0.25$ is $0.125$. Cdf: $1-F(4.5)=1-\frac{3.5}{4}=0.125$ ✓.
  3. $P(0<X<2)$. Only the part $(1,2)$ carries density, so the answer is $1\times0.25=0.25$. Cdf: $F(2)-F(0)=0.25-0=0.25$ ✓.
  4. $P(X=3)$ and $P(X\le3)$ vs $P(X<3)$. $P(X=3)=0$, so $P(X\le3)=P(X<3)=F(3)=0.5$.
Insight
For a uniform, every question reduces to "length of the overlap with $(1,5)$, divided by 4". That is module 06's "probability = length", rescaled so that the total is 1. The height $c=\frac14$ is exactly this rescaling factor.
EXAMPLE (slides 10–11) · f(x) = 5e^(−5x): normalization and cdf

Let $X$ be a continuous r.v. with pdf $$f(x)=\begin{cases}5e^{-5x} & x\ge0\\ 0 & x<0\end{cases}$$ Verify the normalization rule and find the cdf.

  1. Non-negative? $e^{-5x}>0$ for every $x$, so $5e^{-5x}>0$ for $x\ge0$, and $f=0$ for $x<0$ ✓.
  2. Restrict to where $f$ lives. The part over $(-\infty,0)$ contributes 0: $$\int_{-\infty}^{+\infty}f(x)\,dx=\int_0^{+\infty}5e^{-5x}\,dx.$$
  3. Find an antiderivative. By the chain rule $\frac{d}{dx}\left(-e^{-5x}\right)=-e^{-5x}\cdot(-5)=5e^{-5x}$. So $$\int_0^{+\infty}5e^{-5x}\,dx=-e^{-5x}\Big|_{x=0}^{x=+\infty}.$$
  4. Evaluate. At $+\infty$: $-e^{-\infty}=0$. At 0: $-e^{-5\cdot0}=-1$. Upper minus lower: $$0-\left(-e^{-5\cdot0}\right)=0+e^{-5\cdot0}=1\ \checkmark$$
  5. cdf for $t<0$. $F(t)=\int_{-\infty}^t0\,dx=0$.
  6. cdf for $t\ge0$. Same antiderivative, now stopping at $t$: $$F(t)=\int_0^t 5e^{-5x}\,dx=-e^{-5x}\Big|_{x=0}^{x=t}=-e^{-5t}-(-1)=1-e^{-5t}.$$
  7. Checks. $F(0)=1-1=0$, which joins the flat piece. $F(t)\to1$ as $t\to\infty$. $F'(t)=5e^{-5t}=f(t)$ ✓.
$$F(t)=\begin{cases}0 & t<0\\ 1-e^{-5t} & t\ge0\end{cases}$$
Insight
Compare module 14. There $X=-\ln U$ had $F(t)=1-e^{-t}$. Here the exponent carries a 5: the same shape, squeezed 5 times closer to 0. In fact $X=-\tfrac15\ln U$ has exactly this cdf, because $P\!\left(-\tfrac15\ln U\le t\right)=P\!\left(U\ge e^{-5t}\right)=1-e^{-5t}$. Module 24 names the whole family: the exponential distribution with rate $\lambda$, here $\lambda=5$.
EX Probabilities from $5e^{-5x}$— ⊡ ✕

Probabilities not on the slides:

  1. $P(X\le0.2)$. $F(0.2)=1-e^{-5\cdot0.2}=1-e^{-1}\approx1-0.368=0.632$.
  2. $P(X>0.2)$. Complement: $1-F(0.2)=e^{-1}\approx\mathbf{0.368}$. The tail probability of this cdf has the neat form $P(X>t)=e^{-5t}$.
  3. $P(0.2<X\le0.4)$. $F(0.4)-F(0.2)=(1-e^{-2})-(1-e^{-1})=e^{-1}-e^{-2}\approx0.368-0.135=0.233$.
  4. $P(X=0)$. 0, even though $f(0)=5$ is the highest point of the density.
Insight
Most of the mass is packed near 0: 63% of it lies below 0.2. Yet the density's peak value 5 is a height, not a probability. Only areas, such as the 0.632 and the 0.368 here, are probabilities.
R corner · densities, cdfs and integrate() (standard R, not on the slides)

Write the density as an R function and let integrate(f, lower, upper) find areas. The limits may be Inf.

f <- function(x) 5 * exp(-5 * x)
integrate(f, 0, Inf)$value → 1 (normalization ✓)
integrate(f, 0, 0.2)$value → 0.6321206 $=F(0.2)$
pexp(0.2, rate = 5) → 0.6321206, the built-in cdf of this density
1 - pexp(0.2, rate = 5) → 0.3678794 $=P(X>0.2)$
dexp(0, rate = 5) → 5, a density value above 1, which is perfectly fine

punif(3, min = 1, max = 5) → 0.5; punif(3, 1, 5) - punif(2, 1, 5) → 0.25; dunif(3, 1, 5) → 0.25 (the height $c$).

Traps. (i) The second argument of pexp is the rate 5, not $1/5$. pexp(0.2, 0.2) returns $1-e^{-0.04}\approx0.039$, a different distribution. (ii) Printed without $value, integrate adds "with absolute error < …". That is a numerical error bound, not part of the answer. (iii) integrate needs a function that returns one value per input. integrate(function(x) 0.25, 1, 5) fails with "evaluation of function gave a result of wrong length". Use function(x) rep(0.25, length(x)) or function(x) dunif(x, 1, 5), which gives 1.

?check yourselfHeight vs probability
Can a density take the value 3 at some point? Can a cdf? Give an example or a reason.
Answer
A density can: the uniform density on $(0,\tfrac13)$ has height 3 everywhere, with area $3\times\tfrac13=1$. A cdf cannot: $F(t)=P(X\le t)$ is a probability, so $0\le F(t)\le1$ always.
?check yourselfFind the constant
For which $c$ is $f(x)=cx^2$ on $(0,1)$ (0 otherwise) a density? For that $c$, find $F(t)$ and $P(X\le0.5)$.
Answer
Normalization: $\int_0^1cx^2\,dx=c\cdot\frac{x^3}{3}\Big|_0^1=\frac c3=1$, so $c=3$. Then for $0\le t\le1$, $F(t)=\int_0^t3x^2\,dx=t^3$, and $P(X\le0.5)=0.5^3=0.125$. This is the "3x²" density of the interactive figure and of module 23.
?check yourselfEndpoints
$X\sim\mathcal{U}(1,5)$. Compute $P(X\le3)$, $P(X<3)$ and $P(X=3)$. Would the answers change if $X$ were discrete?
Answer
$P(X=3)=0$, so $P(X\le3)=P(X<3)=F(3)=\frac{3-1}{4}=0.5$. For a discrete $X$ with $P(X=3)>0$ the two would differ by exactly $P(X=3)$ (see the TRAP above).
?check yourselfFrom cdf to pdf
A continuous $X$ has $F(t)=1-\dfrac{1}{t^2}$ for $t\ge1$ and $F(t)=0$ for $t<1$. Find its density and check that it integrates to 1.
Answer
Differentiate: $f(t)=F'(t)=\dfrac{2}{t^3}$ for $t>1$, and $0$ for $t<1$. Check: $\int_1^{\infty}2t^{-3}\,dt=\left[-t^{-2}\right]_1^{\infty}=0-(-1)=1$ ✓.
