Expected value

slides: Distribution Functions 23–29 · ahead of the lecture notes
READ FIRST The question this module answers— ⊡ ✕

A random variable is a whole list of possible values, each with a probability (module 15). Very often you want one number that says what you get "on average". Is a bet worth playing? What is a fair price for a lottery ticket, or for an option? Which of two strategies pays more in the long run? All of these questions are answered by the same number, the expected value $\mathbb{E}(X)$.

The slides build it in two steps. Keep both pictures in your head, because each one explains things the other cannot:

  • Long-run average (slide 23). Play a game many times. The average gain per game settles down to a fixed number, and that number is $\mathbb{E}(X)$.
  • Weighted average, or balance point (slide 24). Average the possible values, weighting each one by its probability. Physically: put a weight $f(x_i)$ at position $x_i$ on a rod. $\mathbb{E}(X)$ is the point where the rod balances.

After that come three tools you will use in every later module: the link between $\mathbb{E}(X)$ and the sample mean of data (slide 26), the expected value of a function of $X$ (slides 27–28), and linearity, $\mathbb{E}(a+bX)=a+b\,\mathbb{E}(X)$ (slide 29).

Two facts to hold on to
$\mathbb{E}(X)$ is a number, not a random quantity: once the pmf is known, nothing random is left in it. And it need not be a value that $X$ can take. The game below has $\mathbb{E}(X)=\$0.19$, yet no single game ever pays 19 cents.
EXAMPLE (slide 23) · a game with a biased coin

You flip a biased coin twice, with $P(\{H\})=\frac1{10}$. If you get two heads you win $\$1$. If you get one head and one tail you win $\$10$. If you get two tails you lose $\$2$. Let $X$ be the number of dollars you win. How much do you win per game, on average?

  1. Name the values. $X$ takes three values: $1$ (two heads), $10$ (one of each) and $-2$ (two tails). A loss is simply a negative win.
  2. Probabilities of the four outcomes. The two flips are independent (module 09), so probabilities multiply along each path of the tree: $$P(HH)=0.1\cdot0.1=0.01,\qquad P(HT)=0.1\cdot0.9=0.09$$ $$P(TH)=0.9\cdot0.1=0.09,\qquad P(TT)=0.9\cdot0.9=0.81$$
  3. Group the outcomes by the value of $X$. "One head and one tail" happens in two ways, $HT$ or $TH$, so those two probabilities add: $$P(X=1)=0.01,\qquad P(X=10)=0.09+0.09=0.18,\qquad P(X=-2)=0.81$$ Check: $0.01+0.18+0.81=1$ ✓ (the normalisation rule of module 15).
  4. Imagine playing $n=1000$ times. Over many games, each outcome happens in roughly the fraction of games given by its probability. So expect about $$0.01\times1000=10,\qquad0.18\times1000=180,\qquad0.81\times1000=810$$ games with two heads, one of each, and two tails respectively.
  5. Total gain over the 1000 games. Each group of games contributes (number of games) × (gain per game): $$\$1\times10+\$10\times180-\$2\times810=\$10+\$1800-\$1620=\$190$$ The slide writes the same sum as $\$1\times1000\times0.01+\$10\times1000\times0.18-\$2\times1000\times0.81=\$190$.
  6. Gain per game. Divide by the number of games, $n=1000$. The 1000 cancels in every term: $$\frac{\$1\times1000\times0.01+\$10\times1000\times0.18-\$2\times1000\times0.81}{1000}$$ $$=0.01\times\$1+0.18\times\$10+0.81\times(-\$2)=\$0.01+\$1.80-\$1.62=\$0.19$$
Insight
The number of games cancelled. What remains, $0.01\cdot1+0.18\cdot10+0.81\cdot(-2)$, is a weighted average of the possible values of $X$, with the probabilities as the weights, and that is exactly the definition on slide 24. The game is worth playing ($+\$0.19$ per game on average) even though you lose in 81% of games, because the occasional $\$10$ win more than covers the frequent $\$2$ losses.
TRY IT Change the coin, then play the game— ⊡ ✕
IDEA The same game for any coin— ⊡ ✕

Nothing in slide 23 depended on the number $0.1$. For a coin with $P(H)=p$ and $q=1-p$, the same tree gives

$$P(X=1)=p^2,\qquad P(X=10)=2pq,\qquad P(X=-2)=q^2$$

so the expected gain per game is

$$\begin{aligned}\mathbb{E}(X)&=1\cdot p^2+10\cdot2p(1-p)+(-2)(1-p)^2\\&=p^2+20p-20p^2-2+4p-2p^2\\&=-21p^2+24p-2\end{aligned}$$

Check against the slides: at $p=0.1$ this gives $-0.21+2.4-2=0.19$ ✓.

When is the game fair? Set $\mathbb{E}(X)=0$, i.e. $21p^2-24p+2=0$:

$$p=\frac{24\pm\sqrt{24^2-4\cdot21\cdot2}}{2\cdot21}=\frac{24\pm\sqrt{408}}{42}\approx\frac{24\pm20.199}{42}$$

The root $1.052$ is not a probability, so the only break-even coin is $p\approx0.0905$. For any $p$ above that the game favours you, and for $p$ below it you lose on average.

What to try.

  • "slides: P(H) = 0.1". The big weight $0.81$ at $-2$ is balanced by a small weight $0.18$ far out at $10$, and the fulcrum sits just right of zero, at $0.19$.
  • "break-even". With $p\approx0.0905$ the fulcrum sits at $0$: a fair game.
  • "fair coin". Now $P(X=10)=2\cdot\frac12\cdot\frac12=\frac12$ and $\mathbb{E}(X)=-\frac{21}4+12-2=4.75$.
  • "play 1000 games", several times, then "reset". The running average jumps around for the first few dozen games, then settles near $\mathbb{E}(X)$. With only 100 games it is still visibly noisy, which is why slide 23 says "a very large number of times".
DEF Expected value (slide 24)— ⊡ ✕

Let $X$ be a discrete random variable that takes the values $\{x_1,x_2,x_3,\dots\}$, with pmf $f(x)$. The expected value of $X$ is

$$\boxed{\;\mathbb{E}(X)=\sum_{i=1}^{\infty}f(x_i)\,x_i\;}$$

provided that this series converges absolutely, i.e. $\sum_i f(x_i)\,|x_i|<\infty$ (the sum must stay finite if every $x_i$ is replaced by its absolute value). If the series does not converge absolutely, we say that the expected value of $X$ does not exist.

Other names: the mean of $X$, written $\mu_X$ or just $\mu$.

Reading the formula

Multiply each possible value $x_i$ by its probability, then add up the products. Likely values pull hard and unlikely values pull weakly. With equal probabilities this is the ordinary average; with unequal ones it is a weighted average.

Units

$\mathbb{E}(X)$ has the same unit of measurement as $X$. Probabilities have no unit, so each term $f(x_i)\,x_i$ is in dollars when $x_i$ is in dollars. The game's $\mathbb{E}(X)$ is $\$0.19$ per game, and the expected lifetime of a TV set is measured in years.

The balance point

A free sanity check follows from the picture: the balance point cannot lie outside the weights, so $\min_i x_i\le\mathbb{E}(X)\le\max_i x_i$. An answer outside that range is always a computing error.

WHY Why "converges absolutely"?— ⊡ ✕

If $X$ has finitely many values, the sum is finite and there is nothing to check. The proviso matters only when the support is infinite, like $\{1,2,3,\dots\}$. Two different things can go wrong.

1. The sum is infinite

Win $2^k$ dollars with probability $2^{-k}$, for $k=1,2,\dots$ (the "St. Petersburg" game). Each term is $f(x_k)\,x_k=2^{-k}\cdot2^k=1$, so

$$\sum_k f(x_k)\,x_k=1+1+1+\cdots=\infty$$

No finite average exists.

2. The answer depends on the order of the terms

The labels $x_1,x_2,x_3,\dots$ are just an arbitrary numbering of the values. For "the average" to mean anything, renumbering the values must not change it. A series that converges absolutely has exactly this property: it gives the same sum in any order. A series that converges only conditionally does not. By Riemann's rearrangement theorem, reordering its terms can make it add up to almost anything.

Example: let $X$ take the value $(-1)^{k+1}\,2^k/k$ with probability $2^{-k}$, for $k=1,2,\dots$ (these probabilities do sum to 1). Then $f(x_k)\,x_k=(-1)^{k+1}/k$, and

$$1-\tfrac12+\tfrac13-\tfrac14+\cdots=\ln2\approx0.693$$

but the same terms taken as two positives then one negative give

$$1+\tfrac13-\tfrac12+\tfrac15+\tfrac17-\tfrac14+\cdots=\tfrac32\ln2\approx1.040$$

With absolute values the series becomes $1+\frac12+\frac13+\cdots=\infty$. The test fails, and the slide's rule correctly says that $\mathbb{E}(X)$ does not exist.

In one line
Absolute convergence means the average does not depend on how you happened to list the values. "Does not exist" is not the same as "equals zero".
?check yourselfThe geometric-type pmf of module 15
Module 15 proved that $f(k)=\frac15\left(\frac45\right)^{k-1}$, $k\in\{1,2,\dots\}$, is a pmf. Does $\mathbb{E}(X)$ exist, and what is it? Hint: differentiate the geometric series $\sum_{k\ge0}q^k=\frac1{1-q}$ with respect to $q$.
Answer

All the terms $f(k)\,k$ are positive, so absolute convergence is the same as ordinary convergence. Differentiating the geometric series term by term (valid for $|q|<1$) gives

$$\sum_{k=1}^{\infty}k\,q^{k-1}=\frac{1}{(1-q)^2}$$

With $q=\frac45$:

$$\mathbb{E}(X)=\frac15\sum_{k=1}^{\infty}k\left(\frac45\right)^{k-1}=\frac15\cdot\frac{1}{(1/5)^2}=\frac15\cdot25=5$$

So it exists and equals $5$. If each attempt succeeds with probability $\frac15$, the first success comes on attempt 5 on average (module 20).

EXAMPLE (slide 25) · heads in two fair flips

A fair coin is flipped $n=2$ times. Let $X$ be the number of heads. Find $\mathbb{E}(X)$.

  1. Recall the pmf (module 15): $f(0)=\frac14$, $f(1)=\frac12$, $f(2)=\frac14$.
  2. Apply the definition, with one term per value: $$\mathbb{E}(X)=f(0)\cdot0+f(1)\cdot1+f(2)\cdot2$$
  3. Substitute and add: $$\mathbb{E}(X)=\frac14\cdot0+\frac12\cdot1+\frac14\cdot2=0+\frac12+\frac12=1$$
Insight
The pmf is symmetric about 1 (weights $\frac14,\frac12,\frac14$ at $0,1,2$), and a symmetric rod balances at its centre. So $\mathbb{E}(X)=1$ could be read off the picture without any computing. On average you get one head in two flips, which is what intuition says.
EXTRA EXAMPLES (modules 12 and 15) · four familiar random variables
  1. Girls in a two-child family (module 12). The pmf is $\frac14,\frac12,\frac14$ on $0,1,2$, identical to heads in two flips, so $\mathbb{E}(X)=1$.
  2. The $\pm\$2$ game (module 12, three fair flips). $X\in\{-2,0,2\}$ with probabilities $\frac14,\frac12,\frac14$: $$\mathbb{E}(X)=(-2)\cdot\tfrac14+0\cdot\tfrac12+2\cdot\tfrac14=-\tfrac12+0+\tfrac12=0$$ A fair game: on average you neither win nor lose.
  3. The $(0,1)$ game (module 12). $P(X=1)=0.1$, $P(X=2)=0.6$, $P(X=5)=0.3$: $$\mathbb{E}(X)=0.1\cdot1+0.6\cdot2+0.3\cdot5=0.1+1.2+1.5=2.8\text{ dollars}$$ This is the balance-point picture above.
  4. Heads in three fair flips (module 15). $f=\frac18,\frac38,\frac38,\frac18$ on $0,1,2,3$: $$\mathbb{E}(X)=0\cdot\tfrac18+1\cdot\tfrac38+2\cdot\tfrac38+3\cdot\tfrac18=\frac{0+3+6+3}{8}=\frac{12}{8}=1.5$$ The number of tails in three flips (module 12) has the same pmf, so its mean is also $1.5$.
Insight
A pattern is showing: $n$ fair flips give $n/2$ heads on average. Module 18 proves the general rule $\mathbb{E}(X)=np$ for the binomial.
DEF From data to $\mathbb{E}(X)$: absolute and relative frequency mean (slide 26)— ⊡ ✕

Now switch from a model to data. Suppose an experiment or study produced $n$ observations, and the distinct values observed are $x_1,\dots,x_k$.

  • The absolute frequency of $x_j$ is the number $n(x_j)$ of times $x_j$ occurred. The counts add up to the number of observations: $n=\sum_{j=1}^{k}n(x_j)$.
  • The relative frequency of $x_j$ is the absolute frequency normalised by the total number of observations: $$f(x_j)=\frac{n(x_j)}{n}$$

The sample mean can then be written in two equivalent ways:

$$\bar x=\frac1n\sum_{j=1}^{k}x_j\,n(x_j)\qquad\text{or}\qquad\bar x=\sum_{j=1}^{k}x_j\,f(x_j)$$

The sum is finite, because a sample (or a real population) is finite.

Compare the second form with $\mathbb{E}(X)=\sum_i x_i\,f(x_i)$. It is the same formula, with relative frequencies in the place of probabilities, and that is why the slide reuses the letter $f$. As $n$ grows, relative frequencies get closer and closer to the probabilities. This is the fact slide 23 relied on, and its formal version is the law of large numbers. So

$$\bar x\;\longrightarrow\;\mathbb{E}(X)\qquad\text{as }n\to\infty$$

The sample mean is computed from data and changes from sample to sample. $\mathbb{E}(X)$ is a fixed property of the model. The sample mean is the natural estimate of $\mathbb{E}(X)$.

About the slide's notation
The slide writes $n=\sum_i^n n(x_i)$ and $\frac1n\sum_{i=1}^n x_i\,n(x_i)$, using $n$ both for the number of observations and for the upper limit of the sum. The sum really runs over the distinct values, $k$ of them, as written above. The two readings agree when every observation is listed separately ($k=n$, each $n(x_i)=1$), which gives the familiar $\bar x=\frac1n\sum_{i=1}^n x_i$.

THEOREM Expected value of a function of $X$ (slide 27)— ⊡ ✕

Let $X$ be a discrete random variable with values $\{x_1,x_2,x_3,\dots\}$ and pmf $f(x)$, and let $g:\mathbb{R}\to\mathbb{R}$ be a function. Then $Y=g(X)$ is a random variable, and

$$\boxed{\;\mathbb{E}(Y)=\mathbb{E}(g(X))=\sum_{i=1}^{\infty}f(x_i)\,g(x_i)\;}$$

In words: transform the values and keep the probabilities. You do not need the pmf of $Y$. As an alternative, $\mathbb{E}(Y)$ can be computed by first deriving the distribution of $Y$ (module 14) and then applying the definition to $Y$. Both routes give the same number.

Why it is true

$Y$ equals $y$ whenever $X$ lands on any $x_i$ with $g(x_i)=y$, so $P(Y=y)=\sum_{i:\,g(x_i)=y}f(x_i)$. Put this into the definition of $\mathbb{E}(Y)$:

$$\mathbb{E}(Y)=\sum_y y\sum_{i:\,g(x_i)=y}f(x_i)=\sum_y\ \sum_{i:\,g(x_i)=y}g(x_i)\,f(x_i)=\sum_i g(x_i)\,f(x_i)$$

The last step holds because every index $i$ appears exactly once, in the group of its own value $y=g(x_i)$. The theorem simply skips the grouping.

Both routes on module 14's example

$X\in\{-2,0,2\}$ with probabilities $\frac14,\frac12,\frac14$, and $Y=X^2$.

  1. Route 1, via the pmf of $Y$. Module 14 found $Y\in\{0,4\}$ with probabilities $\frac12,\frac12$. So $\mathbb{E}(Y)=0\cdot\frac12+4\cdot\frac12=2$.
  2. Route 2, via the theorem. $\mathbb{E}(X^2)=\frac14(-2)^2+\frac12\cdot0^2+\frac14\cdot2^2=1+0+1=2$ ✓

Moments

A special function of interest is $g(x)=x^2$, which gives the second moment of the random variable, $\mathbb{E}(X^2)$. More generally, $g(x)=x^k$ gives the $k$-th moment, $\mathbb{E}(X^k)$ (module 17). For heads in two flips:

$$\mathbb{E}(X^2)=\tfrac14\cdot0^2+\tfrac12\cdot1^2+\tfrac14\cdot2^2=0+\tfrac12+1=\tfrac32$$
Trap: $\mathbb{E}(g(X))\ne g(\mathbb{E}(X))$
You cannot, in general, move $g$ inside the expectation. For heads in two flips, $\mathbb{E}(X^2)=\frac32$ but $[\mathbb{E}(X)]^2=1^2=1$: squaring and then averaging is not the same as averaging and then squaring. The gap $\frac32-1=\frac12$ is exactly the variance of module 17. The only functions that pass through $\mathbb{E}$ are straight lines $a+bx$ (slide 29).

THEOREM Linearity: $\mathbb{E}(a+bX)=a+b\,\mathbb{E}(X)$ (slide 29)— ⊡ ✕

Let $X$ be a random variable, and let $a$ and $b$ be real numbers. Then

$$\boxed{\;\mathbb{E}(a+b\,X)=a+b\,\mathbb{E}(X)\;}$$

Proof (one line). Take $g(x)=a+bx$ in the theorem of slide 27, split the sum in two, and use $\sum_i f(x_i)=1$:

$$\mathbb{E}(a+bX)=\sum_i f(x_i)(a+bx_i)=a\underbrace{\sum_i f(x_i)}_{=1}+b\underbrace{\sum_i f(x_i)\,x_i}_{=\mathbb{E}(X)}=a+b\,\mathbb{E}(X)\qquad\square$$

Intuition. $a+bX$ just relabels the axis. Shift every value by $a$ and the balance point shifts by $a$. Stretch every value by a factor $b$ and the balance point stretches by $b$.

Examples

  1. Module 14's $Z=3X+1$, with $X\in\{-2,0,2\}$ and probabilities $\frac14,\frac12,\frac14$. Here $\mathbb{E}(X)=0$ (the $\pm\$2$ pmf), so $\mathbb{E}(Z)=3\cdot0+1=1$. Directly from the pmf of $Z$: $(-5)\cdot\frac14+1\cdot\frac12+7\cdot\frac14=-1.25+0.5+1.75=1$ ✓
  2. An entry fee. If the casino charges $c$ dollars per game, your net gain $X-c$ has $\mathbb{E}(X-c)=0.19-c$. The fair fee (zero expected net gain) is $c=\$0.19$.
  3. A change of units. In cents the gain is $100X$, so $\mathbb{E}(100X)=100\cdot0.19=19$ cents. $\mathbb{E}$ always follows the unit.

Slide 34 (module 17) also uses the two-variable version, $\mathbb{E}(aX+bY)=a\,\mathbb{E}(X)+b\,\mathbb{E}(Y)$. It holds for any $X$ and $Y$, whether independent or not.

Trap
Linearity is for straight-line functions $a+bx$ only. $\mathbb{E}(X^2)\ne[\mathbb{E}(X)]^2$, $\mathbb{E}(1/X)\ne1/\mathbb{E}(X)$, and $\mathbb{E}\big((X-1)^+\big)\ne(\mathbb{E}(X)-1)^+$ (that last one is $\frac14$ versus $0$ on slide 28).
TIP R corner and summary— ⊡ ✕
R corner (standard R, not on the slides)

Store a pmf as two vectors, values and probabilities, and $\mathbb{E}(X)$ is one line:

x <- c(-2, 1, 10); f <- c(0.81, 0.01, 0.18)
sum(x * f) gives [1] 0.19, and so does weighted.mean(x, f).

Slide 23's argument as a simulation:
set.seed(1); g <- sample(x, 1000, replace = TRUE, prob = f); mean(g)
prints a number near 0.19 (the exact value depends on the seed and on the number of games).

$\mathbb{E}(g(X))$: transform the values, keep f:
x <- 0:2; f <- c(1/4, 1/2, 1/4)
sum(x^2 * f) gives [1] 1.5, and sum(pmax(x - 1, 0) * f) gives [1] 0.25.

The same pmf also comes from dbinom(0:2, 2, 0.5), which prints [1] 0.25 0.50 0.25 (module 18). Similarly, sum(0:3 * dbinom(0:3, 3, 0.5)) gives [1] 1.5.

R trap: max(x - 1, 0) returns a single number, the largest entry overall (here 1). So sum(max(x - 1, 0) * f) returns 1, not 0.25. For an element-by-element maximum use pmax.

?check yourselfLinearity in action
Let $X$ be the number of heads in three fair flips. Find $\mathbb{E}(10-2X)$ in two ways.
Answer

With linearity: $\mathbb{E}(10-2X)=10-2\,\mathbb{E}(X)=10-2\cdot1.5=7$.

Directly: $10-2X$ takes the values $10,8,6,4$ with probabilities $\frac18,\frac38,\frac38,\frac18$, so

$$\mathbb{E}(10-2X)=\frac{10\cdot1+8\cdot3+6\cdot3+4\cdot1}{8}=\frac{10+24+18+4}{8}=\frac{56}{8}=7\ \checkmark$$

?check yourselfThe put option
For heads in two fair flips, compute the expected payoff of a put with strike 1, $\mathbb{E}\big((1-X)^+\big)$. Then check that $\mathbb{E}\big((X-1)^+\big)-\mathbb{E}\big((1-X)^+\big)=\mathbb{E}(X)-1$.
Answer

$(1-x)^+$ equals $1,0,0$ at $x=0,1,2$, so $\mathbb{E}\big((1-X)^+\big)=\frac14\cdot1+\frac12\cdot0+\frac14\cdot0=\frac14$.

For every number $x$, $(x-1)^+-(1-x)^+=x-1$: one of the two terms is zero and the other is $|x-1|$ with the right sign. Taking expectations and using linearity gives

$$\tfrac14-\tfrac14=0=\mathbb{E}(X)-1=1-1\ \checkmark$$

This is put–call parity in its simplest form: call minus put equals the asset minus the strike.
