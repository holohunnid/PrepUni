Discrete random variables & the pmf

lecture 2, notes p.10–13 · slides: Distribution Functions 14–22
READ FIRST Countable values ⇒ list each value with its probability— ⊡ ✕

Random variables come in two kinds, and the dividing line is the one module 01 drew for sample spaces: can you count the possible values?

  • If yes — finitely many, or an infinite list $x_1,x_2,\dots$ — the variable is discrete, and we describe it by listing each value with its probability. That list is the probability mass function (pmf).
  • If the values fill an interval, the variable is continuous, single values have probability 0 (module 06), and a list is useless — modules 22–26 use densities instead.

For discrete variables the pmf and the CDF are two views of the same information: the CDF is the running total of the pmf, and the pmf is the size of the CDF's jumps.

DEF Support; discrete vs continuous— ⊡ ✕

The support $\mathrm{supp}(X)$ is the set of values $X$ can take. The notes' three examples:

  • $\mathrm{supp}(X)=\{0,1,\dots,5\}$ — heads in 5 flips: finite (hence countable);
  • $\mathrm{supp}(Y)=\{1,2,3,\dots\}$ — tosses needed by the stubborn coin flipper: infinite but countable;
  • $\mathrm{supp}(Z)=[0,+\infty)$ — lifetime of a TV set: infinite and uncountable (even $[0,1]$ alone is uncountable).

$X$ and $Y$ are discrete; $Z$ is continuous.

Definition
A discrete random variable is one with a countable support — finite or infinite. "Countable" means the elements can be numbered 1st, 2nd, 3rd, … so that every element eventually gets a number.
SEE IT Three kinds of support— ⊡ ✕
DEF Probability mass function and the normalisation rule— ⊡ ✕

Let $X$ be discrete with support $\{x_1,x_2,\dots\}$. Its probability mass function is $f:\mathbb R\to[0,1]$ with

$$\boxed{f(x_i)=P(X=x_i)\ \text{ if }x_i\in\mathrm{supp}(X),\qquad f(x)=0\ \text{ otherwise.}}$$

Because the events $\{X=x_i\}$ are disjoint and together certain (module 05), the masses must add to one — the normalisation rule:

$$\boxed{\sum_{i=1}^{\infty}f(x_i)=\sum_{x\in\mathrm{supp}(X)}f(x)=1}$$

A function is a valid pmf exactly when it is non-negative and satisfies normalisation. Those are the two things to check in "prove that $f$ is a pmf" questions.

EX LECTURE 2 · notes p.11 · slides 16 — find the missing constant— ⊡ ✕

One unknown probability

$$X=\begin{cases}-2&\text{w.p. }\tfrac12\\+4&\text{w.p. }\tfrac14\\6.4&\text{w.p. }c\ \text{(unknown)}\end{cases}\qquad\mathrm{supp}(X)=\{-2,4,6.4\}$$
  1. pmf: $f(-2)=\tfrac12$, $f(4)=\tfrac14$, $f(6.4)=c$, and $f(x)=0$ for all other $x$.
  2. Normalisation: $\tfrac12+\tfrac14+c=1\Rightarrow c=1-\big(\tfrac12+\tfrac14\big)=\tfrac14$.

(The slides use 6.7 for the last value; the value is irrelevant to $c$ — only probabilities enter the normalisation.)

Probabilities proportional to known weights

$$Y=\begin{cases}5&\text{w.p. }2c\\7&\text{w.p. }c\\8&\text{w.p. }3c\end{cases}\qquad 2c+c+3c=6c=1\ \Rightarrow\ c=\tfrac16$$

so $Y$ takes 5, 7, 8 with probabilities $\tfrac26,\tfrac16,\tfrac36$.

DEF LECTURE 2 · notes p.12 · slides 17 — the constant random variable— ⊡ ✕

$X$ is constant if $P(X=c)=1$ and $P(X=c')=0$ for every $c'\neq c$ — "degenerate, with no real randomness". Its pmf and CDF:

$$f(t)=\begin{cases}1,&t=c\\0,&t\neq c\end{cases}\qquad F(t)=\begin{cases}0,&t<c\\1,&t\ge c\end{cases}$$
EX LECTURE 2 · notes p.12–13 · slides 18–21 — pmf and CDF of the number of heads— ⊡ ✕

$X$ = number of heads in $n=2$ fair flips. $\mathrm{supp}(X)=\{0,1,2\}$ ⇒ discrete.

  1. $f(0)=P(\{TT\})=\tfrac12\cdot\tfrac12=\tfrac14$
  2. $f(1)=P(\{HT,TH\})=2\cdot\tfrac12\cdot\tfrac12=\tfrac24=\tfrac12$
  3. $f(2)=P(\{HH\})=\tfrac14$, and $f(x)=0$ for $x\notin\mathrm{supp}(X)$.
  4. The CDF accumulates the pmf: $$F(t)=\begin{cases}0,&t<0\\\tfrac14,&0\le t<1\quad(f(0))\\\tfrac34,&1\le t<2\quad(f(0)+f(1))\\1,&t\ge2\quad(f(0)+f(1)+f(2))\end{cases}$$

Same exercise with $n=3$ (the notes point to the PDF): $f=\tfrac18,\tfrac38,\tfrac38,\tfrac18$ on $\{0,1,2,3\}$ and $F=0,\ 0.125,\ 0.5,\ 0.875,\ 1$ on $t<0$, $[0,1)$, $[1,2)$, $[2,3)$, $t\ge3$. The "tails in 3 coins" option of module 13's CDF figure draws it.

EX LECTURE 2 · notes p.13 · slides 22 — prove that f(k) = (1/5)(4/5)^(k−1) is a pmf— ⊡ ✕
$$f(k)=\frac15\Big(\frac45\Big)^{k-1},\qquad k=1,2,3,\dots$$

Two things to check.

  1. Non-negativity: $f(k)>0$ for every $k$ — a positive number times a positive power ✓.
  2. Normalisation. Hint from the lecture — the geometric series: if $a\in(-1,1)$, $$b+ab+a^2b+\dots=\frac{b}{1-a}.$$
  3. Write out the sum: $$\sum_{k=1}^{\infty}f(k)=\frac15+\frac15\cdot\frac45+\frac15\Big(\frac45\Big)^2+\dots$$ This is a geometric series with $b=\tfrac15$ and $a=\tfrac45$.
  4. So $\displaystyle\sum_{k\ge1}f(k)=\frac{1/5}{1-4/5}=\frac{1/5}{1/5}=1$ ✓. $\square$

Where the geometric-series formula comes from

Let $S=b+ab+a^2b+\dots$. Then $aS=ab+a^2b+\dots$ — the same series without its first term. Subtract: $S-aS=b$, so $S=\frac b{1-a}$. (Needs $|a|<1$ so the terms shrink and $S$ is finite.)

What is this random variable?
It is the stubborn coin flipper of module 01 with a biased coin, $P(H)=\tfrac15$: the first head comes at toss $k$ if the first $k-1$ tosses are tails ($\tfrac45$ each, independent — module 09) and toss $k$ is a head ($\tfrac15$). Module 21 names it: Geometric with $p=\tfrac15$.
?check yourselfUsing the pmf
With $f(k)=\tfrac15(\tfrac45)^{k-1}$, find $P(X\le3)$ and $P(X>3)$.
Answer
$P(X\le3)=\tfrac15\big(1+\tfrac45+\tfrac{16}{25}\big)=\tfrac15\cdot\tfrac{61}{25}=\tfrac{61}{125}=0.488$. $P(X>3)=1-0.488=0.512=(\tfrac45)^3$ — "three tails in a row".
?check yourselfValid pmf?
Is $f(k)=\tfrac{k}{10}$ for $k=1,2,3,4$ a pmf? And $g(k)=\tfrac{k-2}{2}$ for $k=1,2,3,4$?
Answer
$f$: all positive and $\tfrac{1+2+3+4}{10}=1$ ✓ — a pmf. $g$: $g(1)=-\tfrac12<0$ ✗ — not a pmf, even though $\sum g=\tfrac{-1+0+1+2}{2}=1$. Both conditions are needed.
