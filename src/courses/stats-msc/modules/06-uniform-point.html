06

A random point in (0,1)

lecture 1, notes p.9 · slides: Axioms 19–20
READ FIRST When outcomes can't be counted, probability moves to intervals— ⊡ ✕

Pick a number "completely at random" from the interval $(0,1)$. The sample space $\Omega=(0,1)$ is uncountable (module 01), and this changes the game: we can no longer give each outcome a positive probability and add them up. Instead:

  • every single point gets probability 0 — $P(\{0.5\})=0$;
  • intervals carry the probability, and it is proportional to their length — $P((u,v))=v-u$.

This is the first continuous model of the course, and it is the prototype for everything in modules 21–25 (densities, the uniform, the normal). It is also the "raw material" of simulation: module 14 turns this random point into an exponential random variable.

STEP 1 A single point has probability 0— ⊡ ✕

The lecture states $P(\{0.5\})=0$; here is why it cannot be anything else. "At random" means no point is special, so every point would get the same probability $\varepsilon$. Suppose $\varepsilon>0$. Take $N$ different points in $(0,1)$ — the events $\{x_1\},\dots,\{x_N\}$ are disjoint, so by finite additivity

$$P(\{x_1,\dots,x_N\})=N\varepsilon.$$

Choose $N>1/\varepsilon$ and this exceeds 1, which is impossible (module 05). So $\varepsilon=0$.

Consequence: endpoints don't matter
Adding or removing a single point changes a probability by 0. So $$P((a,b))=P([a,b))=P((a,b])=P([a,b]).$$ In continuous models, "<" versus "≤" is irrelevant. (In discrete models it matters a lot — module 13.)
STEP 2 Symmetry, then halving: probability = length— ⊡ ✕

No half of $(0,1)$ is favoured, so it is reasonable that $P((0,0.5))=P((0.5,1))$. The two halves are disjoint and (ignoring the single point $0.5$, which has probability 0) fill $(0,1)$:

$$P((0,0.5))+P((0.5,1))=P((0,1))=1\ \Longrightarrow\ P((0,0.5))=P((0.5,1))=0.5.$$

Repeat the argument on each half, and on each quarter… every interval of length $\tfrac1{2^k}$ gets probability $\tfrac1{2^k}$:

Building intervals out of such pieces leads to the result on the slides:

$$\boxed{0\le u<v\le1:\qquad P((u,v))=\frac{v-u}{\text{length of }\Omega}=v-u}$$

and, for a random point in a general interval $(a,b)$,

$$\boxed{a\le u<v\le b:\qquad P((u,v))=\frac{v-u}{b-a}}$$
TRY IT Probability as a length— ⊡ ✕

Drag $u$ and $v$. The shaded block has height 1 over $(0,1)$, so its area equals its width — the probability. Press "a single point" to shrink the interval to nothing: the probability goes to 0 even though the point is still there.

EXAMPLE · a random point in (2, 6)

A number is drawn at random from $(2,6)$. Find $P(3<X<4.5)$ and $P(X>5)$.

  1. Length of $\Omega$: $b-a=6-2=4$.
  2. $P((3,4.5))=\dfrac{4.5-3}{4}=\dfrac{1.5}{4}=0.375$.
  3. $P(X>5)=P((5,6))=\dfrac{6-5}{4}=0.25$ — same as $P(X\ge5)$, endpoints don't matter.
Insight
Only lengths relative to the whole interval matter: this is why the "height" of the flat block is $\frac1{b-a}=\frac14$ here — module 23 calls it the Uniform$(a,b)$ density.
STRETCH Why axiom 3 needed infinite sequences— ⊡ ✕

What is the probability that the random point is a rational number (a fraction like $\tfrac12$, $\tfrac37$)?

The rationals in $(0,1)$ can be listed one after another — $\tfrac12,\tfrac13,\tfrac23,\tfrac14,\tfrac34,\dots$ — so they form a countable union of single points. Axiom 3 (countable additivity) gives

$$P(\text{rational})=\sum_{i=1}^{\infty}P(\{q_i\})=0+0+0+\dots=0.$$

Infinitely many possible outcomes, and still probability 0. Finite additivity alone could not have told us this.

But not every union works
$(0,1)$ itself is also a union of single points, each with probability 0, yet $P((0,1))=1$. No contradiction: that union is uncountable, and axiom 3 only speaks about countable sequences. This is exactly the line between discrete and continuous that module 15 draws.

A point is drawn at random from $(0,1)$. Find $P(X<0.3\ \text{or}\ X>0.8)$.
Answer
Disjoint pieces: $0.3+(1-0.8)=0.5$. Or by complement: $1-P((0.3,0.8))=1-0.5=0.5$.

Answer
The event is $(0.4,0.6)$, length $0.2$, so $P=0.2$. The exact value $0.5$ alone would have probability 0.
