The cumulative distribution function

lecture 2, notes p.7–9 · slides: Distribution Functions 8–11
READ FIRST One function that answers every "how likely is X in this range?"— ⊡ ✕

With a random variable we keep asking the same kind of question: $P(a<X\le b)$, $P(X>a)$, $P(X<a)$… The lecture's observation: if you know $P(X\le t)$ for every $t$ (and the jumps $P(X=t)$), you can answer all of them. So we give $P(X\le t)$ a name — the cumulative distribution function, or CDF — and treat it as the description of a random variable.

The CDF works the same way for discrete and continuous variables, which is why it comes first: a staircase for the coin-counting variables of module 12, a smooth ramp for the random point of module 06.

RULES Everything in terms of P(X ≤ t)— ⊡ ✕
$$\begin{aligned} P(a<X\le b)&=P(X\le b)-P(X\le a)\\ P(a<X<b)&=P(X\le b)-P(X\le a)-P(X=b)\\ P(X>a)&=1-P(X\le a)\\ P(X<a)&=P(X\le a)-P(X=a) \end{aligned}$$

Each line is a disjoint split:

  • $\{X\le b\}=\{X\le a\}\cup\{a<X\le b\}$, disjoint ⇒ line 1.
  • $\{a<X\le b\}=\{a<X<b\}\cup\{X=b\}$ ⇒ line 2.
  • $\{X>a\}$ is the complement of $\{X\le a\}$ ⇒ line 3.
  • $\{X\le a\}=\{X<a\}\cup\{X=a\}$ ⇒ line 4.
DEF The CDF and its five properties— ⊡ ✕

The (cumulative) distribution function of a random variable $X$ is

$$\boxed{F(t)=P(X\le t),\qquad t\in\mathbb R}$$

(write $F_X$ when several variables are around). Properties:

  1. $F(t)\in[0,1]$ for all $t$ — it is a probability.
  2. $F$ is non-decreasing: $a<b\Rightarrow F(a)\le F(b)$, since $\{X\le a\}\subseteq\{X\le b\}$ (monotonicity, module 05).
  3. $\lim_{t\to+\infty}F(t)=1$ — eventually every value is below $t$.
  4. $\lim_{t\to-\infty}F(t)=0$.
  5. $F$ is right-continuous: $\lim_{t\to a^+}F(t)=F(a)$.
KEY FACT Jumps are point probabilities — and continuous means no jumps— ⊡ ✕

The size of the jump of $F$ at $a$ is the probability of the single value $a$ (slides, Distribution Functions 10):

$$\boxed{P(X=a)=F(a)-F(a^-)},\qquad F(a^-)=\lim_{t\to a^-}F(t).$$

So if $F$ is continuous at $a$, then $P(X=a)=0$. For a continuous random variable this holds everywhere, and the notes draw the consequence:

$$X\text{ continuous}\ \Longrightarrow\ P(X=a)=0\ \Longrightarrow\ P(X\le t)=P(X<t).$$

This is module 06 again, in CDF language: single points carry no probability, so "<" and "≤" give the same number.

Trap: discrete variables do care about ≤ vs <
For $X$ = number of heads in two fair flips (module 15): $P(X\le1)=\tfrac34$ but $P(X<1)=P(X=0)=\tfrac14$. The difference is the jump $P(X=1)=\tfrac12$. In an exam, read the inequality sign twice when $X$ is discrete — and use the formulas on the left rather than guessing.

The PDF deck on continuous variables (slide 2) writes $F(t)=P(X<t)$ with a strict sign. For continuous $X$ it makes no difference; the lecture notes and every other slide use $\le$, and that is the definition to write.
EX LECTURE 2 · notes p.8–9 · slides Distribution Functions 11 — reading probabilities off a CDF— ⊡ ✕
$$F(t)=\begin{cases}0,&t<-1\\0.5+0.5t,&-1\le t\le1\\1,&t>1\end{cases}$$
  1. $P(X\le0.5)=F(0.5)=0.5+0.5(0.5)=\mathbf{0.75}$
  2. $P(X>0)=1-P(X\le0)=1-F(0)=1-(0.5+0.5\cdot0)=\mathbf{0.5}$
  3. $P(X\le2)=F(2)=\mathbf1$ — beyond 1 the CDF is flat at 1.
  4. $P(X\le-5)=F(-5)=\mathbf0$.
  5. $P(X=0.1)=F(0.1)-F(0.1^-)=0.55-0.55=\mathbf0$ — $F$ is continuous, no jump.
  6. $P(0<X\le0.3)=F(0.3)-F(0)=[0.5+0.5(0.3)]-[0.5+0.5(0)]=0.65-0.5=\mathbf{0.15}$. (The slides ask for $P(0\le X\le0.3)$ — the same number, since $P(X=0)=0$.)
Insight
The CDF rises in a straight line from $(-1,0)$ to $(1,1)$: equal-length intervals inside $[-1,1]$ get equal probability. This is a random point in $(-1,1)$ — the module 06 model on a different interval. Probability of an interval = its length ÷ 2.
?check yourselfA step CDF
$X$ = heads in 2 fair flips has $F(t)=0,\ \tfrac14,\ \tfrac34,\ 1$ on $t<0$, $[0,1)$, $[1,2)$, $t\ge2$. Find $P(0<X\le1)$, $P(0\le X\le1)$ and $P(X>1)$.
Answer
$P(0<X\le1)=F(1)-F(0)=\tfrac34-\tfrac14=\tfrac12$. $P(0\le X\le1)=F(1)-F(0^-)=\tfrac34-0=\tfrac34$ — including 0 adds its jump $\tfrac14$. $P(X>1)=1-F(1)=\tfrac14$.

Can $G(t)=0.5+0.5\sin t$ be a CDF?
Answer
No. It stays in $[0,1]$ but it is not non-decreasing (it goes up and down) and has no limits 0 and 1 at $\mp\infty$. All five properties must hold.
