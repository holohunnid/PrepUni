14

Transformations of a random variable

lecture 2, notes p.9–10 · slides: Distribution Functions 12–13
READ FIRST If X is random, so is g(X)— ⊡ ✕

A payoff that depends on a price, a loss that is the square of a deviation, a return that is the log of a price ratio: we constantly apply functions to random variables. If $X$ is random, $Z=g(X)$ is random too — and we want its distribution. The lecture gives one discrete and one continuous example, and between them they show the two techniques you need:

  • discrete: push each value through $g$ and carry its probability along; if several values land on the same number, add their probabilities;
  • continuous: the CDF method — write $F_Z(t)=P(g(X)\le t)$, solve the inequality for $X$, and use the CDF of $X$ (module 13).
EX LECTURE 2 · notes p.9 · slides Distribution Functions 12 — a discrete X, two transformations— ⊡ ✕
$$X=\begin{cases}-2&\text{w.p. }\tfrac14\\\ \ 0&\text{w.p. }\tfrac12\\+2&\text{w.p. }\tfrac14\end{cases}$$

Z = 3X + 1 — a one-to-one map: just relabel

  1. $3(-2)+1=-5$ w.p. $\tfrac14$
  2. $3(0)+1=+1$ w.p. $\tfrac12$
  3. $3(+2)+1=+7$ w.p. $\tfrac14$

Different values go to different values, so the probabilities travel unchanged: $Z\in\{-5,1,7\}$ with $\tfrac14,\tfrac12,\tfrac14$.

Y = X² — a many-to-one map: merge

  1. $(-2)^2=4$ w.p. $\tfrac14$; $\ 0^2=0$ w.p. $\tfrac12$; $\ (+2)^2=4$ w.p. $\tfrac14$.
  2. The value 4 appears twice — it must be listed once, with the probabilities added: $$Y=\begin{cases}0&\text{w.p. }\tfrac12\\4&\text{w.p. }\tfrac14+\tfrac14=\tfrac12\end{cases}$$
Trap
Writing $Y\in\{4,0,4\}$ with $\tfrac14,\tfrac12,\tfrac14$ is not a valid distribution description (the slides show it as an intermediate step and then say it "should be re-written"). Each value appears once, carrying the total probability of everything mapped onto it — the preimage idea of module 12.
EX LECTURE 2 · notes p.9–10 · slides Distribution Functions 13 — X = −ln U— ⊡ ✕

$U$ is a number drawn at random from $(0,1)$ — a uniform random variable (module 06). Its CDF is the length of $(0,t]$:

$$F_U(t)=\begin{cases}0,&t<0\\t,&0\le t\le1\\1,&t\ge1\end{cases}$$

Let $X=-\ln U$. Find $F_X$. The CDF method, one justified step at a time:

  1. Definition: $F_X(t)=P(X\le t)=P(-\ln U\le t)$.
  2. Multiply by $-1$ (the inequality flips): $=P(\ln U\ge-t)$.
  3. Apply $\exp$, which is increasing, so the inequality keeps its direction: $=P(e^{\ln U}\ge e^{-t})=P(U\ge e^{-t})$.
  4. Complement: $=1-P(U<e^{-t})=1-P(U\le e^{-t})$ — a single point has probability 0.
  5. Use $F_U$: $=1-F_U(e^{-t})$.
  6. For $t\ge0$, $e^{-t}\in(0,1]$, so $F_U(e^{-t})=e^{-t}$. For $t<0$, $e^{-t}>1$ so $F_U=1$. Hence $$\boxed{F_X(t)=\begin{cases}0,&t<0\\1-e^{-t},&t\ge0\end{cases}}$$

The notes label the result in green: this is the exponential distribution (with rate 1). It comes back in modules 21 and 23.

Sanity checks
$X=-\ln U>0$ always (since $0<U<1$ makes $\ln U<0$), so $F_X(t)=0$ for $t<0$ ✓. $F_X$ rises from 0 towards 1 as $t\to\infty$ ✓. It is continuous ✓ (no jumps: $X$ is continuous).
Why finance cares: simulation
Computers generate uniform numbers. This transformation turns them into exponential ones — the inverse-transform method: if $F$ is a CDF, $F^{-1}(U)$ has CDF $F$. Every Monte Carlo pricer starts like this. (Here $F(t)=1-e^{-t}$ gives $F^{-1}(u)=-\ln(1-u)$, and $1-U$ is just as uniform as $U$.)
?check yourselfStretch and shift
$U$ uniform on $(0,1)$, $X=2U+1$. Find $F_X(t)$.
Answer
$F_X(t)=P(2U+1\le t)=P\big(U\le\tfrac{t-1}2\big)=F_U\big(\tfrac{t-1}2\big)$: 0 for $t<1$, $\tfrac{t-1}2$ on $[1,3]$, 1 for $t>3$. A random point in $(1,3)$ — the length rule of module 06.
?check yourselfSquaring a uniform
$U$ uniform on $(0,1)$, $X=U^2$. Find $F_X(t)$ for $0\le t\le1$ and $P(X\le0.25)$.
Answer
$F_X(t)=P(U^2\le t)=P(U\le\sqrt t)=\sqrt t$ (no sign issue, $U>0$). $P(X\le0.25)=\sqrt{0.25}=0.5$: half of the $U$'s are below 0.5, and exactly those have squares below 0.25.
