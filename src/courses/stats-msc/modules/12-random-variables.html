Random variables

lecture 2, notes p.6–7 · slides: Distribution Functions 2–7
READ FIRST Attach a number to every outcome— ⊡ ✕

Outcomes like "GB" or "HTT" are awkward to compute with. Usually we care about a number attached to the outcome: how many girls, how many tails, how much money we win. A random variable is exactly that — a rule that assigns a real number to each outcome:

$$X:\Omega\to\mathbb R,\qquad \omega\mapsto X(\omega).$$

The name is slightly misleading: a random variable is not random and not a variable — it is a fixed function. The randomness sits in which $\omega$ occurs; once the experiment is run, $X(\omega)$ is determined. Before it is run, $X$ is uncertain, and that is what "random" means here.

The key move of this module is the preimage: the event "$X=1$" is really the set of outcomes that $X$ sends to 1, $\{\omega:X(\omega)=1\}$. That set is an event, so we already know how to find its probability. Everything about random variables is computed this way.

EX LECTURE 2 · notes p.6 · slides Distribution Functions 2 — families with two kids— ⊡ ✕

Pick a family at random from the population of families with two children: $\Omega=\{GG,GB,BG,BB\}$ (first child, second child). Define $X$ = number of girls. $X$ takes the values 0, 1, 2.

  1. $P(X=0)=P(\{\omega\in\Omega:X(\omega)=0\})=P(\{BB\})=\tfrac14$
  2. $P(X=1)=P(\{\omega\in\Omega:X(\omega)=1\})=P(\{GB,BG\})=\tfrac12$
  3. $P(X=2)=P(\{\omega\in\Omega:X(\omega)=2\})=P(\{GG\})=\tfrac14$

assuming B and G equally likely (so the four outcomes are equally likely). The slides write the same thing as $P(X=1)=P(X^{-1}(1))$: the probability of the preimage of 1.

Insight
Two different outcomes, $GB$ and $BG$, are sent to the same number 1. That is why $P(X=1)$ is twice the others: a value collects the probability of all outcomes mapped onto it.
LECTURE 2 · notes p.6–7 · slides 3 — three flips, X = number of tails

Flip a fair coin 3 times: $\Omega=\{HHH,HHT,\dots,TTT\}$, $|\Omega|=2^3=8$ equally likely outcomes.

  1. $P(X=0)=P(\{HHH\})=\tfrac18$
  2. $P(X=1)=P(\{THH,HTH,HHT\})=\tfrac38$
  3. $P(X=2)=P(\{HTT,THT,TTH\})=\tfrac38$
  4. $P(X=3)=P(\{TTT\})=\tfrac18$

The probabilities sum to 1 ✓. All possible values of $X$ form the support of $X$: here $\{0,1,2,3\}$.

SLIDES · Distribution Functions 4–5 — a game on three flips

Flip a fair coin 3 times. From the second flip on, win $\$1$ if the coin shows the same face as the previous flip, lose $\$1$ otherwise. $X$ = total gain.

outcomeHHHHHTHTHHTTTHHTHTTTHTTT
$X$+20−200−20+2
  1. $P(X=-2)=P(X^{-1}(-2))=P(\{HTH,THT\})=\tfrac28=\tfrac14$
  2. $P(X=0)=P(\{HHT,HTT,THH,TTH\})=\tfrac48=\tfrac12$
  3. $P(X=+2)=P(\{HHH,TTT\})=\tfrac28=\tfrac14$

Same $\Omega$ as the tails example, a different function on it — hence a different distribution. The sample space describes the experiment; the random variable describes what you are interested in.

Note: $X^{-1}(-2)=\{HTH,THT\}$ is an event, so its probability is well defined — this is the whole point of the definition below.

EX SLIDES · Distribution Functions 6 — a random variable on a continuous Ω— ⊡ ✕

Draw a number $\omega$ at random from $(0,1)$ (module 06). You win $\$1$ if $\omega\in(0,0.1)$, $\$2$ if $\omega\in[0.1,0.5)$, $\$5$ if $\omega\in[0.5,0.8)$ and $\$2$ if $\omega\in[0.8,1)$. $X$ = amount won — only the values 1, 2, 5 are possible.

  1. $P(X=1)=P((0,0.1))=0.1$ — length of the interval.
  2. $P(X=2)=P([0.1,0.5)\cup[0.8,1))=0.4+0.2=0.6$ — two disjoint pieces map to 2, so add.
  3. $P(X=5)=P([0.5,0.8))=0.3$ (not computed on the slide).
  4. $P(X=10)=P(\emptyset)=0$ — nothing maps to 10.

Check: $0.1+0.6+0.3=1$ ✓.

Insight
The sample space is continuous, but $X$ takes only three values. Whether a random variable is "discrete" is about its values, not about $\Omega$ (module 15).
DEF Random variable— ⊡ ✕

A random variable is a function $X:\Omega\to\mathbb R$ such that, for any interval $I\subseteq\mathbb R$,

$$\boxed{X^{-1}(I)=\{\omega\in\Omega:\ X(\omega)\in I\}\ \text{ is an event.}}$$

We use capital letters $X,Y,\dots$ for random variables and lower case $x,y$ for the numbers they can take.

Why the condition on preimages?

We want to be able to ask "$P(X\le 3)$?" or "$P(1<X\le2)$?". Those are probabilities of the sets $X^{-1}((-\infty,3])$ and $X^{-1}((1,2])$ — and probabilities are only defined for events. The condition guarantees every such question has an answer. (With finite $\Omega$ where every subset is an event it holds automatically.)

Notation: $\{X\in I\}$ and $P(X\in I)$ are shorthand for $\{\omega:X(\omega)\in I\}$ and its probability.
