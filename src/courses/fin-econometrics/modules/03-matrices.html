The inverse of a 2×2, by heart
$$\begin{bmatrix}a&b\\c&d\end{bmatrix}^{-1}=\frac1{ad-bc}\begin{bmatrix}d&-b\\-c&a\end{bmatrix}$$

Swap the diagonal, change the sign of the off-diagonal, divide by the determinant.

Block-diagonal matrices

If the first row and column are zero off the diagonal, invert the blocks separately. The ES_Testing matrix has this form: the constant is orthogonal to both regressors.

TRAP · you cannot split the inverse

$(X'X)^{-1}=X^{-1}(X')^{-1}$ is wrong unless $X$ is square. $X$ is $n\times K$ and has no inverse. If you could split it, $X(X'X)^{-1}X'$ would equal $I$ and every regression would fit perfectly.

KEY The matrix $X'X$— ⊡ ✕

Entry $(j,k)$ of $X'X$ is the inner product of columns $j$ and $k$: $\sum_ix_{ij}x_{ik}$. With a constant in the first column and one regressor:

$$X'X=\begin{bmatrix}1&\cdots&1\\x_{12}&\cdots&x_{n2}\end{bmatrix}\begin{bmatrix}1&x_{12}\\\vdots&\vdots\\1&x_{n2}\end{bmatrix}=\begin{bmatrix}n&\sum x_{i2}\\\sum x_{i2}&\sum x_{i2}^2\end{bmatrix},\qquad X'y=\begin{bmatrix}\sum y_i\\\sum x_{i2}y_i\end{bmatrix}$$
Three quick sanity checks

(1) $X'X$ is symmetric. (2) If the model has a constant, the top-left entry is $n$. (3) If regressor $k$ has mean zero, the entry pairing it with the constant is 0.

RUNNING EXAMPLE · invert it
$$X'X=\begin{bmatrix}5&15\\15&55\end{bmatrix},\ \det=5\cdot55-15^2=50,\quad (X'X)^{-1}=\frac1{50}\begin{bmatrix}55&-15\\-15&5\end{bmatrix}=\begin{bmatrix}1.1&-0.3\\-0.3&0.1\end{bmatrix}$$
RANK Rank, positive definiteness and why they come together— ⊡ ✕
  1. Rank = number of linearly independent columns (= rows). $\text{rank}(X)\le\min(n,K)$.
  2. Positive definite: $z'Az>0$ for every $z\neq0$. Non-negative definite: $z'Az\ge0$.
  3. $X'X$ is always non-negative definite: $z'X'Xz=(Xz)'(Xz)=\lVert Xz\rVert^2\ge0$.
  4. If $\text{rank}(X)=K$ it is positive definite: $\lVert Xz\rVert^2=0$ only if $Xz=0$, which by independence forces $z=0$. So $X'X$ has rank $K$ and is invertible. This is slide 8 of lecture 1.
  5. For a scalar, "positive definite" just means "positive". That is why $\frac{\partial^2SSE}{\partial b^2}=2X'X$ positive definite is the matrix version of $2\sum x_i^2>0$.
DEF Idempotent matrices (Memorandum A4 and S3)— ⊡ ✕

$A$ is idempotent if $AA=A$: applying it twice changes nothing. Projections are idempotent, because once you are on the plane, projecting again leaves you where you are.

  • A4. For a symmetric idempotent matrix, $\text{rank}(A)=\text{tr}(A)$.
  • S3. If $z\sim N(0,I_n)$ and $A$ is symmetric idempotent with rank $r$, then $z'Az\sim\chi^2_r$.
  • If $A$ is symmetric idempotent, so is $I-A$.

Why A4 holds (optional). If $Av=\lambda v$ then $AAv=\lambda^2v$. Idempotency gives $\lambda^2=\lambda$, so every eigenvalue is 0 or 1. The trace is the sum of eigenvalues and the rank is the number of non-zero ones: both count the ones.

Why S3 holds (optional). Write $A=C\Lambda C'$ with $C$ orthogonal. $w=C'z\sim N(0,C'C)=N(0,I)$ and $z'Az=w'\Lambda w$, a sum of $r$ squared independent standard normals.

Numbers don't have this

The lecture notes "idempotent is a property of matrices; there is no counterpart for real numbers". Strictly, the numbers 0 and 1 satisfy $a^2=a$, but nothing in between does. A matrix can be idempotent and far from both 0 and $I$.

Invert $A=\begin{bmatrix}4&2\\2&3\end{bmatrix}$ and check $AA^{-1}=I$.

Solution

$\det=12-4=8$. $A^{-1}=\frac18\begin{bmatrix}3&-2\\-2&4\end{bmatrix}$. Check: first row of $A$ times first column: $(4\cdot3+2\cdot(-2))/8=1$; times second column: $(4\cdot(-2)+2\cdot4)/8=0$ ✓.

?●●check yourselfTrace trick

Let $P=X(X'X)^{-1}X'$. Show $PP=P$ and find its trace.

Solution

$PP=X(X'X)^{-1}\underbrace{X'X(X'X)^{-1}}_{I_K}X'=P$. Trace, cycling: $\text{tr}(X(X'X)^{-1}X')=\text{tr}((X'X)^{-1}X'X)=\text{tr}(I_K)=K$. So $P$ is $n\times n$ with rank $K$, and $M=I-P$ has rank $n-K$ (module 17).

?●●check yourselfRead a matrix like an econometrician

Someone reports $X'X=\begin{bmatrix}3&2\\1&4\end{bmatrix}$ for a regression with a constant and $n=100$. What is wrong?

Solution

Two things. It is not symmetric ($2\neq1$), and the top-left entry should be $n=100$, not 3. It cannot be an $X'X$. (This is the matrix of the W10 tutorial exercise. The exercise is still good practice for the mechanics of the test, module 25, but the numbers were not produced by a real regression.)
