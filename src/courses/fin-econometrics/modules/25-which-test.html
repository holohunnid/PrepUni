?●●mixed drillName the statistic and distribution

(a) $n=40$, $K=3$, $\sigma^2$ unknown, $\beta_2+2\beta_3=0$. (b) $\sigma^2=5$, $\beta_1=\beta_2=0$. (c) $n=200$, $K=5$, unknown $\sigma^2$, $\beta_2=\beta_3=\beta_4$. (d) $\sigma^2=1$, $\beta_3=2$, $H_A:\beta_3>2$. (e) $n=30$, $K=3$, unknown, all slopes zero.

Solution

(a) $t_{37}$. (b) $\chi^2_2$. (c) $J=2$: $F_{2,195}$. (d) $N(0,1)$, reject in the right tail only (1.645). (e) $J=2$: $F_{2,27}$.

?●●●exam levelA complete problem

$y_i=\beta_1+\beta_2x_{i2}+\beta_3x_{i3}+\varepsilon_i$, $n=53$, $b=(2,\,0.5,\,-0.3)'$, $e'e=100$, $(X'X)^{-1}=\begin{bmatrix}0.10&0&0\\0&0.02&0.01\\0&0.01&0.03\end{bmatrix}$. At 5%: (i) test $\beta_2=0$; (ii) test $\beta_2+\beta_3=0$; (iii) test $\beta_2=\beta_3=0$; (iv) redo (iii) if $\sigma^2=2$ is known.

Solution
  1. $n-K=50$, $s^2=2$. Critical: $t_{50}=2.009$; $\bar F_{2,50}=3.18$.
  2. (i) $\text{se}=\sqrt{2\cdot0.02}=0.2$; $t=2.5>2.009$ ⇒ reject.
  3. (ii) $R=[0\ 1\ 1]$, $m=0.2$; $R(X'X)^{-1}R'=0.02+0.03+0.02=0.07$; $\text{se}=\sqrt{0.14}=0.374$; $t=0.535$ ⇒ do not reject.
  4. (iii) Block $\begin{bmatrix}0.02&0.01\\0.01&0.03\end{bmatrix}$, $\det=0.0005$, inverse $\begin{bmatrix}60&-20\\-20&40\end{bmatrix}$. $m=(0.5,-0.3)'$: $[0.5\ {-0.3}]\begin{bmatrix}36\\-22\end{bmatrix}=18+6.6=24.6$. $F=\frac{24.6}{2\cdot2}=6.15>3.18$ ⇒ reject.
  5. (iv) $\chi^2$ statistic $=24.6/2=12.3>5.99$ ⇒ reject. (No division by $J$.)
