Size, Type I and II errors, power

lecture 7, slides 4–8 · lecture 8, slides 6–7
READ FIRST Two ways to be wrong— ⊡ ✕

You can reject a true $H_0$ (Type I) or fail to reject a false one (Type II). We choose the probability of the first: it is the size. For a given sample we then have no control over the second, and the two pull in opposite directions.

DEF The full picture— ⊡ ✕
$H_0$ true$H_0$ false
"accept" $H_0$✓Type II error
reject $H_0$Type I error✓

One, and only one, of the four cells occurs, and we never know which row of reality we are in.

size$P(\text{reject }H_0\mid H_0\text{ true})$ = P(Type I) — chosen by us
P(Type II)$P(\text{accept }H_0\mid H_0\text{ false})$ — not controlled
power$P(\text{reject }H_0\mid H_0\text{ false})=1-P(\text{Type II})$

For the two-sided test at 5%:

$$0.05=P\left(\frac{b_1}{\sqrt{\sigma^2R(X'X)^{-1}R'}}<-1.96\ \text{ or }\ \frac{b_1}{\sqrt{\sigma^2R(X'X)^{-1}R'}}>1.96\ \Big|\ H_0\right)$$

The size fixes the critical values and so the acceptance and rejection regions. Reducing it to 1% moves the cut-offs from $\pm1.96$ to $\pm2.6$ (precisely 2.576): we reject less often.

Courtroom analogy

$H_0$ = innocent. Type I = convicting an innocent. Type II = acquitting a guilty person. Demanding more evidence (smaller size) reduces the first and increases the second.

KEY The trade-off— ⊡ ✕
$$\downarrow P(\text{reject }H_0\mid H_0\text{ true})\ \Rightarrow\ \uparrow P(\text{accept }H_0\mid H_0\text{ false})\quad\text{and vice versa}$$

Slide 7's question — what happens to the Type II error when we reduce the size? — it goes up: wider acceptance region, so a false $H_0$ is accepted more often too. Choosing the size is "expert judgment". The only way to reduce both is more information: larger $n$, smaller $\sigma^2$, more variation in $X$.

INTERACTIVE Two distributions, one cut-off— ⊡ ✕

Try this. Lower the size: red shrinks, amber grows. Raise $n$: the blue curve walks away from the grey one and both problems shrink. Move the true $\beta_2$ close to 0: power falls towards the size. A test cannot tell 0 from 0.01 with little data. One-sided tests have more power in their direction.

NUMBERS · power by hand (two-sided, 5%)

True $\beta_2=0.5$ and sd$(b_2)=0.25$, so $z\sim N(2,1)$. Power $=P(z>1.96)+P(z\lt-1.96)=P(Z>-0.04)+P(Z\lt-3.96)=0.516+0.000=\mathbf{0.516}$. Type II $=0.484$: a coin toss. At size 1%: $P(Z>0.576)=0.282$, Type II $=0.718$. With four times the data the sd halves, $z\sim N(4,1)$ and power at 5% is $P(Z>-2.04)=0.979$.

?●YES/NO with a reasonFive statements

(a) The size depends on the data. (b) Power + size = 1. (c) With size 0 we never make a mistake. (d) If we reject at 1% we also reject at 5%. (e) A test that always rejects has power 1.

Solution

(a) No: we choose it beforehand. (b) No: power $=1-P(\text{Type II})$, computed under $H_A$; size is computed under $H_0$. (c) No: we never reject, so whenever $H_0$ is false we make a Type II error. (d) Yes: the 1% rejection region is inside the 5% one. (e) Yes, and size 1 too: useless.

?●●practiceCritical value from a size

A one-sided $z$-test rejects when $z>2.05$. What is its size? What is its power if $z\sim N(3,1)$ under the truth?

Solution

Size $=P(Z>2.05)=0.020$. Power $=P(Z>2.05-3)=P(Z>-0.95)=0.829$.
