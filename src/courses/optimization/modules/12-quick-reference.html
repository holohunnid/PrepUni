TIP Exam routines— ⊡ ✕

Unconstrained

State the problem → compute $H(\mathbf x)$ symbolically first (if NSD everywhere, say "concave" and the FOC finishes it) → check existence (compact? coercive?) → solve $\nabla f=\mathbf 0$ for all stationary points → classify each with $H$ at that point → check boundaries → compare and state which global argument you used.

Equality-constrained

Write $\mathcal L=f-\lambda(g-c)$ → set the $n+m$ partials to zero → eliminate $\lambda$ by dividing FOCs → solve with the constraint → find all candidates → classify by comparing values (if compact), by substitution, by concavity, or by the bordered Hessian → report $\mathbf x^*$, $f^*$, and $\lambda^*$ with its interpretation.

Inequality-constrained

Convert to standard form (max, $g\le c$) → Case A: $\lambda=0$, solve unconstrained, check $g\le c$ → Case B: $g=c$, solve by Lagrange, check $\lambda\ge0$ → keep the surviving cases and compare → if $f$ concave and $g$ convex, say so: KKT is then sufficient.

"How much would you pay for…"

That is $\lambda$. Do not re-solve the problem — report the multiplier, with units, and note that it is a marginal (first-order) valuation.

Ten-second self-checks
Did I classify every candidate, or just find them? Did I check the endpoints and corners? Is my global claim supported by concavity, compactness, or coercivity — or by nothing? Did I use $\mathcal L$ rather than $f$ in the bordered Hessian? Is $\lambda\ge0$ where it has to be? Did I answer with the maximiser or the maximum, whichever was asked?
