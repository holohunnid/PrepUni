Traps that cost marks

the false statements, and the checks that catch them
TRAP False — do not write these— ⊡ ✕
ClaimWhy it is false
$V[X-Y]=V[X]-V[Y]$Variances add in both cases; only the covariance term flips sign. This is Q4.
$E[g(X)]=g(E[X])$ for any $g$True for linear $g$ only. $E[X^2]\ne(E[X])^2$ whenever $V[X]>0$ — the gap is exactly $V[X]$.
uncorrelated ⇒ independentFalse in general; true only for jointly normal variables.
dependent ⇒ $\rho\ne0$False. $Y=X^2$ with $X$ symmetric is the standard counterexample. This is Q5.
$V[XY]=V[X]V[Y]$Not a formula in any setting except zero means plus independence. This is Q6.
$\sigma_{X+Y}=\sigma_X+\sigma_Y$Standard deviations never add. Add variances, then take the square root.
quoting $V[R]$ as "the risk"Variance is in squared units. Volatility $\sigma$ is the comparable figure — 0.04 vs 20% is not a rounding difference.
CHECK Do these every time— ⊡ ✕
CheckWhen
$\sum_x P(X=x)=1$before computing anything at all
$V\ge 0$after computing any variance
a variance of 0 ⇒ $\rho=\pm1$whenever a variance comes out exactly zero — cheap consistency test
recompute $V[X]$ the other waydeviation form vs $E[X^2]-\mu^2$: one extra line, catches sign and squaring slips
ask what you were given"only $E[X]$ is provided" ⇒ $g$ must be linear. "Cov is given but not independence" ⇒ only first-power factorisations are legal.
check the unitssquared units means variance, original units means $\sigma$ — decide which the question wants
Tip — the 30-second sweep
Before handing in: every variance non-negative, every probability summing to 1, every $\rho$ inside $[-1,1]$, and every answer in the units the question asked for. Four passes over the page, four different classes of error caught.
