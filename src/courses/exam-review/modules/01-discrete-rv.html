01

Discrete random variables

reading a pmf before you compute anything
DEF Random variable and probability mass function— ⊡ ✕

A random variable $X$ is a rule that assigns a number to the outcome of an experiment. Discrete means it takes its values from a finite (or countable) list.

Its probability mass function (pmf) is that list of value/probability pairs. The exam writes it with a brace — this is the distribution questions 1 and 2 are built on:

$$X=\begin{cases}10 & \text{with } P(X=10)=\tfrac{1}{4}\\ 20 & \text{with } P(X=20)=\tfrac{2}{4}\\ 30 & \text{with } P(X=30)=\tfrac{1}{4}\end{cases}$$

Two axioms you never violate

  • $P(X=x)\ge 0$ for every value $x$
  • $\sum_x P(X=x)=1$, summed over all possible values
Tip — always do this first
Check that the probabilities sum to 1. It costs three seconds and catches a mis-copied distribution before it poisons every later part. If the probabilities contain an unknown constant, that check is the question: solve $\sum_x P(X=x)=1$ for the constant.

Reading the notation

SymbolRead asWhat it is
$X$capital letterthe random variable — the whole rule, not yet observed
$x$lower caseone particular value it can take
$P(X=x)$"probability $X$ equals $x$"a number in $[0,1]$
$\sum$"sum over"add one term per possible value
$E[\cdot],\ V[\cdot]$operatorsfeed in a variable, get out a number
Trap
$X$ and $x$ are not interchangeable. $E[X]$ is a number; $E[x]$ is meaningless. Marking schemes do notice.

Notation note: this paper writes the variance operator as $V[X]$. Other sources write $\operatorname{Var}(X)$ or $\sigma^2$ — same object throughout.
