Q1●module 02Expected value of the three-point distribution
$X$ takes the value 10 with probability $1/4$, 20 with probability $2/4$, and 30 with probability $1/4$. Compute $E[X]$.
Solution
  1. Axiom check first: $\tfrac14+\tfrac24+\tfrac14=1$ ✓
  2. Weight each value by its probability and add: $$E[X]=10(0.25)+20(0.50)+30(0.25)=2.5+10+7.5=\mathbf{20}$$
  3. Read the symmetry as a check: the weights on 10 and 30 are equal, so the distribution balances at the midpoint 20 — the arithmetic was never strictly necessary.
Insight
Two routes to the same number, one arithmetic and one structural. Getting into the habit of looking for the structural route is what makes the later questions fast, and it doubles as a free check on the arithmetic one.
Q2●module 03Variance of the same distribution
For the same $X$, compute $V[X]$.
Solution
  1. $\mu=20$ is a round number, so use the deviation form: $$V[X]=100(0.25)+0(0.50)+100(0.25)=\mathbf{50}$$
  2. Check with the computational form: $E[X^2]=100(0.25)+400(0.50)+900(0.25)=450$, so $V[X]=450-20^2=50$ ✓
  3. If a standard deviation is wanted: $\sigma=\sqrt{50}\approx 7.07$, in the same units as $X$.
Insight
Whichever form you compute with, the other one is a free cross-check that costs one line. On a paper where $V[X]$ feeds into three later questions, that line is worth writing.
Q3●module 04$E[g(X)]$ for a linear $g$
$g(X)=1+2X$ and $E[X]=10$. Compute $E[g(X)]$.
Solution
  1. $g$ is linear, so linearity of expectation applies and the distribution of $X$ is not needed: $$E[1+2X]=1+2E[X]=1+2(10)=\mathbf{21}$$
Insight
The fact that only $E[X]$ is given is itself the signal that $g$ must be linear — with a nonlinear $g$ the question would be unanswerable, since $E[X^2]$ cannot be recovered from $E[X]$. Reading what you were given tells you which tool is intended.
Q4●●TRAPmodule 06Variance of a difference
$V[X]=V[Y]=5$ and $\operatorname{Cov}[X,Y]=5$. Compute $V[X-Y]$.
Solution
  1. Variances add; only the covariance term takes the minus sign: $$V[X-Y]=V[X]+V[Y]-2\operatorname{Cov}[X,Y]=5+5-2(5)=\mathbf{0}$$
  2. Zero variance means $X-Y$ is a constant. Confirm with the correlation: $$\rho=\frac{5}{\sqrt5\cdot\sqrt5}=1$$
  3. $\rho=1$ means $Y=X+c$ exactly, so the difference never moves — consistent. ✓
Trap — answered 1 on the attempt
The two ways to land on a wrong answer here are subtracting the variances ($5-5=0$, right answer for the wrong reason) or mis-signing the covariance term. Do it in two visible steps: variances first, $5+5=10$, then subtract $2(5)=10$.
Insight
A variance of exactly 0 is never a coincidence on an exam — it is a signal that the combination is degenerate. Computing $\rho$ takes one line and confirms it must be $\pm1$. If it is not, the arithmetic is wrong.
Q5●●module 08$E[XY]$ for dependent but uncorrelated variables
$X$ and $Y$ are dependent but uncorrelated. Which is $E[XY]$? (a) 0 · (b) $E[X]E[Y]$ · (c) not computable
Solution
  1. Rearrange the definition of covariance and set $\operatorname{Cov}=0$: $$E[XY]=E[X]E[Y]+\operatorname{Cov}[X,Y]=E[X]E[Y]+0$$
  2. Answer (b).
  3. Why not (a): that would require one of the means to be zero, and nothing in the question says so.
  4. Why not (c): the word "dependent" feels blocking, but the factorisation needs only zero covariance — which is given outright.
Insight
"Dependent but uncorrelated" is written to make you reach for independence and find it missing. Check what the formula actually requires before deciding a question is unanswerable: this one requires exactly the hypothesis you were handed.
Q6●●●module 08$V[XY]$ under the same assumptions
Same $X$ and $Y$ — dependent but uncorrelated. Which is $V[XY]$? (a) 0 · (b) $V[X]V[Y]$ · (c) not computable
Solution
  1. Write the variance out: $$V[XY]=E[X^2Y^2]-\big(E[X]E[Y]\big)^2$$
  2. The second term is fine — Q5 already gave it. The first requires $\operatorname{Cov}[X^2,Y^2]$, about which nothing is known: zero covariance between $X$ and $Y$ does not propagate to their squares.
  3. Answer (c), not computable.
  4. Why not (b): $V[XY]=V[X]V[Y]$ is not a valid identity even under full independence. Why not (a): that would require $XY$ to be constant.
Insight
Q5 and Q6 are deliberately paired: identical hypotheses, opposite answers. The hypothesis is a statement about $X$ and $Y$ to the first power, so it settles the first-power question and says nothing about the squares. "Not computable" is a legitimate answer, and recognising when it applies is the skill being tested.
