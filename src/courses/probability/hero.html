Probability Cheat Sheet

From counting rules to the Central Limit Theorem, built for someone seeing probability properly for the first time. Every concept starts with the plain-language idea, then the formula, then a worked example. The finance thread (returns, portfolios, Value-at-Risk) runs through every module so the abstract material stays concrete.

How to use: read modules 1–4 slowly and in order — they are the language everything else is written in. Modules 5–6 are the distribution zoo (reference, not memorise-in-one-go). Modules 7–9 build the multivariate and asymptotic toolkit, module 10 puts it all into finance. Module 11 is the one-page memory dump for the night before; module 12 has 28 exam-style problems with full solutions — do them on paper before opening the answers.
