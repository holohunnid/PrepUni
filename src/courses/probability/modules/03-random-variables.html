03

Random variables

turning outcomes into numbers: PMF, PDF, CDF
DEF What a random variable is— ⊡ ✕

A random variable (RV) $X$ is a rule that attaches a number to each outcome of the experiment. Roll two dice → $X$ = the sum. Flip 10 coins → $X$ = number of heads. Hold a stock for a day → $X$ = the return. Once outcomes are numbers you can average them, measure their spread, plot them — that is the entire point.

Notation: capital $X$ is the random variable (the rule, value unknown in advance); lowercase $x$ is a particular value it might take. "$X=x$", "$X\le x$" are events, so they have probabilities.

Discrete RVtakes countably many values (0, 1, 2, …). Described by a PMF. E.g. number of defaults among 50 loans.
Continuous RVtakes values in a continuum. Described by a PDF. E.g. a return, a waiting time.
Bothdescribed by a CDF — the universal object that always exists.

Quick test: can you list the possible values? Discrete. Is any value in an interval possible? Continuous.

DEF Discrete: PMF and CDF— ⊡ ✕

The probability mass function (PMF) lists the probability of each value:

$$p(x)=P(X=x),\qquad p(x)\ge 0,\qquad \sum_{x}p(x)=1$$

The cumulative distribution function (CDF) accumulates it from the left:

$$F(x)=P(X\le x)=\sum_{t\le x}p(t)$$

For a fair die: $p(x)=\tfrac16$ for $x=1,\dots,6$. The CDF is a staircase: flat between values, jumping by $p(x)$ at each possible value $x$. The jump size at $x$ is $P(X=x)$.

Any probability comes from summing the PMF: $P(X\in A)=\sum_{x\in A}p(x)$, e.g. $P(2\le X\le 4)=p(2)+p(3)+p(4)=\tfrac12$.

DEF Continuous: PDF and CDF — probability is area— ⊡ ✕

A continuous RV has a probability density function (PDF) $f(x)\ge 0$ with total area 1. Probabilities are areas under the density curve:

$$P(a\le X\le b)=\int_a^b f(x)\,dx,\qquad \int_{-\infty}^{\infty}f(x)\,dx=1$$

The CDF is the accumulated area from the left, and differentiating it recovers the density:

$$F(x)=P(X\le x)=\int_{-\infty}^{x}f(t)\,dt,\qquad f(x)=F'(x)$$

The single most useful computational identity — probability of an interval from CDF values:

$$P(a\lt X\le b)=F(b)-F(a)$$
Trap
For a continuous RV, $P(X=x)=0$ for every single point (a line has no area). Consequences: (1) $\le$ vs $\lt$ makes no difference — $P(a\le X\le b)=P(a\lt X\lt b)$; (2) $f(x)$ is not a probability — it is a density, and can exceed 1 (only areas must stay ≤ 1). Think "probability per unit length": $P(x\lt X\lt x+dx)\approx f(x)\,dx$.

Properties every CDF has

Range & limits$F$ goes from $0$ (at $-\infty$) to $1$ (at $+\infty$)
Monotonenon-decreasing — accumulating area can't go down
Right tail$P(X\gt x)=1-F(x)$ (the "survival function")
Discrete casestaircase with jumps; jump at $x$ = $P(X=x)$
Continuous casesmooth curve, slope = density $f(x)$

INTERACTIVE PDF ↔ CDF — the same distribution, two views— ⊡ ✕

Waiting time until the next trade, $X\sim\text{Exp}(\lambda)$: density $f(x)=\lambda e^{-\lambda x}$, CDF $F(x)=1-e^{-\lambda x}$. Slide $x$ and watch the shaded area on the left become the height of the dot on the right.

Everything you compute with continuous distributions is one of these three moves:

  • $P(X\le x)=F(x)$ — read the CDF,
  • $P(X\gt x)=1-F(x)$ — complement,
  • $P(a\lt X\le b)=F(b)-F(a)$ — difference.

Raise λ (trades arrive faster): the density piles up near 0 and the CDF shoots up sooner — short waits become likely.

DEF Quantiles, median, mode— ⊡ ✕

The quantile function runs the CDF backwards: the $p$-quantile $x_p$ is the value with a fraction $p$ of the probability to its left,

$$F(x_p)=p\qquad\text{i.e.}\qquad x_p=F^{-1}(p)$$
Median$x_{0.5}$ — splits the distribution 50/50. More robust than the mean for skewed data
Quartiles$x_{0.25}$, $x_{0.75}$; IQR $=x_{0.75}-x_{0.25}$
Percentile$x_{0.95}$ = 95th percentile: only 5% of outcomes lie above
Modevalue where the PMF/PDF is highest (the peak)
Finance
Value-at-Risk is a quantile. The 95% VaR of a portfolio is (minus) the 5th percentile of the P&L distribution: the loss threshold exceeded only 5% of the time. Module 10 computes it explicitly.
EX A full continuous-RV workout— ⊡ ✕

Let $f(x)=cx$ for $0\le x\le 1$ (and 0 elsewhere). Find $c$, the CDF, $P(X\gt \tfrac12)$, and the median.

  1. Total area 1: $\int_0^1 cx\,dx=\tfrac{c}{2}=1\Rightarrow c=2$. So $f(x)=2x$: a triangle rising to the right.
  2. CDF: $F(x)=\int_0^x 2t\,dt=x^2$ on $[0,1]$ (0 to the left, 1 to the right).
  3. $P(X\gt\tfrac12)=1-F(\tfrac12)=1-\tfrac14=\tfrac34$. Makes sense: the density's mass leans right.
  4. Median: $F(m)=m^2=\tfrac12\Rightarrow m=\tfrac{1}{\sqrt2}\approx 0.707$ — not 0.5, because the distribution is skewed.
Insight
The full pipeline: normalise → integrate to CDF → answer every probability question from $F$ alone. Note $f(1)=2\gt 1$: densities above 1 are perfectly legal.
